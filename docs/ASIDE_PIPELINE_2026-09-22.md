# Aside Browser를 측정 계층에 넣는다 (2026-09-22)

오너 제안으로 테스트했고 **채택한다.** 이 문서는 무엇을 쓰고 무엇을 안 쓰는지, 그리고
왜 그렇게 나눴는지다.

## 1. 계기 — 로컬 헤드리스가 거부당하는 표면이 있다

`www.jal.co.jp`를 **7가지 조합으로 시도해서 전부 실패**했다. HTTP2 on/off × 진입 URL 4종,
재시도 3회, 셀렉터 대기, 레포 프로브 — 결과는 `ERR_HTTP2_PROTOCOL_ERROR` 아니면 70초
타임아웃이다. **404 경로는 같은 하니스로 정상**으로 뜬다. 주소가 아니라 **헤드리스 지문**을
막는다.

여기서 더 미는 것은 **우회**다. "공개 페이지를 사람과 같은 조건으로 받는다"와 다른 일이고,
`probe-component-states.mjs` 주석이 이미 그 선을 적어놨다.

**Aside Browser는 같은 기계·같은 회선에서 첫 시도에 열었다.** 오너가 실제로 쓰는 데스크탑
크롬이기 때문이다. 우회가 아니라 **진짜 브라우저**다.

## 2. 3계층

```
Tier 1  로컬 Playwright      기본. 지금까지 ~95% 성공
Tier 2  mcp__aside__repl     Tier 1이 막혔을 때. **같은 프로브 코드, 다른 브라우저**
Tier 3  mcp__aside__exec     동의 배너 통과 같은 잡일만. **증거원으로 쓰지 않는다**
```

### Tier 3를 증거원에서 배제하는 이유

`exec`는 프롬프트를 받아 알아서 하는 에이전트다. 토큰은 확실히 덜 든다. 그런데 **오늘
카탈로그를 구한 다섯 건이 전부 원값을 직접 본 결과**였다:

| 잡은 것 | 요약 보고로 잡혔을까 |
|---|---|
| `#005fcc`가 DeepSeek가 아니라 크롬 기본값 — `auto` 한 글자로 갈림 | 아니오 |
| Chatwork CTA로 잰 게 Marketo 폼 버튼 | 아니오 |
| 컨트롤 [0]의 mousedown이 [1]의 focus를 오염 | 아니오 |
| 자동 포커스된 입력이 "상태 없는 컨트롤"로 보임 | 아니오 |
| `#645b4a`를 믿기까지 세 번 확인 | 아니오 |

그리고 **JAL에서 곧바로 또 나왔다**: 가장 많이 렌더되는 본문색 `oklch(0.145 0 0)` ×150이
JAL 게 아니라 **shadcn 기본값**이다. 에이전트가 "본문색은 `oklch(0.145 0 0)`입니다"라고
보고했으면 그대로 브랜드 잉크가 됐을 것이다.

이 카탈로그가 파는 게 재현 가능한 측정이라서, **거기를 위임하면 파는 물건이 바뀐다.**

## 3. 프라이버시 규칙 (ego lite 규칙 + 1)

실제 로그인 세션이 있는 브라우저다. 2026-09-22 ego lite 승인 규칙을 그대로 쓰되 하나 더한다:

1. **`openTab()`만.** `attachActiveBrowserTab()` · `listBrowserTabs()`는 **쓰지 않는다** —
   오너의 다른 탭을 보지 않는다. 끝나면 `closeTab()`.
2. **computed style과 기하만.** 페이지 텍스트·폼 값·계정 식별자·미디어 안 읽는다.
3. **측정 전 `looksAuthenticated` 확인.** true면 탭 닫고 "측정 불가"로 기록한다.
   로그인·계정 생성 안 한다.
4. **`.verification.md`에 수집기를 명시한다** — 어느 브라우저로 읽었는지, 그리고
   **재현에 무엇이 필요한지.**

`mcp__aside__memory_search`(오너 개인 메모)는 이 작업에 **쓰지 않는다.**

## 4. 새 수집기는 known-answer로 검증하고 쓴다

ego lite를 weibo로 검증했던 것과 같다. JAL은 초기 1회 성공 판독이 남아 있어 대조가 됐다:

| | 로컬(1회 성공) | Aside | |
|---|---|---|---|
| 본문 길이 | 2810 | 2810 | ✓ |
| **자체 토큰** | 445 − 29 `--tw-*` = **416** | 479 − 63 `--tw-*` = **416** | ✓ |
| 브랜드 레드 | `#cc0000` | `#cc0000` | ✓ |
| focus | `solid 2px` | `solid 2px` | ✓ |

전체 개수는 다르다(445 vs 479) — Tailwind 레이어가 더 많은 프로퍼티를 낸다. **JAL 자체
416개는 정확히 일치한다.** 총계가 아니라 **자체 토큰**으로 비교해야 한다는 것도 같이 배웠다.

## 5. 토큰 비용 — 실측

| | 소모 | 얻은 것 |
|---|---|---|
| 로컬 시도 (스크립트 4개, 7조합) | ~13,000자 ≈ **4,000 토큰** | **0** |
| Aside (repl 11회, 측정 완료) | ~18,500자 ≈ **5,600 토큰** | **verified_v2 레퍼런스 1건** |

**단가는 거의 같다.** `repl`은 코드를 내가 쓰고 `console.log`로 출력을 조이니 Bash 프로브와
비용 구조가 같다. 얻는 건 토큰 절약이 아니라 **접근**이다.

실제 절약은 다른 데 있다: **헛돈을 안 쓴다.** 막힌 표면에 4,000 토큰을 쓰고 0을 얻는 일이
없어진다.

### `exec` 위임이 값어치 있는 유일한 구간

**후보 스카우팅**(오늘 30개·12개 돌린 census 패스)이다. 거기선 오판의 대가가 "후보 하나
놓침"이지 "틀린 레퍼런스"가 아니다. 측정 패스는 위임하지 않는다.

## 6. 데스크탑 앱이 떠 있어야 한다

첫 호출이 `Aside Browser profile for account u0 … is not connected to the daemon`으로
실패했다. MCP가 데스크탑 앱의 데몬에 붙는 구조다. **Tier 2를 쓰려면 앱과 해당 프로필이
실행 중이어야 한다** — 무인 실행에서는 Tier 1만 가정해야 한다.

## 7. 샌드박스 차이 하나

`repl`에는 `page.waitForTimeout()`이 **없다**. 첫 호출이 `TypeError: not a function`으로
실패했다(탭은 열렸다). 로컬 프로브 코드를 옮길 때 이 한 줄을 바꿔야 한다 —
`locator.hover({timeout})`나 `waitForSelector`는 정상 동작한다.
