## 위임 방식

Sol은 Codex의 워커로 호출할 수 있다. Opus/Grok은 Codex 워커의 모델 이름만 바꿔서 실행하는
방식이 아니라, 각각 Claude Code CLI/Grok Build CLI 프로세스에 작업과 파일 소유권을 넘긴다.
작업 단위별 입력·출력·종료 상태·모델 귀속을 수집하고 통합 담당이 결과를 인수한다.

장시간 작업의 중단/재개·복구와 공통 스케줄러는 아직 전체 검증하지 않았다.
현재 확인은 로그인/응답보다 한 단계 더 나아간 실제 파일 작업 및 병렬 인수 테스트다.
