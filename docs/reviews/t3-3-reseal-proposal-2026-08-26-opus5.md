# T3-3 재봉인 제안 — 은퇴한 평가자 자리 채우기

- 일자: 2026-08-26 · 작성 주체: opus5 · **동결 본문은 아직 수정하지 않았다**(사용자 승인 대기)

## 왜 재봉인이 필요한가

`RUBRIC.md`는 FREEZE 상태이고 §3.2가 평가자를 못박는다:

> 독립 평가자는 **서로 다른 계열 모델 3종**이다: `grok-4.6`, `sol`(codex), `sonnet5`.
> … 3 평가자 미만으로 집계된 항목은 **무효**다.

`run-config.json`은 arm 호스트도 `grok-4.6`으로 봉인하고 이렇게 적는다:

> 실행 전 봉인 값. 여기 없는 값을 실행 중에 정하면 그 run은 무효다.

사용자 결정으로 **sol은 완전 은퇴**, **grok-4.6은 cursor CLI 경유로 사용**한다. 따라서
지금 상태로 실행하면 규정상 무효 run이 된다 — 고쳐야 할 것은 **평가자 한 자리**뿐이다.

## 실측 — 가용 모델 (2026-08-26, `cursor-agent --list-models`)

| 계열 | 모델 ID | 호출 확인 |
|---|---|---|
| xAI | `cursor-grok-4.6-high-fast` | ✅ `GROK_OK` |
| Anthropic | `claude-sonnet-5-thinking-high` | ✅ `SONNET_OK` |
| Anysphere (Cursor) | `composer-2.5` | ✅ `COMPOSER_OK` + JSON 스키마 준수 확인 |

세 계열 전부 **하나의 CLI(`cursor-agent`)** 로 호출된다. 호스트와 평가자가 같은 진입점을
쓰게 되므로 호출 경로의 변수도 하나 줄어든다.

## 제안 — 최소 개정 1건

**`sol`(openai-codex) → `composer-2.5`(anysphere)** — 사용자 지정 2026-08-26.

근거:
1. **계열 독립성이 유지된다.** 원안 xAI/OpenAI/Anthropic → 개정안 xAI/Anysphere/Anthropic.
   §3.2가 요구하는 "서로 다른 계열 3종"을 그대로 만족한다.
1a. **비용이 교체 사유다.** sol은 기술적으로 도달 가능하나(cursor가 `gpt-5.6-sol-high`를
   제공) 채점 3종 × 항목 수의 반복 호출에는 비싸다는 사용자 판단이다. composer-2.5는
   같은 CLI 안에서 훨씬 싼 경로다.
2. **개정 범위가 한 줄이다.** 호스트(`grok-4.6`)와 나머지 두 평가자는 봉인값 그대로다.
   §3.2 C1("세 arm이 같은 호스트를 공유한다")도 영향 없다.
3. **응답 형식이 검증됐다.** 채점은 `scoring-prompts.md`의 응답 스키마를 지켜야 하는데,
   `composer-2.5`가 산문 없이 유효 JSON만 반환하는 것을 실측 확인했다.

## 이 교체가 **새로 만드는** 한계 — 리포트에 적어야 한다

`§3.7 독립성 한계` 절에 한 줄이 추가돼야 한다. 개정안은 세 평가자가 전부 **같은 서빙
플랫폼(cursor)** 을 지나고, 그중 `composer-2.5`는 **그 플랫폼 사업자 자신의 모델**이다.

- 모델 계열은 셋 다 다르므로 §3.2 요건은 만족한다.
- arm 호스트가 `grok-4.6`(xAI)이고 composer는 Anysphere이므로 **직접적 자기 산출물 채점은
  아니다** — §3.2가 "자기 산출물 회피 규칙은 쓰지 않는다"고 정한 것과도 충돌하지 않는다.
- 다만 "서로 다른 계열 3종"이 곧 "서로 독립인 3종"은 아니라는 §3.7의 기존 경고가 한 겹
  더 두꺼워진다. 원안(3종이 공개 웹을 공유)에 더해 **서빙 경로까지 공유**한다.

이 한계는 숨기지 않고 리포트 첫 절에 기재한다 — §3.7이 이미 그렇게 요구한다.

## 알려진 사실 하나 (사용자 판단 자리)

cursor는 `gpt-5.6-sol-high`("GPT-5.6 Sol")를 **여전히 제공한다.** 즉 sol은 기술적으로
도달 가능하다. 그러나 사용자가 "아예 은퇴"로 결정했으므로 이 제안은 sol을 되살리지
않는다. 되살릴 의사가 있다면 개정 자체가 불필요해지므로 알려둔다.
