## 2. 개정이 만든 새 문제

**N1–N5는 전사가 아니라 숨은 채점이다.** 1차는 제목 계층만 중립 라벨로 옮기라고 했다. §3 64–68행은 원문을 N1–N5로 재분류하고 한 문장은 한 라벨에만 싣는다. 다섯 이름은 §4.4 237–243행 채점 항목과 1:1이다. 전사 IRR은 없다. “내용 손실 없이”와 “필드 경로 제거”는 변환 규칙이 없어 충돌한다. 표지 삭제는 216편도 실행 가능하고, 5항목 재작성은 채점 한 축을 사람 한 명에게 먼저 맡기는 일이다. 파일럿(77–78행)이 원문으로 0–4를 잠그면 본실험 패킷과 자극이 달라진다.

**파손률 측정은 되고, 게이트는 실험을 죽인다.** 산출물당 3지선다 1회(80–81행)면 레인당 540 추측, `B_raw`/`B_adj`/Wilson은 이 단위에서 계산된다. 같은 절 83행의 “축별”은 분모가 없다. 84–85행과 §8 조건 6(365–366행)은 합친 `B_raw` CI 하한이 `1/3`을 넘으면 단독 우승과 PASS를 막는다. 세 arm 화면이 다르면 시각 단서만으로도 우연을 이긴다. 그건 처치 효과이지 레이블 누수가 아니다. 형식 단서 부분집합만 누수 게이트다.

## 3. 남은 omd 편향

1차의 형식 보존·항목 1·4 앵커·“생략하라”는 본문에서 빠졌다. N1–N5가 Core v2 목을 채점 패킷의 유일한 순서로 남긴다. 원문 절 순서까지 제거한다(66행). §4.4 233–235행 Core v2 SHA를 용어 참고본으로 전사가 쓰면, 형식 체크리스트를 금지한 문장이 빈다.

## 4. 판정

REJECT가 아닌 이유: 1차 11항의 본문 반영은 사실이다.

FREEZE가 아닌 이유: N1–N5 재분류로 파일럿 앵커가 전사자 손에 잠기고, 합친 `B_raw` PASS가 처치 효과를 실험 무효로 읽는다.

남은 항목:

1. **§3 전사.** 제목 계층만 중립화하고 원문 순서를 보존한다. N1–N5 재분류·한 문장 단일 버킷을 삭제한다. 표지·경로 삭제의 허용 변환을 한 줄로 적는다. Core v2 SHA는 채점·전사 패킷에 첨부하지 않는다. 파일럿 앵커는 본실험과 같은 패킷 형식으로만 교정한다.
2. **§3·§8 파손률.** 추측 단위는 레인 산출물 1회로 고정하고 “축별”을 삭제하거나, 축 패킷마다 별도 추측을 명시한다. `COMPROMISED`는 `형식 단서` 부분집합의 우연 초과에만 붙인다. §8 조건 6에서 합친 `B_raw` PASS 킬을 제거한다. 측정·보고는 남긴다.

이 2항이 본문에 들어간 뒤에만 3차 반박한다. 통과 전 `RUBRIC_FROZEN_SHA`를 쓰지 말고 T3-3을 열지 않는다.
