# C-TRANSCRIBER 재심 — 사용자 지정 opus5

대상: `TRANSCRIPTION.md` §5, `gate-status.json` C-TRANSCRIBER
대조: `docs/reviews/rubric-2026-08-23-capture-conflicts.md` (옵션 2 BLOCK)
새 사실: 사용자가 전사자를 **「opus5가 수행」**으로 지정
일시: 2026-08-23 · 승인권자 grok-4.6

**판정: ACCEPT_WITH_CONDITIONS**

이전 BLOCK은 승인권자가 같은 계열을 고르는 일이었다. 이번은 사용자가 전사자 ID를
봉인하는 일이다. 계열 독립 절반은 포기하고, 세션·메모리 절반과 기계적 변환 범위는
지킨다. 옵션 1(평가자 2종)은 그대로 BLOCK.

`RUBRIC_FROZEN_SHA`는 이 판정만으로 쓰지 않는다. T3-3을 열지 않는다.

---

## 왜 옵션 2 BLOCK을 접는가

§5의 두 조건은 위험이 다르다.

| 조건 | 상태 | 막는 위험 |
|---|---|---|
| 세 계열과 독립 | 위반 (opus5·sonnet5 모두 anthropic) | 채점 사전확률 — 전사 작업의 위험이 아님 |
| 채점 세션·메모리 비공유 | 충족 가능 (별개 인스턴스) | 원문 누설 |
| (문서에 없던 것) | 기계 검증·fail-close로 통제 | 특정 arm에 유리한 전사 왜곡 |

전사는 제목 계층 중립화·표지 삭제·경로 삭제 세 가지뿐이고, 판단 경계는 삭제하지
않고 `TRANSCRIPTION_BLOCKED`다. 네 번째 계열은 없고 사람 전수(216)는 이 실험의
전제가 아니다. 산출물이 아니라 전사자 ID와 절차를 지금 봉인한다.

접지 않는 것: sonnet5가 전사하는 것, opus5가 채점·파일럿·arm 추측·결과 해석에
참여하는 것, 평가자 수를 줄이는 것.

---

## 조건

이 중 하나라도 빠지면 경로는 다시 BLOCK이고 모델 전사를 실행하지 않는다.

### 1. 봉인 값

- 전사자 ID: `opus5`. 벤더 `anthropic`. 런타임 모델 문자열을 `run-config.json`에
  실행 전 기록한다. 별명은 봉인이 아니다.
- `TRANSCRIPTION.md` §5 첫 문단을 사람으로 되돌리지 말고, 위 ID와 아래 면책을
  본문에 적는다. 조용히 우회하지 않는다.

### 2. sonnet5 채점과의 격리

- 전사 세션과 채점 세션을 분리한다. 대화 ID·프로젝트 메모리·이 레포 스킬·
  `AGENTS.md`·Core v2 참고본·팩 `SKILL.md`를 전사 세션에 넣지 않는다.
- 전사 입력은 `TRANSCRIPTION.md`(§4 표지 목록 포함)와 **해당 run 원문 하나**뿐이다.
  다른 arm·다른 반복을 비교용으로 보여 주지 않는다.
- 채점 패킷에는 `PASS` 전사본만 넣는다. 원문, 대응표, seal, 이 절차 문서, 팩 경로는
  sonnet5·sol·grok-4.6 채점 세션에 넣지 않는다.
- opus5 출력이 점수·결함·식별 가능성 메모를 포함하면 그 run은 `TRANSCRIPTION_BLOCKED`다.

### 3. 기계 검증 (전수, 덮지 않음)

- §7.1 검증기를 스크립트로 구현하고 파일 경로+SHA를 실행 전에 봉인한다.
  수작업 체크를 기계 통과로 기록하지 않는다.
- 검증 실행자는 전사자가 아니다. opus5가 자기 산출물을 통과시키지 않는다.
- 한 항이라도 실패하면 비기계 검증으로 덮지 않고 `TRANSCRIPTION_BLOCKED`.

### 4. 의미 검증자

- 전수 사람 의미 검증은 **철회**한다. 슬롯을 `WAIVED`로 봉인하고 `미정`으로 두지 않는다.
- 이유: 주 왜곡 경로(과삭제·표지 잔존·수치/URL 변형·금지 문자열)는 기계 검증이
  전수 담당하고, 허용 변환이 의역을 금하므로 대명사·표 관계의 잔여면이 좁다.
- grok-4.6·sol·sonnet5·opus5에게 원문을 보여 의미 검증을 맡기지 않는다.
- 나중에 사람을 들이면 전사자와 다른 ID여야 하며, 채점에 참여하지 않는다.

### 5. 리포트 한계 절 — 그대로 쓸 문장

문서 축 중립 전사는 평가자 sonnet5와 같은 anthropic 계열의 별개 인스턴스
opus5가 수행한다. 채점 세션·메모리는 공유하지 않으나 계열 독립 조건은
충족하지 못한다. 전사 왜곡은 허용 변환 세 가지와 fail-close, 전수 기계
검증으로 통제했고 비기계 의미 검증은 두지 않았다. 이 상관을 채점
사전확률과 같은 줄에 두지 않는다.
