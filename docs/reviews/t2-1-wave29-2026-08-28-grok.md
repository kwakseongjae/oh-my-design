## 이 웨이브가 말하는 것

**1. A계열 방어 지시가 부분적으로 먹었다.**
웨이브 28은 5건 전부 A계열이었다. 웨이브 29는 A계열이 govuk 1건뿐이고, 그것도 §11 서사가
아니라 §15 접근성 문장의 고유명사다(`vestibular disorders`·`epilepsy` 각 원본 1 / 산출 4파일 0 —
`prefers-reduced-motion` 규칙 자체는 착지했고 **왜 필요한지를 말하는 고유명사만** 빠졌다).
두 웨이브 6건이었던 §11 연혁 누수는 이번에 **0건**이다. 다만 표본이 5개이므로 웨이브 30에서
다시 확인한다.

**2. 진자가 반대편으로 흔들렸다 — 과잉 방어도 발명이다 (greeting).**
anti-invention을 강하게 걸자 워커가 방어적 부정문을 썼다. greeting `:452`는 Desktop 범위를
보존한 뒤 `does not say that anything measures 1440px`를 덧붙였는데, `measures 1440px`라는
측정 틀 자체가 원본에도 sibling에도 없다(원본 0 / sibling 0 / 산출 1). **없는 주장을 지어내
닫은 것**이라 D1이다. 웨이브 27 gaudiy는 같은 자리에서 반대 방향으로 틀렸다 — sibling 값을
본문 사실로 승격했다. 두 실패는 대칭이고 정답은 양쪽 다 **적지 않는 것**이다.
원본이 세운 키를 가르는 범위 한정(`md: 16` ≠ `lg: 16`)과 혼동해선 안 된다.

**3. 도메인 발명이 계속 나온다 (govuk, 웨이브 27·28에 이어 3연속).**
`native application` 원본 0 / sibling 0 / 산출 3, `back-office` 원본 0 / 산출 3.
원본의 `native`는 `native <select>`·`browser native page transitions`뿐이고 `backoffice`는
삭제된 §13에 1회뿐이다. gaudiy `mobile app`, gitlab `product application`, gaudiolab
`applications the company ships`와 같은 형태 — **Scope와 Avoid에서 「우리가 다루지 않는 것」을
쓰려다 원본에 없는 도메인을 세운다.**

**4. sibling 문자열 융합 (govuk).**
원본 §1:95는 `#1a65a6`(live inspect)와 `#1d70b8`(DS specification) 쌍을 세우고, sibling
`:57`만 `#1a65a6`를 DS link token으로 적는다. 산출 `:98`은 둘을 합쳐
`DS colour spec \`link\` token and live-inspect link colour on the Design System colour page`로
썼다 — 그 문자열은 원본에도 sibling에도 없다(원본 0 / sibling 1은 다른 표현 / 산출 1).
gitlab `14px radius with 16px padding`, gaudiy `measures 1440px`와 같은 계열이다.
