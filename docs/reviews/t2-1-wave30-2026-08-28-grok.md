## PASS를 액면가로 받지 않기 위해 한 것

전수 PASS는 「결함이 없다」와 「검토가 느슨해졌다」가 같은 얼굴이다. 판정문의 실측 밀도를
직접 셌고, 가장 얇아 보인 hahow(내 첫 정규식으로 실측 1건)를 전문 확인했다 — `dest` 계수만
30여 건이었고 정규식이 `dest 7` 형식을 못 잡은 것이었다. 판정 품질은 유지되고 있다.

결정적으로, 검토자들이 **이전 웨이브에서 확정된 결함 문자열을 명시적으로 재검사**했다.
hahow 판정문 기준: `native application`/`mobile app`/`product application`/`back-office`/
`1440px` 각 dest 0 · `measures 1440`/`14px radius`/`16px padding` 각 dest 0 · 페르소나 파생물
(`Curious Learner` 등) DESIGN·provenance 0 · C2 `loading | applicable` dest 0(마케팅 CTA는
L/E/S 쌍닫힘). 판정 근거가 이전 판정들의 실측을 상속하고 있다.

표본으로 줄이는 것을 검토할 수 있고, 다시 오르면 지시가 아직 부족한 것이다.
