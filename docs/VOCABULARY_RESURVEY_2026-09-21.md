# identity/CI 어휘 재조사 — 세 시장, 서로 다른 답 (2026-09-21)

확충 계획 4단계(로드맵 C6). §C.3의 시장별 상한은 **이 조사 전까지 잠정**이라고 문서 스스로
적어두었다. 한국에서 「디자인 시스템」 대신 "our identity / CI 가이드"로 다시 찾았더니 Tier 1이
0→4가 됐고, JP·TW·CN에는 그 패스를 돌린 적이 없었다.

세 시장에 하나씩, 병렬로 돌렸다. 원문 보고는 `docs/research/2026-09-21-vocabulary-resurvey/`
(비추적, 09-16 브리핑과 같은 관례).

## 결과

| | verified | 어디에 있나 | 민간 대기업 |
|---|---:|---|---|
| **JP** | 7 | 대학 · 지자체 · 중앙정부 · 행사조직 | **없음** |
| **TW** | 13 | 정부 · 대학 **전부** | **없음** |
| **CN** | 12 | 대학 5 + **민간 대기업 다수** | **있음** |

어휘 전환 자체는 세 시장 모두에서 통했다 — design-system 검색이 **구조적으로 볼 수 없는**
층이 실재한다. 그러나 **그 층이 어디에 있는지는 시장마다 다르다.**

## 나는 에이전트 인용을 믿지 않고 다시 받았다

13건을 직접 페치해서 인용된 값을 grep했다.

```
JP  u-tokyo #0B8BEE ✓   sophia #9A003D ✓   titech #005396 ✓   plateau #00BEBE ✓
TW  NCKU #420A15 ✓      NYCU Pantone286 ✓  NTCH Pantone1797 ✓(브라우저에서만)
    NTHU Pantone259 — 내 환경 DNS 실패, 미확인
CN  QQ #EA1C26 ✓        TencentCloud #00A4FF ✓  PKU R139 ✓  Donghua 7627 ✓
    小爱同学 #05C5FA — 403, 미확인
```

**10건 확인 · 2건 내 환경에서 도달 불가 · 0건 반증.** 미확인 2건은 **반증이 아니다.**

## 방법론 — 이번 조사의 가장 이식성 높은 산출물

**UA를 갖춘 curl로도 부족하다.** 기존 교훈은 "403은 대개 헤드리스 탐지"였는데 한 단계 더 간다:

- TW 에이전트: 자동 페치를 막은 **3개 호스트 전부 실제 브라우저에서 정상 렌더, 그중 2개가 find.**
  국가양청원·타오위안시는 curl만 썼으면 "도달 불가"로 적혔을 것이다.
- **내가 재현했다** — 국가양청원은 curl에 200을 주지만 본문이 JS 셸이라 `1797`이 없다.
  실제 브라우저로 렌더하니 나온다.
- CN: 텐센트 CDN은 **`Referer: https://isux.tencent.com/brands/`가 필요**하다. 없으면 403.
  이것도 재현했다.

→ **이전 패스들이 curl만으로 `blocked`를 적었다면 그 행들은 다시 열어야 한다.**

## 상한에 무엇을 하는가 — 두 종류를 섞으면 안 된다

카탈로그는 **아이덴티티 전용 레퍼런스를 이미 갖고 있고, 최상위 티어를 주고 있다**:

```
id       tier          components  interactive  stated  claims
krds     verified_v2           12            5       5     199   ← 진짜 디자인 시스템
toyota   verified_v2            1            0       0      34   ← 아이덴티티만
sony     verified_v2            1            0       0      23   ← 아이덴티티만
```

**JP·TW의 발견 20건은 toyota/sony 모양이 된다.** 대학·지자체 VI 매뉴얼에는 컴포넌트도
상태도 없다. count는 오르고 **평균 깊이는 내려간다.**

**CN은 다르다.** 텐센트 ISUX 브랜드북은 **제품 브랜드북**이다 — QQ·QQ空间·텐센트클라우드는
살아있는 제품 표면을 가진 제품이고, 브랜드북(토큰급 색·서체·최소 크기·금지사항)에 라이브
캡쳐를 더하면 **완전한 레퍼런스**가 된다. 하이얼·화웨이·샤오아이도 같다.

### §C.3 대비

| 시장 | §C.3 현실적 신규 | 이번 조사가 말하는 것 |
|---|---|---|
| JP | 115~160 (Tier 1 14~22) | 제품 레퍼런스 여력은 **안 바뀐다.** +7은 아이덴티티 도메인 |
| TW | **0 권장** | 제품 기준으론 0이 여전히 맞다. 그러나 **아이덴티티 층은 13건 + 미조사 다수** |
| CN | +30에서 중단 | **과소평가로 보인다.** 텐센트만 브랜드북 14권(4권만 열람), 하이얼·화웨이·샤오미는 기존 추정의 "11개 회사" 밖 |

**700은 지금 당장 바뀌지 않는다.** CN 상향 여지가 생겼지만 CN 결정은 "게이트 확장 후"였고
게이트는 어제 넣었다(`942c5067`). 커버리지가 확정되면 그때 다시 본다.

## 오너 결정이 필요한 것 하나

**아이덴티티 전용 레퍼런스를 넣을 것인가.**

- 넣는다 → JP+TW에서 20건 즉시, TW 층은 더 깊다. 700에 빨리 닿는다. **평균 깊이는 내려간다.**
- 안 넣는다 → JP·TW 재조사의 실질 수확은 0에 가깝다. CN만 남는다.
- 선례는 이미 넣는 쪽이다(toyota·sony가 `verified_v2`). 다만 그게 **의도된 선례인지**는
  확인된 바 없다 — 두 건 다 `added`가 없어 언제 왜 들어왔는지 기록이 없다.

내가 조용히 정하지 않는다. 제품 레퍼런스와 아이덴티티 레퍼런스를 **분리해서 셀지**가
사실상 700의 의미를 정한다.

## 커버리지 공백 (에이전트 자기 신고 — 셋 다 밝혔다)

- **TW**: 중앙부처 대부분, 현·시 정부 대부분, 사립대 미조사 → "13보다 깊다"
- **CN**: 통신3사·보험·전기차·4대 은행 가볍게만 훑음, 물류·부동산·에듀테크·선전 외 도시 미조사,
  텐센트 브랜드북 14권 중 4권만 → "12보다 깊다"
- **JP**: 대기업 표본이 4곳뿐 → 일본 대기업 일반을 말할 수 없다(에이전트도 주장 안 함)

세 시장 모두 **한 번의 패스는 하한이지 상한이 아니다.** 로드맵 §C.7b가 이미 적어둔 그대로다.
