## A5 pass — Latin brand-copy restoration (2026-08-26)

Opened on the F3 auditor's out-of-remit report (`audit-log.md`, "Out of remit"): the auditor found a brand string lost from all three artefacts but could not restore it, because restoring a published value is a value edit their mandate forbids. This pass is that restoration, plus the manual sweep the machine gate structurally cannot perform.

**Why the gate did not catch it.** `migrate-reference.mjs`'s `copy-loss` check builds its needles only from contiguous **non-Latin** runs inside quoted source copy (`NONLATIN_RUN`, `test-v2/tools/migrate-reference.mjs:161`), and only for runs of 4+ characters. A wholly Latin brand string produces no needle at all, so it can vanish from every output and from the ledger with `problems: []`. That is a known precision-over-recall trade in the checker's own comments, and it is why A5 keeps a human sweep. `PASS` on this brand never was evidence that its Latin copy survived.
