### Named gaps

These decisions are unnamed values, not permissions to invent:

- hover, focus, pressed, selected, empty, loading, inline error, form error, success, disabled, skeleton, dialog, menu, tab, toast visual treatments
- semantic success, warning, error, product-app, and documentation palette
- authenticated product or documentation font family
- mobile breakpoint, mobile navigation state, and responsive component transformation
- signed-in application layout and documentation layout
- motion duration, easing, animation name, transition properties, and reduced-motion behavior — promote only after per-component computed capture of all five kinds; official documentation of a single curve or duration is not that gate
- `gradient-11` decorative multicolor shadow as a default card elevation
