## 1. 오너에게 묻는 것 — 이것뿐이다

| 묻는다 | 이유 |
|---|---|
| **게이트의 의미를 바꾸는 변경** — proof/verified 기준 완화, 임계치 변경, 규칙 삭제 | "verified"가 뜻하는 바가 바뀐다 |
| **레퍼런스 통째 삭제** | 되돌리기 어렵고 카탈로그 범위 결정이다 |
| **main 머지 = 프로덕션 배포** | Vercel이 main에서 배포한다. 출시 GO는 오너 몫(memory: feedback_commits) |
| **버전 출시 GO** | 동일 |
| **라이브러리/브랜드 판정이 규칙으로 안 갈릴 때** | AGENTS.md의 넌센스 경로 대조군으로도 모호한 경우만 |
| **유료 서비스·계정 생성·로그인** | 금지 규칙 |
| **화면이 바뀌는 변경의 머지** | 오너가 프리뷰를 직접 열어 본 뒤에만 한다. 스크린샷이나 "권장대로"는 확인이 아니다(2026-10-01 랜딩) |
| **밖으로 나가는 것** — 게시, 메일 발송, 예약 실행 만들기 | 되돌릴 수 없고 오너 이름으로 나간다 |
| **3회 시도해도 수렴 안 하는 실패** | 방향 전환이 필요할 수 있다 |

**이 목록에 없으면 묻지 않는다.** 결과만 보고한다.

**묻는 형식 (오너 지적 2026-09-23: 범주만 나열하면 답할 수 없다).** 물을 때는 AskUserQuestion으로,
① 어떤 레퍼런스/파일의 무슨 건인지 ② 무엇을 발견했는지(측정값) ③ 선택지 2~3개와 각각의 결과
④ 내 추천(첫 번째 선택지) — 을 담는다. 답을 기다리는 동안 그 건과 무관한 큐는 계속 진행한다.

**루프의 실체**: 별도 프로세스가 아니라 이 세션 안의 타이머(ScheduleWakeup)와 서브에이전트 완료
알림이다. 세션이 닫히면 멈춘다. 서브에이전트를 띄웠으면 그 사실을 보고에 적어 오너가 무엇이
돌고 있는지 알 수 있게 한다.

## 2. 묻지 않고 하는 것 (상시 위임)

- 레퍼런스 측정 → 검증 → 저작 → 게이트 → **커밋** (세션 자율권, 2026-09-23)
- **피처 브랜치 푸시** — 매 커밋 후 백업 (상시 위임, memory 2026-08-20)
- 기존 레퍼런스의 오류 정정 — 증거가 요구하면 verified에서 내리는 것까지 (정직한 강등은 판단이 아니라 측정이다)
- 내 도구(`scout-candidates.mjs`, `probe-component-states.mjs` 등)의 결함 수정
- 위임: 역할별 모델과 지시서는 `docs/workers/ROLES.md`를 따른다
- CURRENT_STATE.md · JOURNAL.md · 이 문서의 큐 갱신

보고는 **답을 요구하지 않는 형태**로 한다. "~할까요?"로 끝내지 않는다.

## 3. 목표와 작업 큐

- 방향과 트랙: `docs/ROADMAP.md`. 스프린트마다 목표와 레인을 거기에 적는다.
- 큐의 정본: 요청 원장의 대기열(`asktrack queue show`). 이슈를 만들면 같은 턴에 칸에 넣거나 이유를 달아 보류한다.
- 레퍼런스 수의 작업 목표는 700이다. 세는 것은 verified로 들어간 수다. 새 레퍼런스는 한국·일본·대만·홍콩·중국을 먼저 한다(오너 2026-11-02).

## 4. 회차당 절차 (레퍼런스 묶음)

| 단계 | 누가 | 도구 |
|---|---|---|
| ① 후보 | 본 세션 | 센서스(`~/.omd-workers/census-*`) → 큐 파일. 이미 있는 회사인지는 id가 아니라 홈페이지 주소로 대조한다 |
| ② 수집·작성 | Codex 워커, 동시에 4개까지 | `scripts/workers/run-queue.sh` · 지시서 `docs/workers/REFERENCE_ORDER_TEMPLATE.md` |
| ③ 헤드라인 재측정 | 본 세션 | `scripts/workers/remeasure.sh` — 워커가 쓴 설정 그대로 다시 잰다. **빠뜨리지 않는다** |
| ④ 착지 | 본 세션, 한 줄로 | `scripts/workers/land-batch.sh <워크트리> <워커 폴더…>` — verified_v2가 아닌 것은 빼고 보고한다 |
| ⑤ PR | 본 세션 | 브랜치 푸시 → PR. main 머지는 오너 GO, 머지 뒤 운영에서 확인 |

재측정에서 지킬 것 두 가지: 못 잰 상태는 "변화 없음"이 아니다. 봇 확인이나 차단이 나오면 우회하지 않고 보류로 적는다.
