# holo-foil — 각도에 반응하는 홀로그램 포일

| | |
|---|---|
| 계열 | 재질 |
| CSS-only | 아니오 — JS 24줄 (포인터 각도 전달) |
| 인라인 크기 | CSS 22줄 + JS 24줄 / 약 2.0KB |
| 다크/라이트 | 둘 다 — **다크 우세.** `color-dodge` 는 어두운 바탕에서 훨씬 잘 읽힌다. 라이트에서는 strength 를 올리고 gloss 를 내린다 |
| 라이선스 | 이 구현은 oh-my-design 자작, MIT |
| 난이도 | 상 |

## 무엇인가
두 겹이 만드는 착시다.
1. **이리데선트 층** — 색상환을 반복하는 `repeating-linear-gradient` 를 `color-dodge` 로 합성.
   포인터 위치에 따라 `background-position` 이 움직여 색이 흐른다.
2. **정반사 층** — 포인터를 따라오는 흰 점을 `overlay` 로 합성. 어디가 광원인지 알려준다.

두 층의 이동 속도가 다르기 때문에(1.6배 계수) 각도가 바뀔 때 색과 광택이 어긋나고,
그 어긋남이 "금속 포일"로 읽힌다.

## 라이선스 주의 — 중요
이 계열의 가장 유명한 구현인 **Simey 의 pokemon-cards-css 는 GPL-3.0** 이다
(https://github.com/simeydotme/pokemon-cards-css — LICENSE 원문 확인).
GPL-3.0 코드를 복사해 우리 산출물에 넣으면 카피레프트 의무가 전파된다.
**따라서 저 코드는 한 줄도 가져오지 않았고**, 기법(blend-mode 조합 + 포인터 각도 변수)만
참고해 처음부터 다시 썼다. 기법은 저작권 대상이 아니지만 코드는 대상이다.

## 언제 쓰나
- 등급/희소성을 표현해야 하는 카드 (플랜, 배지, 수집물, 인증서)
- 제품이 물성 있는 물건임을 암시하고 싶을 때 (카드형 결제 수단, 티켓)
- 쇼케이스 1~2개 요소의 "만져보고 싶은" 마감

## 금기
- **버튼·텍스트 블록·본문 카드에 쓰지 않는다.** 카드가 아닌 것에 붙이면 즉시 게임 UI 가 된다.
- 한 화면에 3개 이상 = 유치. 1개가 정답에 가깝다.
- `--fx-foil-strength` 0.5 초과는 브랜드가 무지개에 잡아먹힌다. 제품용은 0.2~0.35.
- 포일 층 위에 본문 텍스트를 올리지 않는다 (대비가 각도에 따라 변한다).
- 틸트 각도를 12deg 초과로 주면 멀미가 난다. 데모의 ±10deg 가 상한.

## 접근성 / 폴백
`@media (hover:none)` 에서 두 층 모두 제거. 마운트도 `matchMedia('(hover:hover)')` 로 차단.
효과는 순수 장식이므로 스크린리더에 아무것도 노출하지 않는다.

## 파라미터
`--fx-foil-strength`, `--fx-foil-gloss`, `--fx-foil-angle`
JS 가 내보내는 `--fx-foil-tilt-x/y` 를 부모의 `transform` 에 물리면 3D 틸트와 자동 연동된다.
