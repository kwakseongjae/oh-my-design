# tilt-3d — 시차가 있어야 비로소 3D

| | |
|---|---|
| 계열 | 깊이 |
| CSS-only | 아니오 — JS 26줄 |
| 인라인 크기 | CSS 10줄 + JS 26줄 / 약 1.4KB |
| 다크/라이트 | 둘 다 — 형태 효과라 색과 무관 |
| 라이선스 | 이 구현은 oh-my-design 자작, MIT |
| 난이도 | 중 |

## 핵심 — 대부분의 tilt 구현이 놓치는 것
카드를 `rotateX/Y` 로 기울이기만 하면 뇌는 그것을 **기울어진 평면**으로 읽는다.
깊이는 **시차(parallax)** 에서 온다. 자식 요소에 `--z` 를 주어 서로 다른 Z 로 띄워야
기울일 때 요소들이 서로 다른 속도로 움직이고, 그때 비로소 3D 로 읽힌다.
데모의 1번 카드(시차 있음)와 2번 카드(없음)를 나란히 두면 차이가 즉시 보인다.

## 라이선스 메모 — vanilla-tilt.js 를 쓰지 않는 이유
`vanilla-tilt.js` 는 MIT 로 표기돼 있으나(https://github.com/micku7zu/vanilla-tilt.js — 배지 수준 확인),
최신 릴리스가 3년 이상 지났고 우리에게 필요한 것은 26줄이다. 의존성 0이 낫다.

## 금기
- **최대 각도 10deg 초과 금지.** 12deg 를 넘어가면 멀미가 나고 텍스트가 읽히지 않는다. 제품용은 5~8deg.
- 그리드 전체(카드 12장)에 걸지 않는다. 마우스를 지나갈 때마다 화면 전체가 출렁인다.
- `perspective` 를 500px 미만으로 두면 왜곡이 심해 싸구려가 된다. 700~1200px.
- 복귀(settle) 트랜지션을 안 주면 커서가 나갈 때 카드가 툭 끊긴다. 400ms 내외 필수.
- 본문을 읽어야 하는 긴 텍스트 카드에는 쓰지 않는다.
- 터치 기기 / `prefers-reduced-motion` 에서 마운트 자체를 건너뛴다.

## 파라미터
`data-fx-tilt-max`(각도), `--fx-tilt-persp`, `--fx-tilt-scale`, `--fx-tilt-track`(추적 속도), `--fx-tilt-settle`(복귀 속도)
자식의 인라인 `--z` 값(px)으로 시차 층을 만든다. **holo-foil 과 조합하면 재질까지 붙는다.**
