# aurora-mesh — 표류하는 메시 그라디언트 배경

| | |
|---|---|
| 계열 | 빛 · 배경 |
| CSS-only | 예 (JS 0줄) |
| 인라인 크기 | CSS 약 24줄 / 1.3KB, 마크업 4줄 |
| 다크/라이트 | 둘 다 — 단, 라이트에서는 `--fx-aurora-opacity` 를 내리고 `--fx-aurora-sat` 를 올려야 한다 |
| 라이선스 | 이 구현은 oh-my-design 자작, MIT |
| 난이도 | 하 |

## 무엇인가
블러를 크게 먹인 색 덩어리(blob) 3개를 서로 다른 주기·지연으로 `transform` 만 움직여
메시 그라디언트가 살아 움직이는 것처럼 보이게 한다.

## 왜 이렇게 구현했나
`background-position` 이나 그라디언트 색 정지점을 애니메이트하면 매 프레임 페인트가 다시 일어난다.
블러 반경이 60px 이상이면 그 페인트가 비싸다. 덩어리를 별도 요소로 두고 `transform` 만 애니메이트하면
합성 단계에서만 처리된다.

## 언제 쓰나
- 히어로 배경을 정적 그라디언트보다 살아 있게 만들고 싶을 때
- 사진/영상 에셋이 없는데 화면 상단이 비어 보일 때
- 브랜드 색이 2~3개 있고 그 색을 "분위기"로만 쓰고 싶을 때

## 금기
- **덩어리 위에 본문 텍스트를 바로 올리지 않는다.** 블러 덩어리는 밝기가 시간에 따라 변하므로
  대비를 보장할 수 없다. 텍스트 뒤에는 반드시 불투명 또는 고정 알파의 판을 깐다.
- 주기를 10초 미만으로 두면 "화면보호기"가 된다. 24s 이상 권장.
- 채도 높은 색 4개 이상 = 2010년대 후반 그라디언트 클리셰. 최대 3개.
- 라이트 모드에서 opacity 를 그대로 두면 유치해진다.

## 파라미터
`--fx-aurora-1/2/3`(색), `--fx-aurora-blur`(기본 72px), `--fx-aurora-opacity`, `--fx-aurora-sat`, `--fx-aurora-base`(바탕색)

## 출처 / 계보
메시 그라디언트 배경은 2021년 Stripe·Linear 이후 표준 어휘가 됐고, 2024~2026 에는
"덩어리를 transform 으로만 움직이는" 형태가 성능 때문에 사실상 표준이 됐다.
`color-mix(in oklab, …)` 는 Baseline 2023 이후 안전하다 — 폴백이 필요하면 두 번째 정지점을 rgba 로 바꾼다.
