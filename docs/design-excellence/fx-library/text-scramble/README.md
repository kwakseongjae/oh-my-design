# text-scramble — 해독되며 정착하는 문자

| | |
|---|---|
| 계열 | 텍스트 |
| CSS-only | 아니오 — JS 36줄 |
| 인라인 크기 | JS 36줄 + CSS 6줄 / 약 1.5KB |
| 다크/라이트 | 둘 다 — 색과 무관 |
| 라이선스 | 이 구현은 oh-my-design 자작, MIT |
| 난이도 | 중 |

## 무엇인가
각 문자에 서로 다른 시작·종료 프레임을 주고 그 사이에는 무작위 글리프를 보여준다.
문자들이 물결처럼 차례로 "정착"한다.

## 반드시 지켜야 할 두 가지
1. **접근성** — 스크램블 중인 텍스트는 스크린리더에게 의미 없는 소음이다.
   최종 문자열을 `aria-label` 로 고정하고 애니메이션 노드는 `aria-hidden="true"` 로 감춘다. 이 구현이 그렇게 한다.
2. **폭 고정** — 글리프 폭이 다르면 주변 레이아웃이 매 프레임 흔들린다.
   `tabular-nums` + `.fx-scramble--fixed`(고스트를 겹쳐 최종 폭을 미리 차지) 로 막는다.
   수치에 쓸 때는 이게 선택이 아니라 필수다.

## 언제 쓰나
- 대시보드/수치가 갱신되는 순간 (값이 "계산됐다"는 신호)
- 기술·보안·데이터 톤 제품의 히어로 헤드라인 **한 줄**
- 상태 라벨 전환 (`대기 중` → `실행 중`)

## 금기
- **본문 문단에 쓰지 않는다.** 읽으려는 텍스트가 흔들리면 그냥 방해다.
- 페이지에 2곳 이상 = "해킹 영화" 클리셰. 톤이 기술 쪽이 아니면 0곳이 맞다.
- 한글은 글리프 폭이 커서 라틴 노이즈 글리프와 섞으면 폭이 크게 튄다 → `--fixed` 필수, 또는 숫자/영문에만.
- 총 지속 1초 초과 금지. 사용자는 그동안 아무것도 못 읽는다.
- `prefers-reduced-motion` 에서 즉시 최종 문자열로 (이 구현은 자동 처리).
