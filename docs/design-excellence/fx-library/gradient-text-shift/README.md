# gradient-text-shift — 문자 안을 흐르는 빛

| | |
|---|---|
| 계열 | 텍스트 · 빛 |
| CSS-only | 예 (JS 0줄) |
| 인라인 크기 | 약 16줄 / 0.8KB |
| 다크/라이트 | 둘 다 — **두 번째 색만 바꾸면 된다.** 첫 색은 `currentColor` 라 테마를 자동으로 따라간다 |
| 라이선스 | 이 구현은 oh-my-design 자작, MIT |
| 난이도 | 하 |

## 설계 포인트
- 첫 정지점을 `currentColor` 로 두면 **테마 토큰을 그대로 상속**한다. 그라디언트 텍스트가
  다크/라이트에서 각각 따로 정의될 필요가 없어진다.
- `@property --fx-gt-p` 로 `<percentage>` 를 등록해야 `background-position` 이 부드럽게 보간된다.
  근거: https://web.dev/blog/at-property-baseline (확인)
- `@supports not (background-clip:text)` 폴백에서 **글자가 투명하게 사라지지 않도록** 반드시 색을 되돌린다.
  이 폴백이 없는 구현은 미지원 환경에서 텍스트가 통째로 사라진다.

## 금기
- **문장 전체에 걸지 않는다.** 강조는 대비에서 오는데 전부가 그라디언트면 대비가 0이다. 한 단어~한 구.
- 상시 흐름(`--flow`)은 9초 이상. 3초짜리 그라디언트 텍스트는 2021년 AI 스타트업 템플릿 신호다.
- 본문(16px 이하)에는 쓰지 않는다 — 작은 글자에서 그라디언트는 그냥 색이 흐린 글자다. 28px 이상.
- 그라디언트 텍스트의 대비는 **가장 밝은 정지점이 아니라 가장 어두운 정지점** 기준으로 측정한다.
- 한 화면에 2곳 이상 금지.
