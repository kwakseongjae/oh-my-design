# dot-grid-field — 좌표계로 읽히는 배경 격자

| | |
|---|---|
| 계열 | 배경 |
| CSS-only | 예 (포인터 노출 변형만 JS 8줄) |
| 인라인 크기 | 약 20줄 / 1.0KB |
| 다크/라이트 | 둘 다 — **도트 색을 반드시 뒤집는다.** 다크 흰색 .35, 라이트 검정 .42 |
| 라이선스 | 이 구현은 oh-my-design 자작, MIT |
| 난이도 | 하 |

## 핵심은 격자가 아니라 마스크
`radial-gradient` 한 줄로 도트를 깔면 화면 끝에서 격자가 **잘린다**. 그러면 배경이 아니라 벽지가 된다.
방사 마스크로 가장자리를 페이드시키는 순간, 같은 격자가 "공간이 여기서부터 시작된다"는 신호로 바뀐다.

## 변형 4가지
- 기본 도트 / `--lines` 라인 그리드(설계도·기술 톤)
- `--drift` 60초에 한 칸 표류 — "있는 줄도 모르는" 생동감
- `--reveal` 포인터 반경 안에서만 격자 노출 (spotlight-pointer 와 같은 변수 사용, 조합 가능)

## 언제 쓰나
- 히어로/섹션 배경에 "구조"를 암시할 때 (기술·데이터·도구 제품)
- 사진이나 일러스트 에셋이 없을 때 빈 공간을 채우는 가장 저렴하고 안 촌스러운 수단
- 빈 상태(empty state)의 캔버스

## 금기
- **마스크 없이 쓰지 않는다.** 가장 흔한 실패.
- opacity 0.35 초과 → 본문 가독성이 떨어지고 격자무늬 셔츠가 된다.
- gap 을 14px 미만으로 두면 모아레가 생기고, 저해상도 화면에서 지저분해진다. 20~40px.
- 표류 속도를 20s 미만으로 두면 배경이 "기어간다". 최소 45s.
- 도트 + 라인 + 오로라 + 그레인 동시 적용 = 배경 소음. 배경 레이어는 최대 2겹.
