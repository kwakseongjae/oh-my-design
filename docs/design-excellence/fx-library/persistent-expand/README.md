# persistent-expand — 큰 패널이 스스로 옮겨 다니고, 누른 자리에 멈춘다

| 다크/라이트 | 둘 다 — 본문 그라디언트(`rgb(0 0 0 / .66)`)를 라이트에서 교체 |

## 왜 만들었나 — 호버 관문을 없앤다
기존 `stack-fan-hover` · `hover-cross-open` · `flip-expand-card` 는 전부 **호버가 열쇠**다.
마우스를 올려야 펼쳐지고 치우면 닫힌다. 그 결과 (a) 터치 사용자는 그 상태를 본 적이 없고,
(b) 데스크톱 사용자도 **매번 호버를 유지해야** 하며, (c) 가만히 두면 페이지가 죽어 있다.

이 효과는 셋을 한 번에 뒤집는다.
- **기본 상태가 이미 크다** — 열린 패널이 행 폭의 **62.7%**, 높이 **68vh**(실측).
- **입력 0 에서도 움직인다** — 5.2초마다 다음 패널이 열린다. 유휴 층이다.
- **여는 것은 클릭이다** — 클릭하면 **고정(pin)** 되고 자동 순환이 멈춘다. 마우스를 치워도 닫히지 않는다.
- **호버는 2% 리프트뿐** — 여는 장치가 아니라, 보려고 멈춘 사람 앞에서 순환을 멈추는 배려다.

## 계보
가로 아코디언 자체는 오래된 문법이다. React Bits `AccordionGallery`
(https://reactbits.dev/, MIT + Commons Clause)는 "hover or focus" 로 연다고 기술한다 —
즉 **호버 관문**이다. 우리가 바꾼 것은 문법이 아니라 **누가 시간 축을 쥐느냐**다:
호버 → (자동 순환 + 클릭 고정). Codrops "Animated Product Grid Preview"
(https://tympanus.net/codrops/2025/05/27/animated-product-grid-preview-with-gsap-clip-path/)도
같은 계열이지만 열림이 호버에 묶여 있다.

## 핵심 — 상태는 클래스 하나다
`.is-open` 하나가 `flex-grow: 1 → 5.4` 를 만들고, 세로 라벨을 지우고, 본문을 올린다.
`.fx-pex.is-pinned` 하나가 "고정됨" 배지를 켠다. **JS 는 클래스만 바꾼다.**

```
열린 폭 = open / (open + n − 1)   →  5.4 / (5.4 + 3) = 64%  (4장 기준)
```
패널 수가 바뀌면 `--fx-pex-open` 을 다시 계산한다. 5장이면 6.9, 3장이면 3.6 이 62% 근처다.

## 정직하게 — `flex-grow` 트랜지션은 레이아웃이다
`transform` 이 아니라 **매 프레임 레이아웃을 다시 계산한다.** 그래서 두 가지를 걸었다:
- `contain: layout paint` 를 패널마다 — 재계산 범위를 패널 안으로 가둔다.
- **패널 5장 · 자식 2단계까지가 상한.** 그 이상이면 `flip-expand-card` 의 FLIP 방식으로 가야 한다.

FLIP 으로 이 효과를 만들 수도 있지만, 아코디언은 **형제들이 동시에 줄어드는** 배치라
FLIP 으로는 형제 전원을 매번 측정해야 한다. 4~5장에서는 `flex-grow` 가 코드가 1/3이고 더 안전하다.

## 금기
- **패널 6장 이상 금지.** 닫힌 패널이 손톱만 해져 세로 라벨도 안 들어간다.
- 열린 폭 55% 미만 금지. 그러면 다시 "소극적인 이미지"다.
- 자동 순환 3.5초 미만 금지 — 읽기 전에 넘어간다. 8초 초과도 금지 — 죽은 것처럼 보인다. 5.2초가 기본.
- **호버로 열지 않는다.** `:hover { flex-grow }` 를 추가하는 순간 이 효과의 존재 이유가 사라진다.
- 닫힌 패널에서 **무엇인지 못 읽게 두지 않는다.** 세로 라벨(`__spine`)은 장식이 아니라 필수다.
- 같은 섹션에 다른 호버 동사(`tilt-3d`, `flip-expand-card`, `hover-cross-open`)를 겹치지 않는다.
- 같은 섹션에 다른 유휴 동사(`wide-drum`, `poster-cylinder`, `coverflow-ring`)를 겹치지 않는다. **유휴 층은 섹션당 1개.**

## 성능 조건
- 트랜지션 대상은 `flex-grow` 1개 + `opacity`/`translate` 2개. `width` 를 쓰지 않는다.
- `will-change: flex-grow` 는 패널에만(4~5장).
- `IntersectionObserver` 로 화면 밖에서 `setInterval` 정지. 배터리를 먹는 유휴 효과는 유휴 효과가 아니다.
- 호버 중에도 타이머를 끈다(정지가 아니라 **해제**).

## 접근성
- 패널마다 `role="button"` · `tabIndex` · `aria-expanded`.
- **Enter/Space** 고정 토글, **← → ↑ ↓** 이동(이동은 곧 고정), **Esc** 고정 해제 → 순환 재개.
- 포커스는 명시적 의도이므로 포커스만으로도 열린다(호버와 다르다).
- 열림이 **지속 상태**이므로 스크린리더 사용자가 읽는 도중 사라지지 않는다. 호버 프리뷰가 못 하는 것이다.

## 모바일 / 리듀스드 모션
- ≤760px: **세로 스택**으로 바뀐다(닫힘 12vh / 열림 54vh). 가로 4칸은 작은 화면에서 죽는다.
- 자동 순환은 모바일에서도 **그대로 살아 있다** — 터치 사용자가 아무것도 안 해도 4장을 다 본다.
- 탭 = 클릭 = 고정. 호버가 없어도 잃는 것이 없다.
- `prefers-reduced-motion: reduce` → **② 완성 상태로 스냅.** 자동 순환을 끄고(첫 패널 열림 유지) 트랜지션을 0.001s 로. 상태 전환과 클릭·키보드는 전부 남는다.

## 이미지 슬롯
`.fx-pex__ph` 색면 → `<img src="…" alt="">`. 열린 패널이 화면의 절반 이상을 차지하므로
**1200px 이상 원본**을 쓴다. 닫힌 패널도 같은 이미지를 쓰되 `object-fit: cover` 로 잘린다 —
인물·중앙 피사체 컷이 유리하다.

## 검증 (헤드리스 크로미움 1440×900, 2026-09-04)
- 콘솔 에러 **0** · 가로 오버플로 **0px**
- 입력 0 상태로 5.6초 → 열린 패널 index **0 → 1** (자동 순환 확인)
- 열린 패널 폭 = 행의 **62.7%**, 높이 **68vh**
- 4번 패널 클릭 → `is-pinned` 부착, index 3 고정. **5.6초 더 기다려도 index 3 유지**(고정 확인)
- `prefers-reduced-motion: reduce` → 5.6초 동안 index **0 유지**(순환 정지), 에러 0, 클릭 고정은 정상 동작
- 스크린샷: `preview.jpg`
