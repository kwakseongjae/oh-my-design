# inertia-drag-gallery — 관성은 세 줄, 경계가 아홉 줄

| | |
|---|---|
| 계열 | 드래그 · 관성 |
| CSS-only | 아니오 — JS 50줄 |
| 인라인 크기 | CSS 30줄 + JS 50줄 / 약 2.6KB |
| 다크/라이트 | 둘 다 |
| 라이선스 | 이 구현은 oh-my-design 자작, MIT. 외부 의존 0 |
| 난이도 | 중 |

## 핵심 — GSAP Draggable + InertiaPlugin 을 대체하는 지점
관성 자체는 세 줄이다: `x += v; v *= friction;` 그리고 `|v| < ε` 이면 정지.
진짜 일은 **경계**에 있다.
- 범위 밖에서 드래그하면 **절반만 따라온다**(`dx * 0.42`). 저항이 느껴져야 사람은 "끝"을 안다.
- 손을 놓으면 속도를 버리고 `x += (한계 - x) * 0.32` 로 되돌아온다. 고무줄이다.
- 이 두 개가 없으면 갤러리가 무한 허공으로 날아가고, 그 순간 싸구려가 된다.

GSAP `Draggable + InertiaPlugin` 은 스냅·스로우 목표 예측·다축까지 준다. **가로 한 축 + 고무 경계**만 필요하면 50줄로 끝난다.

## 속도를 보이게 하는 한 줄
`skew = clamp(-v * 0.035, ±4deg)` — 던지는 동안 카드가 진행 방향으로 눕는다.
운동의 **양**이 아니라 **방향과 세기**가 보여야 물리로 읽힌다. 4deg 를 넘기면 우스워진다.

## 성능 조건
- `will-change: transform` 은 **트랙 1개**에만. 카드 12장에 걸면 레이어 12장이다.
- 카드에 `pointer-events: none` — 드래그 중 이미지 고스트와 텍스트 선택을 막는다.
- 카드의 `rotate` 는 트랜지션(0.5s)으로 따라오게 해 프레임마다 쓰지 않아도 부드럽다.
- 아이템 20장 초과 시 양 끝 밖 카드에 `content-visibility: auto` 를 검토한다.

## 금기
- **`touch-action` 을 지우지 않는다.** 지우면 모바일에서 세로 스크롤이 잠겨 페이지가 갇힌다.
- `wheel` 을 무조건 `preventDefault` 하지 않는다. `|deltaX| > |deltaY|` 일 때만 가로챈다 — 아니면 세로 스크롤을 훔친다.
- 마찰 0.97 초과 금지. 영원히 미끄러져 멈추지 않는다. 0.90~0.95.
- 여기에 스크롤 핀(horizontal pin)을 겹치지 않는다. 같은 축을 두 주체가 다투면 둘 다 고장난다. **가로 스크롤 안무와 배타 관계.**

## 모바일 / 리듀스드 모션
- `prefers-reduced-motion` → **마운트하지 않고** `overflow-x: auto` 로 네이티브 스크롤에 넘긴다. 기능은 100% 남고 관성만 사라진다. 이 폴백이 있어서 JS 실패 시에도 안전하다.
- `mask-image` 로 양 끝을 녹여 "더 있다"를 알린다 — 스크롤바 없는 가로 영역의 필수 어포던스.
