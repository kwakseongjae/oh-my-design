# stack-fan-hover — "팟" 은 이징에서 온다

| | |
|---|---|
| 계열 | 호버 · 깊이 |
| CSS-only | ✅ 예 — JS 0줄 |
| 인라인 크기 | CSS 40줄 / 약 1.2KB |
| 다크/라이트 | 둘 다 — 형태 효과 |
| 라이선스 | 이 구현은 oh-my-design 자작, MIT |
| 난이도 | 하 |

## 핵심 — 세 가지가 전부다
1. **`display:grid` + 전원 `grid-area: 1/1`** — 겹치기에 `position:absolute` 가 필요 없다. 부모가 알아서 가장 큰 카드에 맞춰 커진다.
2. **`transform-origin: 50% 118%`** — 회전축을 카드 **아래 바깥**에 둔다. 손에 쥔 카드 다발이 펴지는 것과 같은 축이다. 축이 중앙(50% 50%)이면 부채가 아니라 바람개비가 된다.
3. **`cubic-bezier(.2,1.28,.34,1)`** — 1 을 살짝 넘었다가 붙는다. 이 오버슛이 곧 "팟" 이다. `linear` 나 `ease-out` 으로 바꾸면 같은 배치인데도 그냥 벌어진다(데모 2번).

`transition-delay: calc(abs(var(--i)) * 26ms)` 로 가운데부터 순서대로 나가면 한 덩어리가 아니라 **펴지는 동작**으로 읽힌다.
`abs()` 는 CSS Values 4 함수다 — 지원이 없으면 `--ai` 를 인라인으로 직접 넣는다.

## 금기
- **spread 를 카드 폭에 가깝게 두지 않는다.** 겹침이 사라지면 부채가 아니라 그냥 나란한 카드다(데모 2번).
- 장당 회전 10deg 초과 금지. 가장자리가 눕는다.
- 호버 뒤에 **정보를 숨기지 않는다.** 펼쳐야만 보이는 텍스트는 터치·키보드 사용자에게 없는 것과 같다.
- 카드 5장 초과 금지. 7장부터는 가운데가 안 보이고 겹침 그림자가 탁해진다.
- 그리드에 여러 개를 늘어놓고 전부 호버 가능하게 두지 않는다. 마우스가 지나가는 궤적마다 폭발이 일어난다.

## 성능 조건
- `will-change: transform` 은 카드에만. 5장 = 레이어 5장, 이 정도가 상한이다.
- 그림자 두 개(닫힘/펼침)를 트랜지션하므로 페인트가 있다. 큰 blur(60px 초과)는 피한다.

## 모바일 / 리듀스드 모션
- `@media (hover:none)` 에서 **58% 펼친 상태를 기본**으로 준다. 터치 기기에서 닫힌 더미로 방치하지 않는다.
- `prefers-reduced-motion` → 트랜지션 사실상 제거(0.001s). 상태 변화는 남는다.
- `:focus-within` 을 `:hover` 와 같이 걸어 키보드로도 펼쳐진다.
