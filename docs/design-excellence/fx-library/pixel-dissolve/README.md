# pixel-dissolve — 격자가 흩어지며 드러나는 층

| | |
|---|---|
| 계열 | 이미지 리빌 |
| CSS-only | 애니메이션은 CSS-only. 격자 칸 생성 + 무작위 순서에 JS 10줄 |
| 인라인 크기 | CSS 14줄 + JS 10줄 / 약 1.1KB |
| 다크/라이트 | 둘 다 — **덮개 색을 배경색과 같게 맞춰야 한다** (`--fx-diss-color`) |
| 라이선스 | 이 구현은 oh-my-design 자작, MIT |
| 난이도 | 중 |

## 무엇인가
아래 층(이미지·비디오·콘텐츠) 위에 배경색과 같은 색의 격자 덮개를 깔고,
각 칸을 무작위 순서로 축소+페이드시켜 없앤다. 결과적으로 "픽셀이 흩어지며 드러나는" 인상이 된다.

## 왜 이게 좋은가
페이드-인은 정보를 주지 않지만, 디졸브는 **아래에 무언가 있었다**는 사실을 알려준다.
생성·복원·해독·로딩 완료 서사에 자연스럽게 붙는다.

## 언제 쓰나
- 결과물이 "만들어졌다"는 것을 보여야 할 때
- 히어로 최초 진입 1회 (페이지당 1회 권장)
- 비포/애프터 전환

## 금기
- **격자 칸 수를 200개 이상으로 늘리지 않는다.** 14×8=112 가 현실적 상한. 넘어가면 저사양에서 프레임이 떨어진다.
- stagger 총합이 1.2초를 넘으면 사용자가 기다린다. `cols*rows*stagger` 를 계산해 두고 잡는다.
- 페이지당 2회 이상 = "로딩이 계속되는 사이트"로 읽힌다.
- 덮개 색이 배경과 1px이라도 다르면 경계가 드러나 조악해진다.
- `prefers-reduced-motion` 에서 격자를 통째로 `display:none` — 반쯤 덮인 채 멈추면 안 된다.

## 파라미터
`--fx-diss-cols`, `--fx-diss-rows`, `--fx-diss-color`, `--fx-diss-cell`(칸 지속), `--fx-diss-stagger`, `--fx-diss-scale`
