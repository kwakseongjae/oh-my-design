# poster-cylinder — 스크롤하지 않아도 도는 원통

| | |
|---|---|
| 계열 | 유휴(idle) · 3D |
| CSS-only | 폴백은 예 (CSS 회전) — 드래그·관성·명암은 JS 62줄 |
| 인라인 크기 | CSS 42줄 + JS 62줄 / 약 3.2KB |
| 다크/라이트 | 둘 다 — 형태 효과. 라이트에서는 그림자 알파를 낮춘다 |
| 라이선스 | 이 구현은 oh-my-design 자작, MIT. 외부 의존 0 |
| 난이도 | 중 |

## 핵심 — 원통은 `translateZ` 하나로 만들어진다
N 장을 `rotateY(i · 360/N) translateZ(r)` 로 배치하면 그것이 곧 원통 벽이다.
부모를 `rotateY` 로 돌리면 전체가 회전한다. **WebGL 도 캔버스도 필요 없다.**

세 층이 겹쳐 "살아 있음"을 만든다:
1. **자동 회전** — 스크롤 0, 입력 0 에서도 움직인다. 이것이 r2 에 없던 것.
2. **드래그 + 관성** — 잡아끌면 따라오고, 놓으면 흐르다 기본 속도로 **수렴**한다(정지가 아니라).
3. **면 명암** — `cos(각)` 으로 `brightness` 를 주어야 원통으로 읽힌다. 이게 없으면 그냥 흩어진 카드다.

## 성능 조건
- `will-change` 는 **스테이지 1개에만**. 면 12개에 걸면 레이어 12장이 되어 합성이 무너진다.
- `backface-visibility: hidden` — 뒷면을 그리지 않아 픽셀 비용이 절반이다.
- `IntersectionObserver` 로 화면 밖에서는 rAF 를 끈다. 유휴 효과가 배터리를 먹으면 안 된다.
- 12장 / 250px 기준 60fps. 24장을 넘기면 `content-visibility` 를 따로 검토한다.

## 금기
- **반지름 < 포스터 폭 × 2 금지.** 곡률이 과해 멀미가 난다. 데모 2번이 그 예다.
- 자동 속도 10deg/s 초과 금지(1회전 36초 미만). 읽을 수 없는 회전은 장식이 아니라 소음이다.
- 원통 안에 **읽어야 하는 본문**을 넣지 않는다. 포스터·썸네일·표지만.
- 같은 섹션에 스크롤 스크럽을 겹치지 않는다 — 유휴 동사 1 + 스크롤 동사 1 규칙.
- `touch-action` 을 지우지 않는다. 지우면 모바일에서 세로 스크롤이 잠긴다.

## 모바일 / 리듀스드 모션
- 모바일: `touch-action: pan-y` 로 세로 스크롤을 페이지에 양보하고 가로 드래그만 가져간다.
- `prefers-reduced-motion: reduce` → 자동 회전 정지(CSS·JS 양쪽). **정지한 원통도 구도로 성립**하므로 요소를 숨기지 않는다. 드래그는 살아 있다.
- 호버 불가 기기에서는 감속 리스너를 붙이지 않는다.

## 이미지 슬롯
데모는 `--h` 로 색상만 바꾼 **플레이스홀더 색면**을 쓴다. 실사용:
```html
<div class="fx-cyl__face" style="--i:0"><img src="<poster>.png" alt=""></div>
```
Higgsgen 에서는 `test-v2/content-runs/aphrodite/higgsgen/assets/<id>.png` 12장.
