## 2. 셀프 피드백 루프 배선 (하네스 레벨 지원 진단 반영)

현재 지원: `omd:autopilot` iteration(상한 3)+critic, `omd:orchestrator` 2라운드 상한.
**미배선이던 것** — 자평 검사 체인을 다음으로 고정한다:

```
생성 → ① render-integrity.mjs (결정론: overflow/escape/ua-default/font/img)
     → ② omd:slop-audit (rule ID 기반, route 증거)
     → ③ omd:designer-review (브랜드 일관성, BLOCK만 집계)
     → FAIL 항목만 지목해 재생성 (전면 재생성 금지) → ①부터 재검
루프 상한: 3회. 2회 연속 같은 rule ID FAIL이면 중단하고 그 rule을 이슈로 등록
           (탐지가 두 번 놓치면 예방 층으로 — T2에서 확립한 층 이동 원칙).
```

수렴 측정: 회차별 (①결함 수, ②rule hit 수, ③BLOCK 수)를 `loop-trace.json`에 기록.
**이 수치가 줄지 않으면 하네스가 아니라 검사가 문제**라는 판정 기준까지 포함.

## 3. 무인 자동 선택 정책

`omd:autopilot`의 "최대 1회 질문 배치"가 무인 실행을 끊는다. 정책:

- 질문이 발생하면 **각 질문의 첫 번째(권장) 선택지를 자동 선택**하고, 질문 원문과 선택을
  `loop-trace.json`의 `autoSelected[]`에 기록한다 — 선택이 사후 감사 가능해야 한다.
- 파괴적 선택지(기존 파일 삭제·덮어쓰기)는 자동 선택 금지 — 해당 과제는 FAIL로 기록하고
  다음 과제로 진행.
- 구현은 autopilot 스킬에 `unattended` 모드 절 추가로 — 이슈로 접수(#아래).
