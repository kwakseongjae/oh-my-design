> 발단: Higgsgen r3 60/100 (r2 70 에서 하락). 사용자: "이미지를 소극적인 사이즈로 쓰는 것, 매번 호버를 해야 펼쳐지고 돌아오는 애니메이션, 화려함 속에 숨어 있는 간결함과 시원시원함이 반영되지 않았다. 사용자의 UX 관점이 부족하다."

## 0. 한 문장

**스펙터클은 사용자가 노동해서 얻는 것이 아니라 가만히 있어도 도착하는 것이고, 시원시원함은 큰 것 하나 + 경쟁 없음 + 큰 숨 + 노동 없음이다.** (레인 B §4.4)

## 2. 장식과 관문을 가르는 4가지 시험 (레인 B §3 — 문헌 모순의 해소)

Nielsen(2013)·Baymard(2019)의 "자동 회전 유해"와 우리의 "유휴 스펙터클 필요"는 같은 층의 진술이 아니다. 문헌이 공격하는 것은 **움직임이 정보 접근의 유일한 경로**인 상태다.

| 시험 | 장식(OK) | 콘텐츠 관문(NG) |
|---|---|---|
| T1 정보 유일성 | 같은 종류의 반복 샘플. 하나를 못 봐도 손실 없음 | 항목마다 고유한 사실·기능·CTA |
| T2 대체 경로 | 같은 콘텐츠에 정적 경로가 있다 | 그 연출이 유일한 경로 |
| T3 사용자 제어 | 호버·포커스로 감속·정지, reduced-motion 정지 | 통제 불가 |
| T4 노동 요구 | 가만히 있어도 도착 | 호버·드래그를 반복해야 보임 |

**한 문장**: 움직임이 "무엇을 볼 수 있는가"를 바꾸면 관문(NG), "얼마나 아름다운가"만 바꾸면 장식(OK).

## 5. 레퍼런스 실측 (레인 A, `rx4-a-scale-probe.md`) — 임계값 확정

측정 가능한 레퍼런스 11곳(tasteskill·open-design·affinity·higgsfield·krea·runway·luma·midjourney·apple-iphone·framer·cosmos·linear; lusion·igloo 는 커스텀 스크롤러라 제외), 1440×900, 앞 10화면. **박스가 아니라 히트테스트 커버리지**(24×15 격자에서 실제로 먼저 칠해지는 요소가 미디어인 비율)가 주 지표다 — r3 폴드는 박스로는 100% 인데 커버리지는 6.9% 였다.

| 지표 | 레퍼런스 중앙값 | IQR | r3 | r2 | 판정 |
|---|---|---|---|---|---|
| **폴드 커버리지 %** | **33.6** | 20.6–46.7 | **6.9** | 13.3 | r3 하위 2위 — 폴드에 이미지가 없다 |
| **지배도(1위/2위 미디어 박스)** | **2.1** | 1.0–3.5 | **1.1** | 1.1 | 균등 격자 — 지배 요소 부재 |
| 폴드 최대 서체 px | 54 | 40–72 (최대 affinity 112) | 93.6 | 113.8 | 148 은 어디에도 없다 → 112 상한 |
| 본문 화면 최대 서체 중앙 px | 48 | 40–56 | **44** | 48 | r3 후퇴 |
| 폴드 말단 요소 수 | 29 | 25–49 (최소 14) | 25 | 18 | ≤5 인 사이트 0 — 의미 단위(LI-37)와 다른 정의 |
| 유휴 애니 중앙 | 2 | 0.5–8 | 9 | 5 | **불변량 아님** — r3 는 늘리고 점수 하락 |
| **호버 관문 요소** | **0** | 0–0 | 0 | 0 | 전 사이트 0 — 절대 불변량 |

r2→r3 회귀가 점수(70→60)와 같은 방향: 폴드 커버리지 13.3→6.9, h1 113.8→93.6, 최대 서체 48→44, 호버로 상태가 바뀐 요소 0→50, 유휴 5→9. **r3 는 유휴 스펙터클을 늘리고 이미지·서체 스케일을 줄였다.**

### 확정 임계값 (검사기 반영)
- **LI-34 주 미디어**: 폴드 **히트테스트 커버리지 ≥ 25%**(q1 20.6, 목표 ≥35) — 박스 기준 "≥45vw/40vh" 는 r3 를 통과시켜 **기각**. 섹션 박스 점유율 중앙 ≥0.35 는 r3(0.10)·r2(0.59) 를 가르므로 유지. 페이지 풀블리드 ≥1 유지.
- **LI-36 초점비 ≥2.0** 확정(지배도 중앙 2.1, tasteskill 8.7·cosmos 6.0·luma 3.5 vs r3 1.1).
- **LI-35 호버 관문 0** 확정. 단 r3 도 관문은 0 이었고 사용자 불만은 **호버 변화량(50)** 에서 왔다 → LC-49 의 상한(리프트 12px·확대 .04·회전 2°·투명도 .25)을 넘는 층을 관문과 같이 FAIL 로 센다(구현됨: r3 `#cross` 32px).
- **LI-7 활자**: 폴드 h1 **≥ 72px**(레퍼런스 q3 72, wow 군 affinity 112·cosmos 74·tasteskill 72) **이면서 ≤ 7.5× body**(112 상한). 본문 화면 최대 서체 중앙 ≥48 은 LC-57(디스플레이 급 ≥3 섹션)로 대신한다.
- **LI-37 폴드 의미 단위 ≤5** 는 문헌 규칙(Nielsen)이고 레퍼런스 말단 요소 기준으로는 ≤25(q1) 가 실측치다 — 두 정의를 병기하고, 검사기는 의미 단위(r4 5·r3 19)를 쓴다.
- **LC-53 유휴 상한**: 화면당 유휴 애니 요소 **≤10**, 폴드 무한 애니 ≤3. 유휴를 늘려 스케일 부족을 보상하지 않는다.

## 6. 스토리보드 게이트 개정 (`storyboard-review.md` v2)

- **C1 개정**: 섹션당 **2층 상한**(스크롤·유휴·호버·진입 중 2). 같은 주효과 연속 금지 유지.
- **C8 폐기 → C8′**: "호버 팟 ≥1" 요구 삭제. 대신 **유휴 층 ≥1(히어로) 이 T1~T4 통과**, 호버는 강화만(LC-49), 열림은 지속(LC-50).
- **C9 크기 락**: 섹션마다 주 미디어의 **비율(16:9/3:2/2:3)과 뷰포트 점유율(%)** 을 숫자로 적는다(refero Media lock). 구현이 락에서 벗어나면 멈춘다.
- **C10 정직한 K**: C7 의 정착 K 는 구현 값으로 재확인해 적는다(r3 선언 52/65/70/60 vs 구현 38/50/55/42).
- **D 표 신설 — 사용자**: 섹션마다 ① 입력 없이 보이는 것 ② 터치(`hover:none`)에서 남는 것 ③ 키보드 도달 ④ 첫 5초에 읽히는 문장 ⑤ 관문이 되는 입력(0 이어야 PASS).
- **E 자기 표절 시험**: "이 스토리보드가 비슷한 브리프에도 그대로 나올 것 같은 부분"을 지목하고 무엇을 왜 바꿨는지 한 줄(frontend-design).
- **첫 줄 다이얼**: 밀도·모션 1–10 선언(LC-59).

## 7. 프로세스 개정 (`skills/omd-aphrodite/SKILL.md`)

1. **눈 검사 격리**: designer-review 는 검사기 결과를 보지 않은 채 렌더만 보고 먼저 판단하고, 기계 결과는 그 뒤에 붙인다(impeccable P4). r3 는 LI 전항목 ok·BLOCK 0 인데 60점이었다.
2. **페르소나 워크스루 3인**: 데스크탑 마우스 · 한 손 엄지 모바일 · 키보드/호버 없음. 각자 "입력 없이 무엇을 봤는가, 관문에 막힌 곳"을 보고(impeccable P2). `omd-persona-tester` 재사용, 지표는 task_success·friction_count 만.
3. **빌드 중 스크린샷 자기 비평**을 trace 에 기록(frontend-design P6).
4. fx-library 스니펫의 반경·간격 기본값은 **DESIGN 토큰으로 치환**한 뒤 인라인(r3 반경 토큰 밖 43건).
5. 라운드 상한 유지(≤3), 데스크탑·모바일을 한 라운드에 묶는다(P7).

## 8. r4 적용 방향 (Higgsgen, 이미지셋 61장 동일, 비용 0)

- 밀도 다이얼 **4**, 모션 **7**. 섹션 11 → **9**. 핀 ≤ 4. 호버 관문 3 → **0**. 동시 미디어 최대 22 → **≤6**.
- S0 진입 커튼 삭제(LC-54). S1 히어로 = 16:9 풀블리드 100vh + 느린 켄번즈(장식, T1~T4 ✓) + 정착 뒤 홀드에 서브헤드.
- S2 장르 = `wide-drum` 전폭 띠(타일 56vh, 자동 흐름, 호버 정지, 드래그). 스택 팬 삭제.
- S3 시퀀스 핀 = 프레임 풀블리드, 캡션 스크램블 삭제(스왑만), 정착 55% + 홀드에 캡션.
