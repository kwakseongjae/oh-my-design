# 스토리보드 리뷰 게이트 (빌드 전) — v1 2026-09-04 (액센트 실측 반영)

> 빌드 뒤 리뷰는 늦다. 60점 라운드의 지적("포인트 컬러·미감이 아쉽다, 스크립트·구도 설정 때 피드백이 있어야")을 받아
> **스토리보드/컨셉 단계에서** 아래를 통과해야 빌드에 들어간다. 업종 무관 — 특정 색이 아니라 **역할·빈도·숫자**로 말한다.
> 수치 근거: r1 리뷰 실측 + 스크롤 안무 규칙(R-A~R-F) + 10개 사이트 액센트 실측(accent-probe, 2026-09-04: 첫 뷰포트 액센트 요소 중앙값 0·9/10 ≤3, 면적 ≤2.82%, CTA 가 최다 위치 10/10, 명도 반전 0~4).

## A. 색
| # | 항목 | PASS 기준 |
|---|---|---|
| A1 | 액센트 역할표 | 액센트가 등장하는 **사건**을 목록으로 적는다(CTA·선택 상태·진행·포커스·데이터 하이라이트 중 택). 목록 밖 사용 0 |
| A2 | 첫 뷰포트 액센트 개수 | **≤ 3 요소, 면적 ≤ 3%** (실측 9/10 ≤3 · 최대 2.82%; r1 은 7 — CTA 가 이기지 못했다) |
| A3 | 액센트 전략 선언 | **절제형**(면 ≤1, 선·CTA 만) 또는 **전면형**(면 ≥7, stripe·affinity·higgsfield) 중 하나를 선언 — 섞으면 FAIL. 절제형이면 면 사용 위치 1곳 명시 |
| A4 | 라벨·태그의 액센트 | 섹션 태그·캡션에 액센트 금지(중성 색 + 자간으로 위계) |
| A5 | 명도 밴드 계획 | 배경 명도 반전 **2~4회**(실측 0~4; 반전은 리듬 장치), 어느 섹션에서 뒤집히는지 표에 명시 |
| A6 | 중성 단계 | 텍스트 중성 3단계 이하(ink · mute · line), 임의 회색 추가 금지 |

## B. 구도
| # | 항목 | PASS 기준 |
|---|---|---|
| B1 | 섹션별 텍스트-이미지 관계 | 겹침 / 나란히 / 관통 중 하나를 섹션마다 명시. "그 위에" 만 있으면 FAIL |
| B2 | 시선 축 | 히어로 헤드라인 상단 1/3, 피사체와 헤드라인이 **다른 1/3** 을 차지 |
| B3 | 피크 | 압도 지점 **정확히 1개** + 직전 호흡 섹션 1개 |
| B4 | 리듬 | 섹션별 잉크 비율 계획(숫자) — 3연속 같은 밀도 금지 |
| B5 | 여백 방향 | 섹션마다 큰 여백이 어느 쪽인지(상·하·좌·우) 명시, 전 섹션 동일 금지 |

## C. 효과
| # | 항목 | PASS 기준 |
|---|---|---|
| C1 | 섹션당 효과 | **주효과 1 + 보조 1** 이하. 같은 주효과가 연속 섹션에 오지 않는다 |
| C2 | 페이지 효과 예산 | 효과 종류 **≤ 7**, 라이브러리 인라인 **≤ 120KB** |
| C3 | 핀 구간 | **≤ 4** (전부 핀이면 2000vh 초과 — 실측) |
| C4 | 이미지의 행동 | 각 이미지에 동사 1개(줌·회전·펼침·가로 이동·크로스페이드·마스크·정지) — "정지" 가 60% 초과면 FAIL |
| C5 | 텍스트 마스크용 이미지 | 글자 모양이 살아남는 텍스처(매크로·균질)만 — near-dark 프레임 금지(R-A 실측) |
| C6 | 리듀스드 모션 | 전 효과의 정지 상태를 스토리보드에 한 줄로 |
