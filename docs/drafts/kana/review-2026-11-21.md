# /kana — model review, 2026-11-21

The owner decided on 2026-11-21 that there is no native reviewer and that the model reviews the skill instead (「검토자는 없어 자체 검토해」). This file is that review for the writing half. It was done by Claude Fable 5.2 in the main session, with scripts where a script can decide. **No native Japanese reader has read these rules, and this review does not replace one**: it checks that the Japanese in the files is what the sources wrote, not that a Japanese reader would find the rules right.

| Check | Method | Result |

## The quotes that were not found

- **One real difference.** `writing/rules.md` UW-19 quotes DADS as 「デスクトップデバイスでは、ボタン配置を、…」. The page says 「デスクトップデバイスにおけるボタン配置を、…」. The fetch tool changed two words. `verdicts.md`, `references/writing-rules.md` (KW-19) and the published page already carry the page's wording; only the research file has the wrong one.
- **Markdown only** (most of the rest): SmartHR and Ubie strings where the research file added backticks, an asterisk or a `<br />`, or elided the start with ….
- **Templates, not quotes:** 「〜してください」, 「ご〇〇ください」, 「〜しました。」 and the like in headings.
- **Illustrations marked "ours, unreviewed"** in `writing/rules.md` (UW-02 and UW-07). None is in `references/writing-rules.md`, in a fixture or on the page.
- **Microsoft table cells** that wrap in the extract (second pass), which the text layer cannot confirm in one piece.
- Before the check read image alt text, ten DADS example strings (the ＊ error texts, the sample dialog and banner) showed as not found. They are in the alt text of DADS's screenshots, word for word.

## What was not checked

- Whether a Japanese reader would agree with any rule, with the wording of a rule in English, or with the choice of which rules lead.
- The typography half (`references/rules.md`, JW rules) beyond removing composed examples; the strings in the typography checker's fixtures (`scripts/lang/fixtures/kana/`), which are test input and not skill text.
- English-language quotes and quotes shorter than four characters (the byte check does not read them).
- The Korean one-line readings on `/ko/kana` were read against the English rules by the model on the same day; they are restatements of ours, not quotes, and nobody else has read them.
- The PDF of the Microsoft guide as an image. Only its text layer was read.
