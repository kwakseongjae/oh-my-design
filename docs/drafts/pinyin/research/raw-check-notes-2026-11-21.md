# /pinyin research — notes on the raw quote check (2026-11-21)

`raw-check-2026-11-21.md` is generated by `scripts/lang/check-quotes-raw.mjs`. This file records how the main session read its non-"web" rows. It is not a second read; `verdicts.md` is. No native reader from the Mainland has seen it.

418 quotes: web 355, extract 29 (the Microsoft PDF extract: characters confirmed, spaces not), stripped 4, cells 14, none 16. One source is marked superseded (CLREQ-2020); no quote rests on it alone.

- **Spacing pairs are confirmed.** CN-57 (「90°」 against 「90 °」, 「15%」 against 「15 %」) and CN-60 (a space or none around a link) are in the WordPress China page bytes exactly as quoted, spaces included. Each pair is two lines joined across a `<br>`, which the check treats as no difference.
- **stripped, 4.** Element Plus (CN-09, CN-15): the page has a space after the bold label, 「清晰明确： 语言表达…」, and the quote has none. Ant (CN-50, CN-54): a table row and a code span rewritten in Markdown. No spacing rule rests on these four.
- **cells, 14.** Table rows the researcher wrote with `|` between cells (CN-08, 16, 17, 18, 56). Every cell of four or more characters is on the page; the row as written is an assembly.
- **none, 16.** Six are Microsoft examples that are not in the extract in one piece (CN-01, 03, 24, 26, 38, 44); in the Taiwan guide the same pattern was wrapped table cells, but these six were not looked at. Nine are short pairs written by the researcher with `/` or `|` (「登录 / 登陆」, 「模板 / 模版」, 「阈值 / 阀值」, 「新建 / 新增」 and the like, CN-01, 08, 16, 17): the cells are under four characters, so the check does not test them. One (CN-59) carries Markdown backticks. None of the 16 was checked against the page by hand.
- **Sources the raw fetch did not get:** GOV-LAW and both moe.gov.cn standard pages (404), Apple's style guide URL (404). No candidate cites any of them. `verdicts.md` says every cited URL opened; that holds for cited sources. TERMONLINE, ARCO and Apple's zh-CN page are client-rendered and returned almost no text; The Arco docs page is not cited; its font stack was read from a CSS file in its repository (ARCO-css).
- **Not tested at all:** English-language quotes (the W3C translation of GB/T 15834 Part 5 shows 0 for that reason), single marks, and any quote under four characters.
