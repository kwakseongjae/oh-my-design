# Mainland Chinese rule candidates: second-read verdicts (2026-11-21)

How this was checked. The Microsoft guide was read from the local pdftotext extract and W3C CLREQ from the local text dump (clreq-2026-11-21.txt); quotes from those two were checked as substrings, and code points read directly. Every other cited page was opened again today, but this session had only the WebFetch extractor (no raw fetch), so those quotes were confirmed by blind section-by-section re-extraction and matching, not against page bytes. For those pages full-width versus half-width cannot be told reliably and is said so where a rule depends on it. All cited URLs opened (HTTP 200); none was unreachable. GB/T 15834 and 15835 Chinese texts remain unread; the U+ code points on the W3C Part 5 translation page are that page's annotations (CLREQ says the standard gives none for connector marks).

One voice counted twice: WordPress China and Teambition 中西文混排 share headings and example sentences (「…好开心！」, 「Stay hungry, stay foolish.」, the Hackers & Painters line, the front-end developer sentence). Where both are counted (CN-39, CN-47, CN-57, CN-59) treat them as one source. They do disagree in CN-44.
