# /zhuyin research — second-reader verdicts (2026-11-21)

Second read of the 55 candidates in `rules.md`. No native reader from Taiwan has reviewed this file. Rules were not repaired and none were added.

## How each source was checked

- **MS** (and the MS-S contrast): read from the local pdftotext extracts. Every MS quote was looked up as a whitespace-stripped substring and read in context on its page; code points named below come from the extract. Bold and italic are lost in the extract, and wrapped table cells were read across lines.
- **Web sources** (MZ, MZ-mkt, WP, L10NTW, MOE appendix pages 1-7, CLDR JSON, CLREQ current / 2017 / 2020 / zh editor's draft, CLREQ font mapping, TIPO): opened at the cited URL on 2026-11-21 through the fetch tool, which passes the page to an extraction model. Passages were asked for by heading and topic, not by pasting the candidate's quote, and compared with rules.md. **Glyph width, code points and spaces in web quotes cannot be told reliably this way**; a verdict relies on width only where the page names it in words (半形/全形) or names the code point (MZ U+2026; CLREQ U+25CF, U+2022; CLREQ-zhED U+0020).
- **Reachability:** every cited URL opened. The current CLREQ copy stops inside 5.5.4, so section 6 and the appendices were not seen (as gaps.md says); the candidates cite the superseded editor's draft for those topics, and that draft was read in full.
- **Conventions:** "supported" means the passage is there and says what the candidate says, at the strength the candidate gives (including an n/3 count). A candidate marked DISAGREE is "supported" when both sides are on their pages as described; it still gives no single rule. A passage that names only 繁體中文, or no region, in a superseded draft is "weaker than stated".
