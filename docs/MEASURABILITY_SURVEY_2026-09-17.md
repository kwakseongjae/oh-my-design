# 카탈로그의 90%는 다시 잴 수 있다 (2026-09-17)

수요 상위 10개를 끝까지 해보니 4개 개선 / 1개 확인 / **5개 차단**이었다. 그 비율이 440
리뉴얼의 천장처럼 보였고, 나는 "브랜드가 발행하는 방식 때문에 막힌다"고 적었다.
**표본으로 재보니 틀렸다.** 상위 10개가 비대표 표본이었고, 내 도구가 약했다.

## 측정

`web/scripts/survey-measurability.mjs` (`--sample N --seed S`, 결정적 표본).
레퍼런스마다 다시 잴 만한 표면을 최대 3개까지 열어 분류한다.

| 분류 | 뜻 |
|---|---|
| `renders` | 컨트롤이 DOM에 있다 → 상태 측정 가능 |
| `images-only` | 컨트롤 없이 이미지뿐 (`line` 유형) |
| `index-only` | 본문만 있고 컴포넌트가 없다 (`yeogiotte` 유형) |
| `blocked` | HTTP 4xx/5xx |

## 세 번 재고 두 번 틀렸다

| 분류기 | renders |
|---|---:|
| 1차 — 레퍼런스당 URL 1개, 유채색 컨트롤만 | **33%** |
| 2차 — 표면 3개까지 시도, 테두리 있는 흰/회색 컨트롤도 인정 | **77%** |
| 3차 — 실제 브라우저 신원 | **90%** |

1차가 틀린 이유 둘. **(a)** URL을 하나만 봤다 — `naver`가 `images-only`로 나왔는데
고른 URL이 navercorp 브랜드 페이지였고, 실제로는 검색결과에서 컨트롤을 측정했다.
**(b)** 유채색만 셌다 — `29cm`의 `ghost-outline`은 흰 배경에 회색 테두리라 애초에 안 잡힌다.

2차 → 3차가 가장 크다. **막힌 10개 중 8개가 헤드리스 탐지였다.**

```
panasonic  cgv  sony  inflearn  yanolja  china-airlines  baemin  wanted
   HTTP 403  →  200, 컨트롤 렌더
```

user-agent와 언어 헤더를 붙이고 자동화 플래그를 끈 것뿐이다. 우회가 아니라 **공개 페이지를
사람의 브라우저와 같은 조건으로 받는 것**이다. 로그인·유료 장벽·접근 제어는 넘지 않으며,
그런 표면은 애초에 이 카탈로그의 증거가 아니다.

## 60개 표본 결과 (seed 23)

| 분류 | 건수 | 비율 |
|---|---:|---:|
| **renders** | 54 | **90%** |
| images-only | 3 | 5% |
| blocked | 2 | 3% |
| index-only | 1 | 2% |

남은 6개: `figma` `tving` `kakaogames`(이미지) · `tesla` `coupang`(403 유지) ·
`remember`(색인).

## 상위 10개가 왜 나빠 보였나

그 코호트에 이미지 문서 브랜드가 몰려 있었다(`line` `kakao`) — 그리고 `baemin`을
"403 차단"으로 기록한 것은 **내 잘못이었다.** 실제 신원으로는 열리고, 다시 재보니
`woowa-more-light`가 문서 값과 전부 일치했다(상태 색 변화는 없음). 해당 기록은 정정했다.

## 그래서 바뀌는 것

- 천장은 **50%가 아니라 90%**다. 440 리뉴얼은 기술적으로 막혀 있지 않다.
- 진짜 제약은 발행 방식이 아니라 **레퍼런스당 사람 시간**이다. 상위 10개에서 측정 가능한
  것들은 각각 15~25분이 들었다.
- `blocked`를 "불가능"으로 읽으면 안 된다. 3분의 2가 도구 문제였다.

**주의 — 이건 측정 가능성이지 품질이 아니다.** `renders`는 "상태를 잴 수 있다"는 뜻이지
"좋은 레퍼런스"라는 뜻이 아니고, 실제로 재보면 `naver`·`baemin`처럼 **색이 안 변하는 것도
많다**. 그것도 결과이고 부재로 기록한다.
