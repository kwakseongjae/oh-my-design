# Fieldnote plate review

Use a restrained laboratory-workbench visual language: warm paper background `#F3F1EA`, near-white work surface `#FCFBF7`, dark green ink/action `#173F3A`, orange exception accent `#D96A3A`, border `#A9B2AC`, muted text `#66716C`. Body uses Arial; display headings use Georgia. Cards are square (`0px`); controls use `2px`. Preserve dense evidence and spatial order without ornamental dashboards, gradients, glass, pills, or invented status claims.
