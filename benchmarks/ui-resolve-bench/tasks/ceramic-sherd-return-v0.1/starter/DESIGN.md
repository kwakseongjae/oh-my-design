# Ceramic sherd return review — DESIGN.md

## Visual direction

Quiet ceramic sherd-return ledger. Dense evidence stays legible through explicit grouping, restrained contrast, and compact geometry. This is an operational record, not a promotional dashboard.

## Tokens

- Canvas: `#F2EFEC`
- Surface: `#FFFDFB`
- Ink: `#332D2A`
- Muted text: `#746F6C`
- Border: `#ACA19B`
- Primary action: `#685047`
- Accent: `#655F79`
- Card radius: `5px`
- Control radius: `5px`
- Body: Arial
- Display: Georgia

## Layout

- Preserve the visible relationship between every supplied record and assigned container.
- Keep operational windows separate from the main register.
- Keep evidence, state, and the action distinct in the decision area.
- Narrow layouts may reflow containers, but identifiers and concise relationship evidence remain atomic.

## Content

- State only supplied operational facts.
- Unknown validation and institutional acceptance remain absent.
- Use direct labels and concise status copy.
