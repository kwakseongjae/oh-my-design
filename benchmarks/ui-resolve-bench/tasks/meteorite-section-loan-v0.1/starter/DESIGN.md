# Meteorite Collection — DESIGN.md

## Visual direction

Quiet collection-ledger utility. Dense evidence stays legible through explicit grouping, restrained contrast, and compact square geometry. The interface should feel like a working museum loan register, not a promotional dashboard.

## Tokens

- Canvas: `#EDF2F3`
- Surface: `#FCFEFF`
- Ink: `#172A31`
- Muted text: `#61717A`
- Border: `#98A9B0`
- Primary action: `#185A6B`
- Accent: `#8B5366`
- Card radius: `4px`
- Control radius: `4px`
- Body: Arial
- Display: Georgia

## Layout

- Preserve a visible relationship between each meteorite specimen and its assigned slide cases.
- Keep the laboratory return strip separate from the specimen register.
- Keep evidence, state, and the loan action distinct in the decision area.
- Narrow layouts may reflow containers, but identifiers and concise relationship evidence remain atomic.

## Content

- State only supplied collection facts.
- Unknown scientific validation and institutional acceptance remain absent.
- Use direct operational labels and concise status copy.
