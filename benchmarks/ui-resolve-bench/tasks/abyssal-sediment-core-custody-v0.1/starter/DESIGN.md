# Abyssal Archive — DESIGN.md

## Visual direction

Quiet marine-archive utility. Dense evidence stays legible through explicit grouping, restrained contrast, and compact square geometry. The interface should feel like a working custody ledger, not a promotional dashboard.

## Tokens

- Canvas: `#EDF2F3`
- Surface: `#FCFEFF`
- Ink: `#172A31`
- Muted text: `#61717A`
- Border: `#98A9B0`
- Primary action: `#185A6B`
- Accent: `#8B5366`
- Card radius: `4px`
- Control radius: `4px`
- Body: Arial
- Display: Georgia

## Layout

- Preserve a visible relationship between each sediment core and its assigned archive sleeves.
- Keep the cold-vault intake strip separate from the core register.
- Keep evidence, state, and the release action distinct in the decision area.
- Narrow layouts may reflow containers, but identifiers and concise relationship evidence remain atomic.

## Content

- State only supplied custody facts.
- Unknown scientific validation and institutional acceptance remain absent.
- Use direct operational labels and concise status copy.
