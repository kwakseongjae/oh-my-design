02 — Borrowing guide

From need to neighborly return.

A reservation begins as a request. The library team verifies availability, confirms the handoff, and shares return instructions directly.

  1. Describe the job

    Tell us the tool you have in mind—or the task you are trying to complete—and your preferred timing.

  2. Receive a confirmation

    The library team checks what is actually available and replies with pickup details or another option.

  3. Borrow, then return

    Follow the confirmed handoff and return instructions so the shared shelf is ready for the next neighbor.

i
