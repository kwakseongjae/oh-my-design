How it works

A clear path from project idea to borrowing request.

01

Name the job

Tell the library what you are working on and which kind of tool you need. You can describe the job even if you do not know the exact tool name.

02

Request a window

Share the days that would work for your project. A request starts the conversation; it does not promise that a particular tool is available.

03

Confirm before pickup

The library can follow up with availability, any borrowing terms, and the practical details you need before a pickup is arranged.

Know before you request

Use the form to begin a reservation inquiry. Sending it is not a confirmed reservation, and no payment is taken on this page.

Availability and borrowing fees are not published here.

The library will need to confirm both for the tool and dates you request.

Start your request

Share enough detail for the library to understand your project. This starts an inquiry; availability and terms still need confirmation.

For example, describe the repair, build, or garden task.
