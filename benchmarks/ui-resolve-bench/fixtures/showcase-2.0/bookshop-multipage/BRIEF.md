From scratch, create a four-page website for an independent bookstore-cafe in HTML/CSS/JS (no build step, no network): index.html (home), events.html (event list), event-detail.html (detail of one event), visit.html (location and space). Establish a project-owned design system FIRST and express every page from it: one shared stylesheet, the same navigation on every page with the current page marked, and identical heading, body, and primary-action styling on all four pages. Use the provided images in ./assets/ (give every image explicit dimensions). Aim for a modern editorial aesthetic with restrained micro-transitions behind prefers-reduced-motion. Every internal link must resolve to one of the four pages. All events and people are fictional — label them as sample content; opening hours, prices, and the street address are not published — state that honestly exactly where a visitor would look for each.
