# Benchmark media tools

This guide is infrastructure shared byte-for-byte by every benchmark arm. It is not a product-design skill.

- Read declared task and skill files with `read_file`. Never use an editing tool as a substitute for reading.
- Never write to `.grok/`, `.agents/`, a skill file, a runtime profile, or another cell.
- Use only tools advertised in the current admitted init record. Do not discover or invoke MCP tools.
- A task may choose whether media helps. This guide supplies no subject, style, composition, palette, copy, prompt, or preference.
- When a worker authors a media prompt, preserve its exact bytes in the external browser request and include its SHA-256. The browser operator performs mechanical service only.
- Save declared outputs only in the current cell paths. Do not inspect another cell, browser tab, queue payload, or result.
- If a tool, source, or result is absent, report it as absent. Do not replace it with ambient or global material.
