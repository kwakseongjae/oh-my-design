이웃장터 — 가상의 동네 중고거래 서비스. 이 React + Vite 워크스페이스 안에 프로덕션 수준의 웹 프런트를 완성하라. 사용자는 `npm install && npm run dev`로 확인한다.

`src/data/data.json`이 유일 소스: 매물 30건(각 2컷, 상태 3종: 판매중/예약중/거래완료, 나눔 포함), 판매자 12명(신뢰지수·배지), 동네 6곳, 카테고리 8종, 문의 대화 8건. 이미지는 `/assets/`에 60장.

작업 순서는 스킬의 철학 유도 사슬을 그대로 따른다: 이 서비스의 철학(중고거래 앱이 왜 밀도·신뢰·시간성을 우선하는지, 무엇을 희생하는지)을 먼저 선언하고, 결정 표(D-ID)로 토큰을 유도하고, 컴포넌트 명세를 문서화한 뒤 페이지를 만든다. DESIGN.md에 그 유도가 실려야 한다.

이 도메인의 크래프트 포커스: **고밀도 리스트의 스캔성** — 한 줄에서 제목·가격·동네·시간·상태가 시선 한 번에 읽히는 행 해부, 상태 배지(판매중/예약중/거래완료)의 시스템 토큰화, 상대 시간 표기의 위계. 거래완료 매물의 시각 처리(딤 처리하되 접근 가능)도 결정 표에 포함하라.

페이지 4개, 각 페이지는 레이아웃 문법을 선언하고 구성 수치를 따른다:
- `/` 홈 피드 — 고밀도 매물 리스트(썸네일 행), 동네 선택과 카테고리 칩 필터, 상태·시간 즉시 가독. 와이드 뷰포트 전략(컬럼 추가 또는 좌측 max)을 명시하라. 빈 필터 결과 상태 포함.
- `/items/:id` 매물 상세 — 이미지 2컷, 가격(나눔이면 나눔 표기), 상태·상품 상태·설명, 판매자 카드(신뢰지수·배지·거래 수), 문의 대화 미리보기(채팅 말풍선 문법 — 이 매물에 chats가 있으면), 같은 동네의 다른 매물. 존재하지 않는 id는 정직한 오류 화면.
- `/sellers/:id` 판매자 프로필 — 신뢰지수의 시각화(수치+라벨, 근거 표기), 배지, 판매 매물 목록(상태 구분).
- `/free` 나눔 모아보기 — 나눔(0원) 매물만, 나눔 맥락에 맞는 카피.

품질 계약: 시각 품질 계약과 슬롭 게이트 전수, 컴포넌트 크래프트 45규범, 한국어 타이포 계약, SPA 기본기, 사용자 언어 카피, 고지는 푸터 1줄. 완성 전 자가 비평(critique.md)과 SELF-WALK. 추가 패키지 설치 금지, npm 실행 금지, 런타임 네트워크 금지.
