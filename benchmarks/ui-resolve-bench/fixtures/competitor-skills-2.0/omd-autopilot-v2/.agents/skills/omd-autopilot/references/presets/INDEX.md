# OmD 프리셋 카탈로그 v1

렌더 비평(G2)까지 통과해 실화면에서 검증된 컴포넌트·레이아웃 명세의 동결본.
목적: 0에서 즉흥 유도하지 않는다. 즉흥은 런마다 품질 변동의 근원이다 —
프리셋은 안정 품질의 바닥이고, 철학은 그 위의 파라미터다.

## 사용 계약 (derivation chain 4단계에서 적용)

1. **선택** — 화면/컴포넌트 설계 전에 이 카탈로그를 훑고, 장르 태그가 맞는
   프리셋을 먼저 고른다. 부합 프리셋이 있는데 0에서 만들면 게이트 GS8 위반.
2. **파생** — 프리셋의 해부(anatomy)·상태·접근성 계약은 유지하고, 토큰
   슬롯(색·라운드·간격·타이포)만 선언된 철학의 결정 표(D-ID)로 채운다.
   해부 자체를 바꾸는 파생은 결정 표에 D-ID와 근거를 남겨야 한다.
3. **기록** — 사용한 프리셋 ID를 컴포넌트 명세와 critique.md에 남긴다
   (`P-CM-01 파생, 토큰: D-P2-1/D-P3-2`).
4. **부재** — 맞는 프리셋이 없으면 "no-preset: <컴포넌트> — <이유>"를
   기록하고 유도한다. 그 결과물이 검증을 통과하면 다음 버전 카탈로그 후보다.

## 파일 구성

- `fundamentals.md` — 장르 불문 기본기: 커스텀 리스트박스(P-FN-01),
  라우트 포커스 패턴(P-FN-02), 가로형 미디어 카드(P-FN-03),
  필터 칩 행(P-FN-04), 빈 결과 상태(P-FN-05), 결과 수 정의 라인(P-FN-06)
- `commerce.md` — 커머스: 상품 카드(P-CM-01), 3컷 갤러리(P-CM-02),
  스펙 표(P-CM-03), 평점 분포(P-CM-04), 리뷰 목록(P-CM-05),
  세일가 위계(P-CM-06), 벤토 홈(P-CM-07)
- `marketplace.md` — 마켓플레이스/커뮤니티: 고밀도 매물 행(P-MK-01),
  거래 상태 배지(P-MK-02), 신뢰 지표(P-MK-03), 채팅 미리보기(P-MK-04),
  히어로+데이터 블록(P-MK-05)
- `editorial.md` — 에디토리얼/비주얼 헤비: 매거진 아티클 웰(P-ED-01),
  랭킹 캐러셀+연동 리스트(P-ED-02), 룩북 스크롤 내러티브(P-ED-03)

## 검증 계보

전 프리셋은 2026-08 디자인 엑설런스 3케이스(온집 v2 커머스, 이웃장터
마켓플레이스, 스타일몰 패션)에서 셀 완주 + G2 렌더 비평 수정 사이클을
통과한 산출물의 증류다. component-craft.md(C1–C45)와 slop-gates.md가
최저선이고, 프리셋은 그 위의 구체 해부다 — 충돌 시 게이트가 이긴다.
