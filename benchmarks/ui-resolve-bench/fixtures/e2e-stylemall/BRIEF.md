스타일몰 — 가상의 온라인 패션 편집숍. 이 React + Vite 워크스페이스 안에 프로덕션 수준의 웹 프런트를 완성하라. 사용자는 `npm install && npm run dev`로 확인한다.

`src/data/data.json`이 유일 소스: 상품 28종(모델컷+제품컷 2컷, 세일가/랭킹/사이즈), 브랜드 12개, 리뷰 84건(키·구매 사이즈 포함), 룩북 3개(커버+컷 3), 기획전 2건. 이미지는 `/assets/`에 71장.

작업 순서는 스킬의 철학 유도 사슬을 그대로 따른다: 패션 커머스의 철학(이미지가 지배하고 UI는 물러선다면 무엇을 희생하는지, 세일 정보의 정직한 위계란 무엇인지)을 먼저 선언하고, 결정 표(D-ID)로 토큰을 유도하고, 컴포넌트 명세를 문서화한 뒤 페이지를 만든다. DESIGN.md에 그 유도가 실려야 한다.

이 도메인의 크래프트 포커스: **이미지 지배 레이아웃** — 크롬 최소화·타이포 절제 속에서도 정보(브랜드>상품명>가격 위계)가 정확히 읽히는 카드 해부, 세일가 표기(정가 취소선·할인율·세일가의 시각 위계), 랭킹의 표현, 브랜드 위계(브랜드가 상품 위에 있는 정보 구조).

페이지 5개, 각 페이지는 레이아웃 문법을 선언하고 구성 수치를 따른다:
- `/` 홈 — 비주얼 헤비: 기획전 배너, 랭킹 상위 캐러셀(컨트롤 내부, 일시정지 가능), 룩북 프리뷰, 주목 브랜드. 와이드에서 이미지 그리드가 공간을 살리게.
- `/products` — 상품 그리드(카테고리·성별 필터, 랭킹/가격/할인율 정렬 — 커스텀 리스트박스), 세일 상품의 가격 표기 위계. 빈 필터 결과 상태 포함.
- `/products/:id` — 모델/제품 컷 전환, 사이즈 선택, 세일가, 리뷰(평점 분포 + 키·구매 사이즈가 보이는 목록), 브랜드 진입, 등장 룩북 역참조. 존재하지 않는 id는 정직한 오류 화면.
- `/lookbooks/:id` — 스크롤 내러티브 문법: 컷과 카피가 스크롤을 따라 전개되고(리빌은 1회 재생, prefers-reduced-motion 폴백), 등장 상품이 문맥 위치에 조인된다.
- `/brands/:id` — 브랜드 소개(한 줄·팔로워), 해당 브랜드 상품 그리드.

품질 계약: 시각 품질 계약과 슬롭 게이트 전수, 컴포넌트 크래프트 45규범, 한국어 타이포 계약, SPA 기본기, 사용자 언어 카피, 고지는 푸터 1줄. 완성 전 자가 비평(critique.md)과 SELF-WALK. 추가 패키지 설치 금지, npm 실행 금지, 런타임 네트워크 금지.
