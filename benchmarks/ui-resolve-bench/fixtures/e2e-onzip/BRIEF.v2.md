온집(ONZIP) v2 — 가상의 홈 인테리어 커머스·커뮤니티. 이 React + Vite 워크스페이스 안에 프로덕션 수준의 웹 프런트를 완성하라. 사용자는 `npm install && npm run dev`로 확인한다.

이번 데이터는 풍부하다 — 화면이 이를 온전히 담아야 한다. `src/data/data.json`(v2)이 유일 소스: 상품 24종(각 이미지 3컷: 스튜디오/라이프스타일/디테일, 스펙표, 한 줄 피치), 리뷰 93건, 집들이 6편(갤러리 4컷+본문 단락), 기획전 2건, 카테고리 6종. 이미지는 `/assets/`에 98장.

작업 순서는 스킬의 철학 유도 사슬을 그대로 따른다: 이 서비스의 디자인 철학과 원칙(희생 포함)을 먼저 선언하고, 결정 표(D-ID)로 토큰을 유도하고, 컴포넌트 명세를 문서화한 뒤에 페이지를 만든다. DESIGN.md에는 그 철학과 유도 근거가 실려야 한다 — 디자이너가 읽고 "왜 이 값인가"에 답을 찾을 수 있게.

페이지 5개, 각 페이지는 레이아웃 문법을 선언하고 그 구성 수치를 따른다:
- `/` 홈 — 데스크탑에서 공간을 살리는 구성(기획전 2건과 인기 상품·최신 집들이를 함께 엮는 벤토 또는 혼합 그리드를 검토하라). 와이드 뷰포트에 정당화되지 않은 빈 공간을 남기지 마라.
- `/store` — 24종 카드 그리드(카테고리·재고 필터, 가격/평점 정렬). 카드에는 라이프스타일 컷과 한 줄 피치를 활용하라. 정렬 셀렉트는 커스텀 리스트박스다.
- `/store/:id` — 이미지 3컷 캐러셀 또는 갤러리, 스펙표, 이 상품의 리뷰(평점 분포 요약+목록), 등장한 집들이 역참조. 넓은 화면이 비지 않도록 정보 구획을 설계하라.
- `/posts` — 집들이 목록(집 유형 필터).
- `/posts/:id` — 매거진형 상세: 갤러리 4컷과 본문 단락을 교차 배치하고, 사용된 상품을 조인해 카드로.

품질 계약: 시각 품질 계약과 슬롭 게이트 전수, 컴포넌트 크래프트 45규범, 한국어 타이포 계약, SPA 기본기, 사용자 언어 카피(구현 어휘 금지), 고지는 푸터 1줄. 완성 전 자가 비평(critique.md)과 SELF-WALK. 추가 패키지 설치 금지, npm 실행 금지, 런타임 네트워크 금지.
