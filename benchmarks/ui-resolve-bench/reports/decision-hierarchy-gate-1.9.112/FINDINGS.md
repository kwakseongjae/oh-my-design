# Hierarchy is now tied to the decision contract

The accepted gate separates “the task has all facts” from “the task makes the
decision legible.” A future high-consequence fixture must declare where the
selected target, supplied evidence, current state, and final action live. The
evaluator then checks their relationship without choosing a visual style.

This avoids two weak alternatives:

- generic visual heuristics that reward larger type, more color, or more cards
  everywhere;
- semantic markers that pass even when every role is visually flattened.

The gate instead requires exact roles, reading-order integrity, one bounded
target-emphasis channel, one bounded state-distinction channel, and physical
separation of the action. A valid implementation may remain quiet, dense, or
minimal as long as the irreversible decision is inspectable.

The next valid denominator is a new unseen high-consequence task that
preregisters both 1.9.111 text geometry and this hierarchy oracle. The deletion
artifacts remain diagnostic history and are not rescored.
