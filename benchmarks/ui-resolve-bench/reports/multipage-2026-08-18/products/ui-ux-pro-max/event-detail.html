The night, as written

Elena Voss — a sample author invented for this page — reads from a sheaf of letters that never found a postmark. The chairs face a single stool. The lamp does most of the hosting.

There is a pause after the third letter, then tea. Questions, if anyone still has a voice. No signing line is advertised because this is not a live tour date.
