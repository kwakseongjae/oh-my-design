# Known-failure closure repair — 1.9.388

Cold-chain r2 exposed a quality-efficiency split. The compact candidate used the deterministic reflow helper and passed every responsive gate with 46.8% less wall time and 69.0% fewer tokens than its paired control, but it left a contrast ratio it had already measured at 4.107:1 unchanged. The independent evaluator therefore rejected accessibility and the Reliability@3 promotion became mathematically unreachable.

The canonical apply skill now treats every supplied baseline failure and every pre-edit measured failing critical gate as a conjunctive release blocker. A measured failure cannot be mentioned and deferred: it must map to a product correction or verified fail-close in the same transaction. `measured-but-unchanged`, any unresolved known failure, or an open known-failure closure blocks static closure, browser proof, and delivery.

This keeps the compact reflow helper's efficiency while preventing the workflow headline from narrowing acceptance to reflow alone.
