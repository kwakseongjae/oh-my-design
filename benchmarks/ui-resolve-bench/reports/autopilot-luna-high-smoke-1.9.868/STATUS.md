The landing result proves the full one-prompt path can establish `DESIGN.md`,
build a real surface, consume controller feedback, preserve prior assertions,
and reach 100/100 without user intervention. It is one task, not a reliability
or superiority claim.

The two failures expose product-contract defects that must be fixed before a
fresh epoch:

1. The cold-chain provider spent its final budget probing Playwright, Chromium,
   screenshots, and a local server even though browser verification belonged
   to the controller. It produced product bytes but did not return before the
   900-second limit.
2. The locale controller allowed a second repair after the first repair made no
   objective improvement. The second repair regressed a previously passing
   accessibility assertion, reducing the sealed score from 40 to 20.
3. The locale task required an honest unavailable-translation state in the
   hidden task contract, but the exact user prompt did not request that state.
   A fair same-prompt benchmark must expose the consequential required state to
   every arm.

Observed usage is incomplete because the timed-out cold-chain call did not emit
provider usage. The six reporting calls used 8,855,794 input tokens (8,168,704
cached) and 117,744 output tokens. The sum must not be presented as a full-block
token total.

The next fresh epoch is blocked until controller-owned browser execution is an
explicit provider prohibition, bounded repairs require strict objective lift
with zero protected regression, and the task/prompt authority is re-frozen.
Public one-shot, comparison, and 2.0.0 readiness claims remain blocked.
