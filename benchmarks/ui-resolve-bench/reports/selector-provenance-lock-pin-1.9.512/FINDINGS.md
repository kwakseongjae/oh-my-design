# Selector provenance lock pin

This pin freezes the provider-free repair from 1.9.511. Snapshot-backed typography rows must now use a stable class, id, or attribute anchor that exists in the snapshotted pre-edit product. A class introduced by the product edit can no longer masquerade as a pre-edit measurement selector.

The proof evaluator also separates missing pre-edit measurements from an actual computed typography delta. The frozen rail candidate now reports `reflow-pre-edit-selector-unresolved` instead of the misleading `reflow-locked-typography-changed`.

This is an immutable source pin, not a quality promotion. Transfer still requires a new unseen task and a preregistered Reliability@3 comparison.
