# Orbital sample-return custody — unseen baseline

This task was created and deterministically evaluated before any model, control, or candidate exposure. It preserves four return canisters, six custody seals, two quarantine bays, three review views, one note toggle, and one custody-review form. The target-only decision carrier exists in the pre-edit source.

The raw DESIGN.md baseline scores **75/85**. Task contract, state journey, design grounding, and evidence honesty pass. Responsive and accessibility fail: the document expands to 1,075px at 390px and 320px and to 2,150px under actual 200%; both target tokens fragment and the pending state wraps in every narrow condition; muted normal text measures 3.78:1 with one serious contrast violation per viewport.

The task is suitable for a carrier-local fit transfer test because the desktop hierarchy is valid while nested narrow carriers are not. The next step is an immutable task-source pin. No model run is authorized before that pin.
