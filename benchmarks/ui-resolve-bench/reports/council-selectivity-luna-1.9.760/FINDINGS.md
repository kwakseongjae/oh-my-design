# Findings — authority-source calibration 1.9.760

The calibrated council passed its exact mixed-case gate. It deferred the three repository-fixed audience, scope, and CTA questions while retaining annual pricing as the only interview. Questions fell from four to one without losing the required user decision.

Both Luna/high lanes completed with valid artifacts. No automatic decision changed, no undeclared file changed, no timeout or retry occurred, and Cursor usage was zero.

The authority-source contract is the material correction:

- preserve an explicit existing contract → `defer`;
- ask the product owner for an answerable new commitment → `interview`;
- stop on a required external fact or official source that cannot be supplied as a product choice → `blocked`.

Two lanes consumed 106,424 input tokens, 82,432 cached, plus 2,939 output and 1,548 reasoning-output tokens. That is 35,474.67 input tokens per correctly removed interruption. It is better than 1.9.758 but still too expensive for unconditional production dispatch.

This is one calibration case, not general effectiveness evidence. The next denominator must independently test all three authority modes across multiple cases, including an external-unverifiable block and a no-dispatch deterministic control, before the council can become a default 2.0 behavior.
