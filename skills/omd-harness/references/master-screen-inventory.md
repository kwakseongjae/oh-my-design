# screens.md — 화면 인벤토리 계약 (checkpoint #1)

Read this file only when entering DESIGN_GENERATION step 2.

`screens.md`는 화면 인벤토리 디깅이다: 브리프·데이터 인벤토리·여정에서 이
제품이 필요로 하는 **완전한 화면 목록**을 도출한다 — 사용자가 말하지 않은
화면(온보딩, 빈/오류 상태, 설정, 결제/확인)도 여정이 함의하면 포함한다.
화면당 한 행:

| 화면 | 목적(여정 단계) | 핵심 요소 | 레이아웃 문법 | 상태(빈/오류/로딩) | 프리셋 후보 |

- 레이아웃 문법은 콘텐츠 역산과 함께 적는다(캐러셀 4+/벤토 5+/매거진 4+).
  데이터가 문법을 못 채우면 보강 계획을 같은 행에 적는다.
- 프리셋 후보 열은 omd-autopilot 프리셋 카탈로그(`references/presets/`)가
  설치된 채널이면 그 ID로, 아니면 비워 둔다.
- Checkpoint #1 승인은 화면 목록과 각 화면 구성 **둘 다**를 대상으로 한다.
  사용자는 와이어프레임 전에 화면을 추가·삭제·개명·재구성할 수 있다.
- 승인된 `screens.md`에 없는 화면은 만들지 않는다. 나중에 추가하려면 이
  체크포인트로 재진입한다.
