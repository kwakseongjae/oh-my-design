# 프리셋 — flavors (레퍼런스 카탈로그 기반)

## P-FL-01 토스 계열
**언제** — 돈 걸린 선택·동의·납부·복구. 장르 P-AU · P-CK · 금융형 P-OB. 제품(TDS)과
마케팅(toss.im)을 표면으로 가를 수 있을 때(§1, §12.1). / **언제 아닌가** — P-CM ·
P-MK · P-ED. 두 표면 기하 평균. 로고 블루를 UI 프라이머리로 치환(§2, §7 Don't).
**Base** — shadcn `Button`(`Button`, `buttonVariants`) · `Input` · `Field` · `Checkbox` ·
`Badge`. 조립 P-PR-01 · P-PR-02 · P-PR-08 · P-PR-04. 배지는 액션 아님(C27, §4).
카드·탭·토스트·다이얼로그는 레퍼런스에 없음 — P-PR-20/27은 확장(§7 Don't, §9).
**해부** — 우선: 비교 가능한 답, 가치 먼저·비용 나중, 중단 흐름의 상태·결과·다음 안전
행동(§10, §12.5, §13). 희생: 그림자로 만드는 권위, 두 표면 평균 기하, 금융 은어(§6,
§7, §10). 타이포가 지배하고 면은 조용하다. 블루는 기능(§12.2). 열: 라벨 → 큰 터치
액션/필드(+도움·에러) → 중첩 약관(P-PR-04). 흉내 실패: 로고 블루 치환, Tossface 본문
승격(§3 선언만), 문서 크롬 색 이식, 라운드/높이 평균, 없는 카드·섀도·탭 추가(§7).
**상태** — 버튼 fill/weak · primary/danger/light/dark · loading/disabled/pressed/keyboard
focus. 로딩 중 폭 유지(§4, §14). 필드 box/line/big/hero + focus/error/disabled/read-only.
약관 checked/unchecked/disabled/중첩. 마케팅 hover는 레퍼런스에 없음.
**접근성** — APG Button · native input · Checkbox. `:focus-visible` 즉시(G15, G19). 로딩
라벨 유지(C4). 배지 onClick 금지(C27). 에러 3채널(C16). 라우트 P-FN-02. 중첩 약관은
독립 탭 스톱.
**토큰 슬롯** — 색 밀도: 뉴트럴이 넓고 프라이머리는 행동·포커스·위험만(§2, G23). 라운드:
제품은 크기와 페어, 마케팅은 더 낮고 각진 별 스케일 — 합치지 않음(§5, §7, §8). 간격:
컴팩트 클러스터. 전역 레이아웃은 레퍼런스에 없음(§5, §8). 타이포: 산세리프 한 가족,
큰 헤딩·읽히는 행간. Tossface 본문 금지(§3, G1). 모션: 레퍼런스에 없음(§15).
**게이트** — C1 C3 C4 C11 C16 C27 C42 C45 · G1 G7 G10 G15 G19 G23 G26 G27 G28 G37 G39 G40 · GS1 GS7 GS8
**검증** — 미검증 — 리서치 유도

## P-FL-02 당근 계열
**언제** — 이웃 거래가 주 콘텐츠이고 크롬보다 매물·동네 이름이 지배할 때. 장르 P-MK
(P-FN-05/04/07). SEED와 마케팅 주황을 다른 값으로 유지(§1, §2). / **언제 아닌가** —
P-CM · P-ED · P-DB. 마케팅 주황을 SEED Primary로 재명명. 검증 안 된 브랜드 웹폰트(§3, §7).
**Base** — shadcn `Button` · `Input` · `Field` · `Tabs` · `Sonner`(`Toaster`, `toast()`) ·
`Skeleton`. 조립 P-PR-01 · P-PR-02 · P-PR-08 · P-PR-27. 탭 hug|fill(fill 상위 5, §4, §8).
셀렉트 P-FN-01(G28). 시트는 레퍼런스에 없음 — P-PR-22는 확장. 스낵바 액션 최대 1개(§4).
**해부** — 우선: 모든 사용자 콘텐츠 행에 동네 이름, 주황은 희소, 시스템 폰트로 크롬이
사라짐, 신뢰는 배지가 아니라 평온과 대면 가능성(§12.1–4, §13). 희생: 디스플레이 페이스,
주황 CTA 경쟁, 엔터프라이즈 필터, 스트릭, 전국 익명 마켓 미감(§11, §12). 밀도: 모바일
매물 3–4행(§12.8). 행은 썸네일+제목+메타(동네) — P-FN-07, 매물 카드 발명 금지(§7).
흉내 실패: 마케팅 hex=carrot-500, Pretendard 사용 주장, 주황 히어로, 빈 상태 일러스트(§10, §14).
**상태** — 버튼 primary/primary-low/secondary/danger/disabled/hover/keyboard(§4, §14).
필드 outlined/underlined + focused/disabled/readonly/required/invalid. 탭 selected/disabled/
focus. 스낵바 default/success/warning. 거래 완료는 화면이지 토스트가 아님(§14, G16).
**접근성** — 자식 APG + Tabs. 스낵바는 포커스를 빼앗지 않음(P-PR-27). 거래 완료 primary
1개(C3). 에러는 구체·비난 없음·다음 행동(§10). `:focus-visible`(G19). 이모지는 에러·
신뢰·결제에 금지(§10, G30).
**토큰 슬롯** — 색 밀도: 뉴트럴이 넓고 주황은 행동·활성만. 뷰포트 주황 1개(§12.1, G23).
위험/정보/성공은 유틸리티(§12.6). 다크는 시맨틱 재매핑(§12.7, C39). 라운드: 마케팅 필과
SEED를 합치지 않음(§5). 간격: 4 배수(G24). 타이포: 시스템 산세리프, 헤딩은 웨이트로만
(§3). 모션: 짧은 이름난 구간, 스프링 금지(§15, G12). reduced-motion이면 즉시(G27).
**게이트** — C3 C11 C16 C27 C39 C42 · G12 G16 G18 G19 G23 G24 G26 G27 G28 G30 G37 G40 · GS1 GS5 GS7 GS8
**검증** — 미검증 — 리서치 유도

## P-FL-03 오늘의집 계열
**언제** — 사용자 집 콘텐츠가 발견의 입구이고 다음이 구매·시공 실행일 때. 장르: P-CM과
P-ED를 한 여정으로(§12.1). 홈이 이미지에 지배되고 크롬이 조용할 때. / **언제 아닌가** —
금융(P-FL-01), 동네 중고(P-FL-02), 패션 룩북 전용(P-FL-04). 서비스를 P-MK 하나로 접기(§12.2).
**Base** — shadcn `Button` · `Input` · `Card`의 **셸만**(바깥 elevated 금지). 액션 P-PR-01,
검색 P-PR-02(C12; 관측 탑내비 인풋은 보더 없는 투명 한 줄, §4). 상품 해부는 P-CM-01.
배지·모달·토스트는 레퍼런스에 없음 — 확장.
**해부** — 우선: 영감과 다음 실행의 연결, 이미지 주도, 텍스트·컨트롤은 상대적으로 조용
(§1, §12.1). 희생: 게시된 비주얼 시스템, 의미 상태색, 프레임 있는 커머스 카드, 과거
시안 부활(§1, §2 `#35c5f0` 제외, §7). 바깥 상품 article: 투명·직각·패딩 0. 자식 구성은
레퍼런스에 없음(§4) — P-FN-07은 확장, 바깥을 카드화하지 않음. h1은 같은 페이스 레귤러
(§3). 섀도는 원형 플로트만(§6). 흉내 실패: 옛 민트 부활, 선언만 된 Noto를 UI 가족으로
주장, 정적 홈에서 상태를 관례로 채우기, “O! Moment”를 색·애니 증거로 쓰기(§12.3).
**상태** — `interactionCount: 0`. hover/pressed/focus/disabled/empty/loading/error는
레퍼런스에 없음(§14). C1/C11/G26은 로컬 확장이지 “오늘의집 상태”가 아님. 관측 default만:
채운 작은 액션, 아웃라인 유틸, 텍스트 액션, 원형 플로트.
**접근성** — 자식 APG. 원형 플로트는 캡처에 텍스트가 없으므로 아이콘-온리 `aria-label`
(P-PR-01). 히트 ≥44(C2). 포커스 링은 레퍼런스에 없음 — `:focus-visible` 즉시(G15, G19). 라우트 P-FN-02.
**토큰 슬롯** — 색 밀도: 흰 캔버스 + 어두운 뉴트럴. 액션 블루는 채운 작은 버튼과 텍스트
액션에만(§2, §7 Do, G23). 세일/에러/성공/오버레이 색은 레퍼런스에 없음. 라운드: 기본
직각, 유틸/액션만 작은 코너, 플로트만 원(§1, §5). 간격: 촘촘한 홈 클러스터. 5·9px류는
스케일이 아님(G24). 그리드·반응형은 레퍼런스에 없음(§8). 타이포: 가변 산세리프, 본문
행간이 타이트, 액션만 볼드(§3). 모션: 레퍼런스에 없음(§15).
**게이트** — C2 C3 C12 C24 C26 C45 · G15 G19 G23 G24 G26 G45 · GS1 GS5 GS7 GS8
**검증** — 미검증 — 리서치 유도

## P-FL-04 무신사 계열
**언제** — 패션 사진·에디토리얼이 다양성을 지고 크롬은 흑/백/선으로 물러날 때. 장르
P-CM(스퀘어 그리드; 세일가 P-CM-06은 확장) + P-ED(스트릿 스냅·룩북, §12.1). 후기
P-CM-05f. / **언제 아닌가** — 스토어 토큰을 CI·캠페인·앱에 일반화(§1, §12.2–3). 세일 색 부활(§2). 둥근 카드·호버 리프트·그라데이션 헤드라인.
**Base** — shadcn `Button`(`buttonVariants` link/ghost가 GNB에 가깝다) · `Input`(검색) ·
`NavigationMenu` 또는 커스텀 마스트헤드(P-FN-08; AI 기본 nav는 G42). 상품은 링크 셸 —
내부 CTA 공존 금지(C25). 순서는 P-CM-01. 필터 P-FN-04 — 선택 색은 레퍼런스에 없음.
**해부** — 우선: 검증된 상품·에디토리얼 실사, 직각 풀블리드 이미지, 얕은 크롬 위계(§1,
§12.1). 희생: 인터페이스가 유행을 대신하는 장식, 스토어/회사 정체성 혼용, 없는 상호작용을
이커머스 관례로 메우기(§12.2–3). 구조: GNB 스토어 링크(전폭 높이, 직각) + 검색(낮은
높이, 작은 코너) + 스퀘어 상품 이미지 링크(패딩 0) + 작은 유틸 버튼. 이미지가 리듬을
정함(§3, §4). 평평(§6). 흉내 실패: STANDARD를 전 제품 증거로, 세일 뱃지를 토큰으로,
스퀘어에 라운드, 시스템 폰트 교체, 없는 모션(§7, §14, §15).
**상태** — interaction 0. hover/focus/pressed/disabled/empty/loading/error는 레퍼런스에
없음(§14). C1/C11/G26은 로컬 확장. 관측 default만: GNB 링크, 검색, 상품 이미지 링크, 상품 유틸 버튼.
**접근성** — 이미지 링크의 이름은 상품명. 유틸 아이콘은 `aria-label`, 히트 ≥44(C2). 검색은
보이는 라벨 또는 동등 이름(C12). `:focus-visible`(G19). 전체 클릭과 내부 CTA 동시 금지(C25).
**토큰 슬롯** — 색 밀도: 극저. 캔버스/전경 양극, 뮤트와 라인만 보조. 프로모·세일·에러
색은 레퍼런스에 없음(§2, G23). `#000`/`#fff`는 AI 기본(G7)이 아니라 “사진이 다양성을
진다”는 결정의 결과로만 허용(GS7). 라운드: 상품·유틸은 직각, 검색만 작은 코너(§1, §5).
간격: 촘촘한 소단위와 섹션 하단의 한 단계 큰 갭(§5). 반응형은 레퍼런스에 없음(§8).
타이포: 산세리프 한 가족, 본문 위계가 얕음. 이탤릭 헤딩 금지(§3, G38a). 모션: 레퍼런스에 없음(§15).
**게이트** — C2 C3 C12 C24 C25 C26 · G2 G5 G7 G8 G19 G23 G26 G38a G42 G45 · GS1 GS6 GS7 GS8
**검증** — 미검증 — 리서치 유도

## P-FL-05 배민 계열
**언제** — 즉시성(주문·결제·배달 상태)과 생활 밀착 온기가 공존해야 할 때. 장르: 상태·
결제는 P-CK, 계정은 P-AU. 캠페인·굿즈·폰트 카탈로그는 다른 레이어(§12.3–5). / **언제 아닌가** — 레스토랑 카드·앱 탭을 “기억 속의 배민”으로 그리기(§7 Don't). 헤리티지
간판체를 앱 UI 본문으로 쓰기(§3, §7). 옛 민트·블랙 필 CTA 부활. 네 표면을 한 기하로 평탄화.
**Base** — 제품 액션·필드는 P-PR-01 · P-PR-02 · P-PR-08(주문·복구는 직접 카피, §10).
코퍼릿이 필요할 때만 shadcn `Button` outline/secondary. 다운로드 카드형 CTA는 `Button`
또는 `Card`+`Button`(흰 면, 중간 라운드, §4). 캐러셀 C34. 셀렉터 펼침은 P-FN-01(G28).
**해부** — 우선: 속도 속에서도 온기, 문화를 거래 밖 자산으로, 캠페인은 비틀고 주문·복구는
직선, 현재의 맑은 민트+단정한 제품 서체가 향수보다 앞설 것(§11, §12.1–4). 희생: 익명
기관미, 헤리티지 폰트의 기능 UI 오용, 한 “배민 스타일”로 평균(§1, §7). 제품 층은 짧은
직접 문장. 브랜드 층은 일상을 조금 비튼 짧은 줄 — 슬로건을 UI 필러로 반복하지 않음(§10).
흉내 실패: WORK를 시스템 폰트로 치환, 옛 민트/블랙 필 복원, 라이선스 없이 폰트 재배포(§6, §7).
**상태** — 앱 다운로드 카드 default/hover. 코퍼릿 캐러셀 default/disabled. 폰트 카탈로그
다운로드 가능/불가. 그 밖 버튼은 default만(§14). 주문·결제 에러/로딩 공식 계약은
레퍼런스에 없음 — 카피 원칙만: 무엇이 일어났고 다음에 무엇을 하면 되는지(§10).
**접근성** — 주문·결제·상태 고지에 애매한 유머 금지. 캠페인 톤을 복구에 들이지 않음
(§10, §12.3). 에러 3채널(C16). 캐러셀 disabled 대비는 제품이 정함(C42). `:focus-visible`(G19). WORK가 없으면 미리보기 대체로만 쓰고 앱 정체 서체라고 부르지 않음(§3, §9).
**토큰 슬롯** — 색 밀도: 공개 웹에서 민트는 액센트이지 전면 워시가 아님. 다운로드 면은
흰 캔버스(§2, G23). 코퍼릿은 더 무채인 별 팔레트(§12.5). 라운드: 웹 다운로드는 중간,
