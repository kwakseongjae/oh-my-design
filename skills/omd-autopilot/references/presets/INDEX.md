# OmD 프리셋 카탈로그 v2

렌더 비평(G2)까지 통과해 실화면에서 검증된 컴포넌트·레이아웃 계약의 동결본.
목적: 0에서 즉흥 유도하지 않는다. 즉흥은 런마다 품질 변동의 근원이다 —
프리셋은 안정 품질의 바닥이고, 철학은 그 위의 파라미터다.

## 프리셋은 컴포넌트 라이브러리가 아니다

shadcn/ui·Radix·MUI는 **구조**를 준다. OmD 프리셋은 그 구조를 **당신이 선언한
철학에서 어떻게 유도할지**를 준다 — 해부, 상태 매트릭스, 접근성 계약, 그리고
**토큰 슬롯**(어느 결정 D-ID가 어느 값에 묶이는지). 그래서 둘은 경쟁하지 않고
겹쳐 쓴다:

| | shadcn/Radix | OmD 프리셋 |
|---|---|---|
| 제공 | 마크업 구조·동작·기본 스타일 | 해부 계약·상태 매트릭스·토큰 슬롯·게이트 |
| 값의 출처 | 라이브러리 기본값(모든 프로젝트 동일) | 프로젝트 철학의 결정 표(D-ID) |
| 실패 방지 | 접근성 동작 | 접근성 + AI 슬롭 + 레이아웃 문법 |
| 결과 | 어느 제품이든 같은 얼굴 | 이 제품만의 얼굴, 근거 추적 가능 |

프로젝트가 shadcn을 쓰면 프리셋의 **Base** 항목이 시작점을 지정하고, **토큰
슬롯**이 무엇을 프로젝트 토큰에 묶고 무엇을 그대로 둘지 지시한다. shadcn을
안 쓰면 같은 계약을 손으로 구현한다 — 계약은 동일하다.

## 3 레이어

1. **fundamentals** (`fundamentals.md`, P-FN-xx) — 장르 불문 기본기.
   패딩 해부·포커스·마스트헤드·히어로·푸터·빈 상태 등. 전 프로젝트 필수.
2. **primitives** (`primitives/*.md`, P-PR-xx) — 컴포넌트 어휘. shadcn/Radix
   대응 매핑과 APG 계약 포함. form / overlay / navigation / display.
3. **genres** (`genres/*.md`) — 화면 단위 조립: commerce(P-CM) ·
   marketplace(P-MK) · editorial(P-ED) · onboarding(P-OB) · auth(P-AU) ·
   checkout(P-CK) · dashboard(P-DB). 프리미티브를 조립해 쓰고 중복 정의하지
   않는다 — 해부에서 `P-PR-01`, `P-FN-01` 처럼 참조한다.
4. **flavors** (`flavors/*.md`, P-FL-xx) — 레퍼런스 카탈로그(`web/references/`
   440종)에서 유도한 장르-지역 성향 프로파일. 브랜드 사실을 발명하지 않고
   해당 레퍼런스 DESIGN.md의 절(§)을 인용해 "이 계열은 무엇을 우선하고 무엇을
   희생하는가"를 토큰 성향으로 번역한다. 레퍼런스에 없는 항목은 "레퍼런스에
   없음"으로 남기고 관례로 메우지 않는다.

기계 판독본은 `catalog.json`(생성물) — 웹 프리셋 페이지와 `omd book`이 소비한다.
마크다운이 정본이고 JSON은 투영이다.

## 사용 계약 (derivation chain 4단계에서 적용)

1. **선택** — 화면/컴포넌트 설계 전에 카탈로그를 훑고 장르·프리미티브
   프리셋을 고른다. 부합 프리셋이 있는데 0에서 만들면 게이트 GS8 위반.
2. **파생** — 해부·상태·접근성 계약은 유지하고, 토큰 슬롯만 결정 표(D-ID)로
   채운다. 해부를 바꾸는 파생은 결정 표에 D-ID와 근거를 남긴다.
3. **기록** — 사용한 프리셋 ID를 컴포넌트 명세와 critique.md에 남긴다
   (`P-CM-01 파생, 토큰: D-P2-1/D-P3-2`).
4. **부재** — 맞는 프리셋이 없으면 "no-preset: <컴포넌트> — <이유>"를
   기록하고 유도한다. 그 결과물이 검증을 통과하면 다음 버전 카탈로그 후보다.

## 프리셋 작성 템플릿 (신규 항목은 이 형식을 지킨다)

```
## P-XX-nn 이름
**언제** — 이 프리셋이 맞는 상황 / **언제 아닌가** — 쓰면 안 되는 상황
**Base** — shadcn/Radix 대응(있으면) 또는 hand-rolled
**해부** — 요소 순서와 구조, 무엇이 무엇을 지배하는지
**상태** — default/hover/active/focus-visible/disabled/loading/error/empty 중 해당
**접근성** — 역할·키보드·포커스 이동·aria (APG 패턴명 인용)
**토큰 슬롯** — 철학이 채워야 할 값 목록(하드코딩 금지 지점)
**게이트** — 이 프리셋이 방어하는 G/C/GS 번호
**검증** — 어느 케이스의 어느 렌더에서 확인됐는지 (미검증이면 "미검증")
```
