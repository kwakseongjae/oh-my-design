# r3 빌드 제약 (r2 리뷰 round-2 + 사용자 70점 피드백에서)

## 반드시 고칠 것
1. **정착 타이밍 양방향**: 사용자 지적 = 종점이 섹션 퇴장과 겹침(펼침을 못 봄). 리뷰 지적 = S1 은 반대로 p≈0.45 에 끝나고 774px 무사건. 규칙(LC-48, rx-timing 확정치 대기): 결과 상태 정착은 핀 진행의 **정해진 대역** 안에서, 정착 후 감상 홀드 ≥ N vh, 무사건 구간 금지.
2. **S3 토큰 점등의 인과**: 프레임 06 캡션 "bench height · midday" ↔ 점등 "eye level · morning" 모순. 토큰 스왑 + 밑줄 이동으로 프레임과 1:1 결합.
3. **S5 카드별 `--pz` 원근 변주가 GSAP 동일 트윈에 덮임** → 카드별 트윈 또는 CSS 변수 유지.
4. **390 안무 0**: `innerWidth<900` 게이트로 모바일은 이미지가 행동하지 않는 유일한 뷰포트. coarse-pointer 용 경량 안무(스크럽 없이 view()-timeline 리빌 + 자동 재생 시퀀스) 필수. 390 첫 화면에 h1 보이게(현재 y=733).
5. **회귀**: 라벨 11px×93 → 13px, 토큰 밖 hex 6종 → 0, `:active`·`disabled` 상태, hover transform 모순(틸트는 pointer 추종만).
6. **§5 예산**: 핀 4(DESIGN §5 는 2 허용이었음 — r3 에서 DESIGN.md 를 4 로 개정하거나 핀을 2~3 으로 줄인다; 총 vh ≤ 14).
