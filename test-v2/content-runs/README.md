# content-runs — 공개 콘텐츠용 비교 런 (봉인 벤치 밖)

X/스레드 콘텐츠·영상용 하네스 비교 런을 여기서 돌린다. **`03-runs/`(봉인된 T3-3 실험 칸)와
완전히 분리**되어 있고, 여기 산출물은 어떤 벤치 수치·순위 주장에도 쓰지 않는다.

규칙 (grokbot X 인수인계 하드 룰과 동형):

1. 산출물은 **비공식 생성물**임을 콘텐츠에 명시한다 — 해당 브랜드의 공식 자산이 아니다.
2. 레퍼런스 브랜드를 태그·멘션하지 않는다.
3. 봉인 해제 전 T3 수치를 함께 언급하지 않는다. 이 런은 정성 비교 시연이다.
4. 세 arm은 같은 브리프·같은 모델·같은 이미지 채널을 받는다 — 다른 것은 하네스뿐.

실행: 오케스트레이터가 arm별 프롬프트로 grok build를 호출하고, 완료 후
`node build-compare.mjs <brand>`로 촬영용 비교 페이지를 만든 뒤
`node ../tools/render-integrity.mjs <brand>/*/render.html`로 무결성을 확인한다.
