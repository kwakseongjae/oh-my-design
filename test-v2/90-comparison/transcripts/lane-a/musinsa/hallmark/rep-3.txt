Heading: Tokens

All color and font declarations in `render.html` read these names. No mid-render hex / OKLCH / `font-family` literals.

Accent is a highlighter (banner strip, sale figure, saved heart). It is not a section fill.

Heading: Type

| Token | Stack | Use |
| --- | --- | --- |
| `--font-display` | Big Shoulders Display → Arial Narrow → Apple SD Gothic Neo | wordmark, `h1` |
| `--font-body` | IBM Plex Sans → Apple SD Gothic Neo → Noto Sans KR | UI, product names |

Two families. No third. No Google Fonts request — the file opens offline; Hangul falls through to the system Korean face. Display is roman. Headings never italic.

Scale is a major third from 16px: `--text-xs` … `--text-2xl`. Catalogue forbids a giant hero, so `h1` caps near `--text-2xl`.

Prices use `font-variant-numeric: tabular-nums`.

Heading: Space, motion, z

4pt scale `--space-3xs` … `--space-3xl`. Page gutter `clamp(1rem, 4vw, 1.5rem)`.

Sport duration scale 0.7×: `--dur-micro: 84ms`, `--dur-short: 154ms`, `--dur-long: 294ms`. Easings: `--ease-out`, `--ease-in`, `--ease-in-out`. Animate `transform` and `opacity` only.

`--z-sticky-nav: 300` sits above `--z-sticky: 200`. Banner height `--banner-h` and bar `--bar-h` are the offset contract for any future in-page sticky.

Heading: Components

Heading: N12 nav

Solid accent banner (“타임세일 · 상의”) over an ink bar. Scroll down past 48px retracts the banner (`translateY`). Dismiss zeroes `--banner-h` so the page does not keep a gap. Wordmark is the text **MUSINSA** — no official mark. Desktop shows store links; below 60rem they collapse into a `details` sheet. Primary chrome CTA is “로그인”, one line, 44px hit.

Heading: Color filter

One radio group in normal flow (no `position: absolute; top: 0`). Values: 전체, 블랙, 화이트, 다크 그레이, 아이보리, 카키. Checking a color hides `article.product` whose `data-color` does not match. The live count is the number of cards still in the grid, not a store-wide census.

Chip states in CSS: default, hover (`@media (hover: hover)`), `:focus-visible` via `input:focus-visible + .chip`, `:active`, `:disabled`, `data-state=loading|error|success`, plus `:checked` as the selected surface.

Heading: F6 grid

Uniform 3:4 cells. Tracks are `minmax(0, 1fr)` — 2 / 3 / 4 / 5 columns at 0 / 40 / 60 / 90 rem. First card is the generated still (`image.jpg`, `fetchpriority="high"`, not lazy). Remaining cards are CSS plates with a TODO swap comment. Save is optimistic: `aria-pressed` flips immediately; filled heart is the success signal; no toast.

Save states: default, hover, focus-visible, active, disabled, loading, error, success/pressed.

Price copy is only what the snapshot showed. Missing prices render as `—`.

Heading: Ft1 footer

Display wordmark, one sentence, three same-page links. No four-column sitemap.

Heading: States (interactive)

Every button and chip implements:

1. default
2. hover (fine pointer only)
3. `:focus-visible` — 2px `--color-focus`, offset 2px, instant (no fade)
4. `:active` — `translateY(1px)`
5. disabled — opacity 0.55 + `not-allowed`
6. loading — `data-state="loading"`
7. error — `data-state="error"`
8. success — `data-state="success"` / `aria-pressed="true"`

Dark surfaces (nav, selected chip, banner) set `color` in the same rule as `background`.

Heading: Responsive

- `overflow-x: clip` on `html` and `body`
- Clickable labels `white-space: nowrap`
- Display heads `overflow-wrap: anywhere; min-width: 0`
- Section heads stay one column
- Hit targets ≥ 44px
- Safe-area padding on inline and block-end

Heading: Motion

Editorial Catalogue is motion-cut. Kept: banner retract, chip/button press, one 1.02× image hover on fine pointers. `prefers-reduced-motion: reduce` collapses durations to 150ms and kills the image scale and nav slide.

Heading: Imagery

Lane A generated still, Grok Imagine, 3:4, stored as `image.jpg`. No remote image hosts. CSS plates are placeholders, not product photography.

Heading: Honest copy

No invented conversion rates, review counts, or pre-sale list prices. Filter count tracks the eight cards on this page. Wordmark is type, not the brand’s logo file.
