Genre: editorial. Macrostructure: Catalogue. Theme: Sport. Nav: N12 (banner + retract). Footer: Ft1 (mast-headed). Feature: F6 product card grid (3/4, 5-up, Save). CTA: C1 outlined chip. Section head: S2 hanging. Enrichment: E8 photography inside the grid, no separate hero. Catalogue headings stay inventory-sized.

Previous nav: none (first  run in this slot). This build: N12, because a commerce category has a genuine, time-bound state to announce — the applied color filter.

Heading: Position

The page is a visual index of tops, not a marketing landing. Every SKU is equal. The one job is: turn on a color, watch the grid shrink. First paint already has 컬러 블랙 on.

Heading: Type

Display is condensed, roman, uppercase only on the wordmark and filter-row labels. Product names and the page title stay sentence case. Body 16px / 1.5. Tabular numerals on prices and counts. Measure capped at 65ch on lede and empty copy.

Heading: Layout

Sticky N12: tint+ink banner (`--color-paper-3`) over a dark bar. Banner retracts on scroll-down, returns on scroll-up, dismiss zeroes `--banner-h`. Wordmark is the text string `MUSINSA` — no official mark file.

Hanging inventory head (`상의`) then three filter rows (종류 / 컬러 / 성별). Chips wrap; they never scroll the page sideways. Product grid: 2 / 2 / 4 / 5 columns at 0 / 40 / 60 / 90 rem, tracks `minmax(0, 1fr)`, cards 3:4, hairline not shadow, radius 0.

Footer is one mast band: wordmark, one line, three links.

Heading: Interaction

Filter chips and icon buttons implement default, hover, focus-visible, active, disabled, loading, error, success. Focus ring is instant (`:focus-visible`, 2px `--color-focus`, no fade). Save is optimistic and silent. 레드 is disabled (zero items in this local set). 니트 with no matches shows an empty state plus “필터 지우기”.

First render: 컬러 = 블랙. Visible count is the local remaining cards, not a fabricated catalogue total.

Heading: Imagery

`image.jpg` is the generated representative still: a black cotton crewneck, studio, no mark. It is the first card when 블랙 is on. Other cards use snapshot stills stored next to the HTML so the file opens offline.

Heading: Copy rules used

No invented conversion stats, no “350,441개” after a filter, no official logo, no extra screens (PDP/checkout). Product names, prices, likes, and ratings that appear are taken from the 2026-08-22T19-50-15-466Z evidence; missing prices are omitted.

Heading: Motion

Catalogue is motion-cut. Allowed: banner translateY, chip/button press, optional 1.02 image scale on fine hover. `prefers-reduced-motion: reduce` collapses durations to 150ms.

Heading: Offline contract

`render.html` requests only same-directory files (`image.jpg`, `goods-*.png`). CSS reset zeroes `figure`, `blockquote`, `ul`, `ol` margins. `html` and `body` use `overflow-x: clip`.
