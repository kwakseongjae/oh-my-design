Heading: Style — `minimalism fashion catalog dense high contrast`

For the listing surface: **Minimalism & Swiss Style** + **Data-Dense Dashboard** spacing, not oversized Exaggerated Minimalism.

- Monochrome, grid, no decorative shadow
- 8px rhythm, 12–14px catalog type
- One accent (sale/like red, arrival blue) — matches “single accent only”
- Hover 150–300ms; `prefers-reduced-motion` kills motion

Heading: Typography — `fashion modern sans catalog`

Pack luxury pairing is Cormorant + Montserrat (network `@import`). Offline rule forbids that.

Render stack (local only):

```
"Pretendard Variable", Pretendard, -apple-system, BlinkMacSystemFont,
"Apple SD Gothic Neo", "Noto Sans KR", "Malgun Gothic", sans-serif
```

Captured family is Pretendard Variable. If it is not installed, the OS Korean gothic is the fallback. No Google Fonts request.

Closest pack pairing if a network font were allowed: **Minimal Swiss** (Inter/Inter) — one family, weight for hierarchy. That is what the local stack imitates.

Heading: Page grammar

One screen. No extra routes.

1. Store header (text wordmark)
2. `h1` 상의
3. Facets: subcat, brand, **color**, material, quick chips, secondary
4. Applied-filter chip (`블랙 ×`)
5. Tally: 상품 / 브랜드 / 스냅
6. Sort + count
7. Product grid

**First paint applies one filter: 컬러 = 블랙.** Unfiltered capture count is `350,441`. Narrowed tally uses `48,217` as a catalog-scale stand-in for that color (not measured). Clearing the chip restores `350,441`. Subcat / gender filters further intersect the 12 sampled goods.

`image.jpg` is the representative generated catalog still, used as the 시어서커 체크 셔츠 블랙 card. Other shots are local CSS garment tiles (offline). No `msscdn` URLs.

Heading: Interaction

- Click/tap is the primary control (no hover-only filter)

- Wishlist hearts toggle `aria-pressed`

- Reduced motion: transitions off
- Empty state copy if the intersection is zero
