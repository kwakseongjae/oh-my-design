Heading: Pack `--design-system` (raw)

- Pattern: **Portfolio Grid** — visuals first, filter by category, fast loading.
- Style: **Exaggerated Minimalism** — black/white, high contrast, statement type. Fashion-appropriate.
- Density 8: 8–32px scale (listing, not marketing whitespace).
- Motion 3: 150–200ms color/opacity; no GSAP (offline first render).
- Typography: **Noto Sans KR / Noto Sans KR** (Korean Modern).
- Anti-patterns: flat-without-depth, text-heavy pages, emoji-as-icon.

The first `--design-system` color table (`#059669` emerald, `#ECFDF5` mint ground, note “category green + map accent”) is a directory/listing default. It does not match evidence chrome (`body #000`, page `#fefdfd`, header bar `#f5f5f5`, outline chip `#e0e0e0` / `#666`). **Color domain Result 4 (E-commerce Luxury) and Result 5 (Museum/Gallery)** plus evidence computed colors replace it.

Heading: Color use

- Surfaces: white cards on `#fefdfd`. Filter rows `#f5f5f5`.

Heading: Layout

- Breakpoints: 390 / 768 / 1024 / 1440 (pack §5).
- Grid: 2 → 3 → 4 → 6 columns. Images flush (`gap: 0`), 5:6 media (evidence tile ~240×288).
- Filter stack: subcat → brand → color → material → benefit chips → dropdowns → applied chip → result tabs → count.
- Sticky black nav 52px. Content not trapped under it.
- Horizontal rows scroll; no page-level horizontal scroll.

Heading: Filter contract (this screen’s job)

One filter, already on: **컬러 = 블랙**.

- First paint: `body[data-filter="black"]` hides non-black tiles in CSS (works with JS off).
- Visible tiles are evidence items whose name contains 블랙, plus the generated catalog still (`image.jpg`) for `롤업 레이어드 크롭 반팔티 [블랙]`.
- Count live region reports visible cards (`3개` on load).
- Clearing the chip sets `data-filter="all"` and restores the unfiltered evidence set.
- Empty filter values (아이보리, 네이비, …) announce an empty message; recovery is 필터 해제.

Unfiltered snapshot count `350,441` is **not** restated as a filtered total — this reconstruction only contains sampled evidence tiles.

Heading: Accessibility (pack §1–3)

- Skip link → `#products`.
- `h1` 상의, product names `h2`.
- Icon-only controls have `aria-label` (menu, search, like, cart, clear filter).
- Color filter: text label + swatch (not color alone).
- Focus visible, 44px targets, 8px+ gaps on chip rows.
- `aria-live="polite"` on count.
- `lang="ko"`. Viewport does not disable zoom.

Heading: Stack notes (`html-tailwind`)

Standalone HTML, tokens as CSS variables (Tailwind utilities inlined — no CDN). Grid gaps via parent `gap` / hairline borders, not per-card margins. Responsive padding `--spacing-gutter` 16px → 24px.
