Heading: 상의 카테고리 — surface-local design system

스냅샷 `2026-08-22T19-50-15-466Z` · 표면 desktop-1440 / mobile-390 · 과업: 필터 하나를 적용해 상품 그리드를 좁힌다.

프로젝트 루트  쓰지 않는다. 이 문서는 이 런의 `render.html`만 묶는다 (`surface-local-only`).

Heading: Philosophy

**사진이 상품이고, 필터가 유일한 과업이다.**

스냅샷의 상의 카테고리는 히어로 카피 없이 소분류 칩과 사진 그리드로 열린다. 이 화면은 그 입장을 유지한다.

| 원칙 | 얻는 것 | 희생하는 것 |
| --- | --- | --- |
| P1 사진 우선 | 접힌 화면에서 상품 컷이 바로 읽힘 | 히어로 스테이트먼트, 섹션 에어, 그림자 타일 |
| P2 필터 하나 | 소분류 칩 한 줄이 그리드를 실제로 줄임 | 브랜드·컬러·소재 다중 패싯, 정렬 콤보 |
| P3 스냅샷만 | 뷰포트에 있는 가격·브랜드·후기만 표시 | 추정 가격, 350,441개 같은 그리드 불일치 수치, 공식 로고 원본 |

Heading: Components

프리셋 먼저 고른다 (GS8).

Heading: Filter chips — P-FN-04 파생, 토큰 

- 역할: 소분류 필터 단일. 정적 배지와 혼용하지 않음.
- 해부: `role="group"` + `aria-pressed` 버튼. 기본 활성 = 전체.
- 상태: default / hover(면 chip) / pressed(언더라인+700) / focus-visible / active(scale 0.98).
- 필터 해제: 기본에서 `hidden`, 활성 필터가 있을 때만 노출.
- 빈 소분류(니트/스웨터, 후드, 맨투맨, 피케)는 그리드를 0으로 줄이고 P-FN-05로 간다.

Heading: Product card — P-CM-01 파생, 토큰 

- 해부: 미디어(5:6) → 브랜드 eyebrow → 상품명 2줄 클램프 → 가격(최대 웨이트) → 메타.
- 세일: 할인율(악센트) + 세일가. 정가가 스냅샷에 없으면 만들지 않음 (P-CM-06, ).
- 전체 클릭 카드, 내부 CTA 없음 (C25).
- 생성 이미지 `image.jpg`는 「베이직 언발 오프숄더 긴팔티 차콜」 카드의 샘플 컷.

Heading: Result line — P-FN-06

- `role="status"`: `수록된 샘플 12개 · 소분류 전체` / `{소분류} · 샘플 N개`.

Heading: Empty — P-FN-05

- 문장: `이 조건의 상품이 없습니다.` + `필터 해제` 1개.
- 표면: dashed rule. 이모지·일러스트 없음.

Heading: Header / login

- 워드마크 텍스트. 스토어 구분은 링크가 아니라 이름만 (추가 화면 없음).
- `로그인 / 회원가입` = 유일한 primary (`data-cta="primary"`). 목적지 화면은 이 과업에 없다.
- 좁은 폭: 메뉴 디스클로저 (`aria-expanded` + `#store-nav`).

Heading: Layout grammar

**고밀도 카탈로그 격자.** 초광폭 전략: 컬럼 추가 (C32).

콘텐츠 역산: 스냅샷 imagery 12장 → 카드 12. 6열 문법이 요구하는 셀을 채운다. 캐러셀·벤토·매거진 문법은 쓰지 않음 (GS6).

```
skip → header 52px → h1 「상의」 → filter band → status → 6-col grid → footer
```

그리드는 좌우 거터 없이 전폭. 타이틀·필터·상태·푸터만 `--gutter`.

Heading: States

| 상태 | 도달 | 기계 증거 |
| --- | --- | --- |
| default | 첫 로드 | `#grid[data-state=default]`, 칩 `전체` `aria-pressed=true`, 카드 12 |
| filtered | 소분류 칩 Enter/Space | `#grid[data-state=filtered]`, 해당 칩 pressed, 다른 카드 `hidden`, status 갱신 |
| empty | 니트/스웨터 등 빈 칩 | `#grid[data-state=empty]` + `#empty` 표시, status `샘플 0개` |

개발자 상태 스위처 없음.

Heading: Honesty

- 상품명·알트는 evidence.json 샘플과 데스크톱 뷰포트에 보인 브랜드/가격/후기만.
- 카테고리 전체 상품 수, 스냅샷에 없는 가격·후기, 공식 로고 원본: 푸터에서 이름을 밝히고 비움.
- `image.jpg`는 생성 샘플 컷이며 라이브 상품 사진이 아니다.
