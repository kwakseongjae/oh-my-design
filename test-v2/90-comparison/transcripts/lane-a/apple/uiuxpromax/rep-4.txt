Heading: Motion

**Scroll Reveal** (Subtle) — Trigger: scroll (viewport enter) | Duration: 300-400ms | Easing: `power1.out`

```js
gsap.from(el, { opacity: 0, y: 12, duration: 0.35, ease: 'power1.out', scrollTrigger: { trigger: el, start: 'top 90%', toggleActions: 'play none none reverse' } });
```

**Framework notes:** Requires the ScrollTrigger plugin registered once via gsap.registerPlugin(ScrollTrigger)

-  Keep the y offset small (8-16px) so it reads as a fade, not a slide
-  Don't reveal below-the-fold content needed for SEO/crawlers as invisible-by-default without a no-JS fallback

**Runtime on this render:** GSAP is a network dependency. First render uses CSS `opacity` / `transform` only, 200ms, with `@media (prefers-reduced-motion: reduce)` disabling motion. No GSAP script tag.

Evidence: `motion.present = false`.


Heading: Anti-Patterns (Do NOT Use)

-  Cheap visuals
-  Fast animations

Heading: Additional Forbidden Patterns

-  **Emojis as icons** — Use SVG icons (Heroicons, Lucide, Phosphor)
-  **Missing cursor:pointer** — All clickable elements must have cursor:pointer
-  **Layout-shifting hovers** — Avoid scale transforms that shift layout
-  **Low contrast text** — Maintain 4.5:1 minimum contrast ratio
-  **Instant state changes** — Always use transitions (150-300ms)
-  **Invisible focus states** — Focus states must be visible for a11y
-  **Google Fonts / CDN Tailwind at runtime** — first render is offline
-  **Invented metrics** — prices, ratings, unmeasured hex, unmeasured type sizes
-  **Extra screens** — Home only


Heading: Stack guidelines (`html-tailwind`)

| Guideline | Do | Don't |
|-----------|----|-------|
| Semantic colors | `var(--color-primary)` in components | Raw hex on each control |
| Images | `width`/`height` or `aspect-ratio`; relative `src` | External image URLs |
| Z-index | `z-index: 50` on sticky nav | Rely on DOM order |
| Responsive | One DOM; `hidden` / desktop nav via CSS | Separate mobile and desktop page copies |
| `@apply` | Not applicable (no Tailwind build) | Tailwind CDN |

Breakpoints used: 390 (evidence mobile), 768, 1024, 1440 (evidence desktop). Pack also lists 375.


Heading: UX validation (`--domain ux`)

| Issue | Do |
|-------|----|
| Skip links | Skip to main content before global nav |
| Heading hierarchy | `h1` then `h2` — do not skip |
| Focus states | Visible ring on interactive elements |
| Keyboard | Tab order matches visual order |
| Sticky nav | Reserve header height so content is not covered |
