Heading: Design Dials

- **Variance:** 2/10 — Centered / Minimal
- **Motion:** 2/10 — Subtle
- **Density:** 2/10 — Spacious

Rationale for dials (pack Step 1, bound to evidence):

- Variance 2: first-screen composition is centered product photography with a single headline stack (`capture/desktop-1440-viewport.png`).
- Motion 2: `evidence.json` → `surfaces.desktop-1440.motion.present = false` (“no video above the fold at capture time”).
- Density 2: full-bleed product units with large type and empty field above the phones; pack density low = 24–96px spacing.


Heading: Pattern

Pack `--design-system` returned **Real-Time / Operations Landing** for the second query. That pattern (metrics, sandbox, status colors) does not describe this page.

Domain search `--domain landing "hero product cta social-proof"` returned **Feature-Rich Showcase** as the closest product-homepage structure:

- Section order: Hero (value prop) → feature/product units → CTA repetition
- Primary CTA placement: Hero + after units
- Color strategy: brand primary + card surfaces

**Implemented page pattern (home only):**

1. Global nav (chrome from viewport)
2. First-screen iPhone unit (headline, lead, two CTAs, generated lineup image)
3. Full-bleed MacBook Air unit
4. Full-bleed iPad Air unit
5. Two-up promo grid: MacBook Pro, Watch Series 11, AirPods Pro 3, iPad Pro

Task path: first-screen primary CTA `더 알아보기` → `#iphone-intro` (same file, iPhone intro). No additional screens.


Heading: Style

Pack `--design-system` style: **Exaggerated Minimalism** (oversized type, black/white, single accent).

Domain search `--domain style "minimalism light product photography"` also ranked **Minimalism & Swiss Style** (clean, spacious, geometric, sans-serif, essential). Swiss is the closer match to the captured home (light field, no giant 12rem type, no black canvas on the first screen).

**Implemented style mix:**

- Swiss/minimal: grid of product units, no decoration, no emoji icons, no shadows
- Not exaggerated-minimalism giant type: type sizes come from evidence `typeScale`, not `clamp(3rem, 10vw, 12rem)`
- Not vintage analog / 3D configurator (other style hits)

Anti-patterns from pack output to avoid: cheap visuals; text-heavy pages; fast animations.

Heading: Key effects

Pack `--design-system` effects (`font-size: clamp(3rem 10vw 12rem)`, weight 900, tracking -0.05em) are **not applied**. They conflict with the measured type scale.

Motion (dial 2, pack GSAP Scroll Reveal subtle):

- Duration 150–300ms for control hover (pack UX / html-tailwind)
- `prefers-reduced-motion: reduce` disables animation and smooth scroll
- No GSAP CDN (offline constraint)
- No above-the-fold video (`motion.present = false`)

Heading: Stack (html-tailwind)

`--stack html-tailwind "layout hero image button navigation responsive"` applied as CSS equivalents (no Tailwind CDN):

- Responsive images: single local `image.jpg` (1280×720), `width`/`height` + `aspect-ratio` to limit CLS
- `object-fit: contain; object-position: center bottom`
- Fixed header `z-index: 50`; drawer `40`
- Icon-only controls have `aria-label`
- Mobile-first, then `768` / `1024`
- Touch targets `min-height/min-width: 44px`
- `cursor: pointer` on interactive elements
- Visible `:focus-visible` ring


Heading: UX checks used (pack Quick Reference §1–§3, §9)

- Skip link to `#main`
- Keyboard: Tab order follows visual order; Escape closes the mobile drawer
- Contrast: `#1d1d1f` on `#f5f5f7`; `#ffffff` on `#0066cc`; `#f5f5f7` on `#000000`
- Sticky header offset via header height tokens
- One primary CTA per unit (`더 알아보기`), secondary outline (`iPhone 쇼핑하기` / `구입하기`)
- No hover-only action
- `touch-action: manipulation`
