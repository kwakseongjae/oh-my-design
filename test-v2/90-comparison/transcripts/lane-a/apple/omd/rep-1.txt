Heading: Apple KR Home Design System

This document is the  portable contract for this run. It is a
surface-local system derived from the frozen snapshot, not Apple's published
design-system site. Unresolved values are omitted rather than filled.

Heading: Experience

**Scope.** One consumer surface: the Korean Apple home (`https://www.apple.com/kr/`, snapshot `2026-08-22T19-46-47-156Z`). The first render is that home. The only additional view is the intro path for the first product plate.

**Primary task.** From the first screen, move into the introduction path of one product kind.

**Stance.** The home is an entrance to one product introduction. Reproduce the measured first plate; open that plate's intro; leave every unmeasured product fact blank.

**Principles (each names a sacrifice).**

- P1 Honesty over catalog completeness. If a price, spec, or count is not in the snapshot, the screen names the missing category instead of inventing a number.
- P2 One journey over a long homepage. Extra product plates and a store/checkout are sacrificed so the graded verb stays reachable on one primary control.
- P3 Measured chrome over reinterpretation. Color, type metrics, header height, and pill radius come from `evidence.json` chrome. Unmeasured spacing uses the pack 4pt scale and is labelled as proposed.

**Source classes used.** `prompt-fact` (brief: home, intro path, snapshot handle). `repository-fact` (evidence chrome, imagery alts, viewport copy, manifest). `agent-proposed-greenfield-decision` (unmeasured spacing, motion durations, compact nav type). `unresolved` (SF Pro KR files, prices, destinations of nav items other than the intro path).

Heading: Components & States

Heading: Global header (no-preset: observed chrome)

Anatomy: wordmark · primary links · search · bag. Mobile: wordmark · search · bag · disclosure. Height 44/50px, fill `--color-header`.

| State | Applicability |
|---|---|
| default | yes |
| hover | yes (link color/weight; surface change on icon buttons) |
| focus-visible | yes (outline on controls, not on programmatic heading focus) |
| active | yes (pressed scale on icon buttons) |
| disabled | not-applicable — header controls that have no destination stay enabled and announce absence |
| loading | not-applicable |
| error | not-applicable |

Search and bag are real buttons. They do not invent a search index or a cart; they write a `role="status"` sentence that names the missing category.

Heading: Button (pill)

Anatomy: label only (no icon on the two hero actions). Min hit 44×44. Radius `--radius-pill: 980px`. Fill vs outline is a variant, not a second component.

| State | Primary fill | Outline |
|---|---|---|
| default | accent fill, on-accent text | transparent, accent border/text |
| hover | darker accent (oklch lightness −0.05), same border-width | accent tint fill |
| focus-visible | 2px accent outline, offset 3px, immediate | same |
| active | scale 0.98 | scale 0.98 |
| disabled | opacity + `cursor: not-allowed` + native `disabled` | same |
| loading | not-applicable (no async submit) | — |
| error / success | not-applicable on the control; page-level `role="alert"` / `role="status"` | — |

Primary uniqueness: one `data-cta="primary"` per view (“더 알아보기” on home). “iPhone 쇼핑하기” is `data-cta="local"` and must not reuse the primary verb.

Heading: Product plate (P-ED-03 cover)

Anatomy: centered display title → lede → CTA row → full-width figure. Non-interactive except the CTA row. States: default only. Intro view reuses the plate and adds a prose well (CJK ~40ch) plus honest-absence sentences where price/spec would sit.

Heading: Route announcement

P-FN-02: on view change, `document.title` updates, `scrollTo(0,0)`, `#page-title` receives focus with `tabindex="-1"` and no visible ring.

Heading: Layout & Platforms

**Grammar.** Home = one cover plate. Intro = same plate + prose well. Not bento (needs ≥5 cells), not magazine (needs ≥4 images), not carousel (one image).

**Wide strategy.** Center max. Copy well `max-width: 40em`. Figure `max-width: 72rem`. Background plate is full bleed; controls stay in the well (C37).

**Viewports.** 1440 (full nav), 390 (50px header, 32/19 type, disclosure nav), 320 (no horizontal document scroll, `overflow-x: clip`). 200% reflow: buttons wrap, heading `overflow-wrap: anywhere`, hit targets stay ≥44px.

**Touch.** Icon controls and CTAs min 44px. Inline prose links are the exception named by the skill.

**Overflow.** `document.documentElement.scrollWidth <= clientWidth` is a product requirement at 320 / 390 / 1440.

**Platforms.** This run is a single static HTML file. No native apps.
