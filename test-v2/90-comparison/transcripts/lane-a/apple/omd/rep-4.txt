Heading: Experience

**Scope.** One consumer route: the captured home. First paint is the iPhone
family band. The only product journey the brief names is: from that first
band, open the introduction path for one product family.

**Primary task.** Activate **더 알아보기** on the iPhone band and arrive at
an iPhone introduction region in the same document.

**Philosophy (stance).** Each scroll unit carries one product family and one
intro action. The system sacrifices comparison tables, price grids, and extra
product pages the snapshot does not authorize. Chrome is measured; imagery is
a distribution, never a single brand-defining photograph.

Principles (what is gained / what is given up):

- P1 **One family per band.** Gain a readable first task. Give up stacking
  several products into one hero.
- P2 **Measured chrome over remembered Apple.** Gain tokens that resolve to
  evidence. Give up loading SF Pro KR, drawing brand marks on devices, and
  any number not in `evidence.json`.
- P3 **Intro path over storefront.** Gain a keyboard-reachable introduction.
  Give up a shop, search hits, and a bag — those records are absent.

Supported prompt facts: screen = 홈; task = 소개 경로 이동; locale visible
in evidence `ko-KR`; title `Apple (대한민국)`.

Heading: Pill button (derived from evidence primaryButton + C1–C10)

Anatomy: label only, stadium radius, min 44×44 on touch. Variants: filled
(primary journey) and outline (local / shop).

| State | Filled | Outline | Applicability |
|---|---|---|---|
| default | cta-fill / cta-on | transparent / accent, 1px accent border | yes |
| hover | darker fill (oklch L 0.50), no extra shadow | paper-tint fill | yes |
| focus-visible | 2px accent outline, offset 2px, immediate | same | yes |
| active | scale 0.98 | scale 0.98 | yes |
| disabled | opacity + `cursor: not-allowed` + `disabled` | same | yes |
| loading | n/a — no async submit on this surface | — | not-applicable (no network write) |
| error | n/a | — | not-applicable (buttons are not fields) |

Border-width does not change across states. Primary uniqueness: one
`data-cta="primary"` — iPhone **더 알아보기**. Shop and other bands use
`data-cta="local"` or `submit`. Snapshot copy reuses the string 더 알아보기
on later bands; those controls are local and do not open extra screens.

Heading: Layout & Platforms

**Priority.** 1440 (desktop-1440 evidence) and 390 (mobile-390 evidence),
then 320 and 200% reflow as pack gates.

**Home grammar (P-ED-03).** Cover (iPhone) then the next family plate
(MacBook Air), matching the first captured viewport. No hamburger+sidebar
app shell. Overflow-x: clip. Image tracks `minmax(0, 1fr)`.

**Breakpoints.** Header disclosure below 834px (header height 50px at 390).
CTA row wraps as a group; each pill `white-space: nowrap` (G49).

**Touch.** Task controls ≥44px on the 390/320 viewports. Desktop may use
the visually shorter pill.

**200% reflow.** Display headings `overflow-wrap: anywhere; min-width: 0`.
Measure for intro prose is the center well, not full bleed.

**Platforms named.** Light color-scheme only (`method.colorScheme`). Dark
is unresolved and not shipped.
