Heading: Apple 홈 Design System

Portable projection of the surface-local system for the captured Korean Apple home. Unknowns are omitted at the smallest boundary. Values without a  are not used in code.

Heading: Philosophy

Stance: the first screen is a quiet product stage, not a storefront dashboard.

- P1 Hardware on a still plate. Sacrifice decoration, cards-in-cards, and accent washes so one product can occupy the fold.
- P2 One path off the fold. Sacrifice repeating primary verbs as global CTAs; the above-fold iPhone “더 알아보기” is the journey.
- P3 Measured tokens only. Sacrifice invented metrics, prices, and sibling SKUs. If evidence does not carry a number, the surface stays empty there.

Heading: Components & States

Preset IDs: P-ED-03 (lookbook stages), P-CM-07 (2-up home tiles), P-FN-02 (route focus), P-FN-05 (empty bag). no-preset: global global-nav — capture chrome, not a catalog preset.

Heading: Button (P derived, C1–C10)

Anatomy: label only (no icon on product CTAs). Pill. Min 44×44.

| State | Applicability | Treatment |
| --- | --- | --- |
| default | yes | fill = accent + on-accent, or outline 1px accent |
| hover | yes | fill darkens via `oklch` relative color; outline fills a 8% accent tint |
| focus-visible | yes | 2px accent outline, offset 2px, instant |
| active | yes | scale(0.98) |
| disabled | yes | opacity 0.45 + cursor not-allowed + `disabled` |
| loading | not-applicable | no async submit on this surface |
| error / success | not-applicable | button is not a form validator |

Border-width does not change between states. Focus is outline, not a thicker border.

Heading: Global header

Height 44 desktop / 50 mobile. Background header token. One `nav`. Desktop: inline links. ≤1099px: disclosure button (`aria-expanded`, `aria-controls`). Current destination: `aria-current="page"`. Icon controls (search, bag, menu) are 44×44.

Heading: Product stage / tile

Anatomy: kicker (optional wordmark) → title → lede → actions → optional figure. Media and text share width. Internal gaps 8 / 12 / 24 (title tight to lede; actions separated). Entire tile is not a click target when inner CTAs exist (C25).

Heading: Dialogs (search, bag, unavailable)

Native `<dialog>` with styled `::backdrop`. Empty bag uses P-FN-05 copy in user language. Search has a labelled input restyled from tokens (P0-2).

Heading: Route heading (P-FN-02)

On view change: `document.title`, `scrollTo(0,0)`, focus `#page-title` with visual ring suppressed.

Heading: Layout & Platforms

- Priority: 1440 (capture desktop-1440) → 390 (mobile-390) → 320 → 200% reflow.
- `overflow-x: clip` on the root. `document.documentElement.scrollWidth <= clientWidth` is a product requirement.
- Stages are full-bleed plates; copy sits in a content well `min(980px, 100% - 2*gutter)`.
- Promo grid: 1 column <735px, 2 columns `minmax(0,1fr)` above (G50).
- Touch: primary controls ≥44px.
- 200% reflow: display headings `overflow-wrap: anywhere; min-width: 0`.
- Skip link targets `#main`, never the primary CTA.
- Exactly one `<main>` and one visible `<h1>` per view.
