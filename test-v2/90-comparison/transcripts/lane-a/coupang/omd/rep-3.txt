Heading: 철학

**한 줄 입장.** 이 화면은 광고 히어로가 아니라 **검색으로 물건을 찾는 커머스 크롬**이다.

원칙과 희생:

1. **검색이 유일한 주 과업이다.** 카테고리 서랍·기획전 레일·오늘의 발견은
   홈의 맥락이지 별도 제품 화면이 아니다. 희생: 장바구니·마이페이지·기획전
   상세를 만들지 않는다.
2. **크롬은 측정값, 사진은 역할.** 헤더 높이 70px, 페이지 면 `#fefefe`,
   본문 색 `#212b36` / `#7b7b7b`, 서체 Apple SD Gothic Neo 스택은 evidence
   `chrome`에서 온다. 히어로 사진은 잠긴 역할 — *지금 미는 카테고리와 혜택을
   상품 실물로 보여 준다* — 를 생성 이미지로 채운다. 희생: 스냅샷에 있던
   제조사 로고·공식 워드마크 원본은 복제하지 않는다.
3. **밀도는 카탈로그, 악센트는 신호.** 면 장르는 각진 타일(보더 카드).
   파란 카테고리 판과 검색 테두리만 악센트다. 희생: 라운드 히어로, 퍼플
   그라데이션, 아이콘 타일 3열을 쓰지 않는다.

Heading: 과업 상태 (SELF-WALK)

브리프 동사: **검색창에 질의를 입력해 상품 목록으로 이동한다.**

| 동사 | 키보드 경로 | 프로그램 증거 |
|---|---|---|
| 검색어 입력 | Tab으로 `#q` → 입력 | `input#q` value |
| 제출 | Enter 또는 `data-cta="submit"`에서 Enter/Space | `submit` 핸들러, 빈 값이면 `aria-invalid` + `#q-error[role=alert]` 포커스 복귀 |
| 목록 도착 | 같은 문서에서 `#results` 표시, `#home` `hidden` | `body[data-state=results]`, `h1#page-title-results`에 프로그램 포커스(시각 링 억제, P-FN-02), `document.title` 갱신, `role=status`가 「‘질의’ · 샘플 N건」 |
| 홈 복귀 | 워드마크 Enter | `data-state=home`, 홈 h1 포커스 |

개발자 상태 스위처 없음. `data-state`는 실제 컴포넌트/바디에만 있다.

Heading: 반응형 · 접근성

- 검증 폭: 1440 / 390 / 320. `html { overflow-x: clip }`. 문서 가로 스크롤 금지.
- 터치 타깃 최소 44px (아이콘 검색·카트·카테고리).
- 스킵 링크는 `#main` (주 CTA가 아님).
- 뷰마다 `main` 1, `h1` 1.
- `:focus-visible`만 링. 라우트 헤딩 포커스는 링 없음.
- `prefers-reduced-motion: reduce`에서 전이 제거.
- 한글 `word-break: keep-all`, 디스플레이 `overflow-wrap: anywhere; min-width: 0`.
- 음성 검색은 스냅샷에 아이콘만 있고 동작 증거가 없어 **disabled** +
  “사용할 수 없습니다”. 없는 기능을 있는 것처럼 만들지 않음.

Heading: 이미지

대표 이미지 `image.jpg`는 레인 A 고정 채널(Grok Imagine)로 생성했다.
프롬프트에 브랜드명을 넣지 않았고, 글자·로고를 넣지 않았다.
구도는 스냅샷 히어로와 같다: 전경 음료 실물, 배경 야외 무대.
이 파일이 홈 히어로 `figure`의 `src`다.
