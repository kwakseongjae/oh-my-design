Heading: 쿠팡 홈 — 표면 로컬 디자인 시스템

이 문서는 T3-3 레인 A · coupang ·  · rep-4 산출물의 결정 기록이다. 프로젝트 루트 를 쓰지 않는다(벤치 칸 밖 기록 금지). 권위 클래스는 `surface-local-only`. 스냅샷 handle `2026-08-22T19-48-17-298Z`, 서피스 desktop-1440 (1440×900).

Heading: 철학

검색이 홈의 유일한 주 과업이다. 기획전·추천 레일·오늘의 발견은 그 과업을 가리지 않는 주변 콘텐츠다.

희생:

- P1 검색 우선 — 히어로에 구매 CTA를 두지 않는다. 악센트는 검색 테두리·카테고리 타일·장바구니 배지에만 쓴다.
- P2 캡처에 없는 값은 비운다 — 닫힌 카테고리 트리, 장바구니 화면, 로그인 흐름을 만들지 않는다.
- P3 상품은 카드로, 문서는 문장으로 — 커머스 장르(P-CM-01, P-CM-07 축소)를 유지하되 벤토를 데이터 없이 억지로 채우지 않는다.

주석은 결정 ID. 구현은 `render.html` `:root`와 같다.

```css
--color-paper: oklch(0.985 0.008 85);          
--color-ink: oklch(0.285 0.025 251);           
--color-accent: oklch(0.58 0.20 264);          
--color-brand: oklch(0.46 0.116 44);           
--color-muted: oklch(0.58 0.012 250);          /* 캡처 p #7b7b7b를 틴트 */
--radius-control: 2px;                         
--radius-card: 4px;                            
--header-search: 44px;                         /* 터치 타깃 */
--space-section: 2.5rem;                       /* 섹션 공기 */
--well: 1020px;                                /* 초광폭 = 좌측/중앙 웰, 히어로만 풀블리드 */
--duration-fast: 120ms;
--duration-base: 200ms;
```

전경/배경 쌍: paper↔ink, accent↔accent-ink, promo-b↔promo-b-ink, 히어로 scrim↔on-dark.

Heading: 컴포넌트 명세

프리셋 사용: `P-FN-01` 검색 범위 리스트박스, `P-FN-02` 목록 전환 포커스, `P-FN-05` 빈 결과, `P-FN-06` 결과 수 정의, `P-CM-01` 결과 카드. 히어로는 no-preset: 스냅샷이 풀블리드+우측 레일 오버레이라 벤토(P-CM-07) 최소 칸을 채울 수 없음.

| 컴포넌트 | 해부 | 상태 | 접근성 |
|---|---|---|---|
| 검색 폼 | 범위 트리거 · 입력 · 제출 | idle / error / focus-within | `role="search"`, label[for=q], 에러는 alert+aria-invalid+describedby+포커스 |
| 범위 리스트박스 | P-FN-01 | default / hover / expanded / option active·selected | 트리거 포커스 유지, aria-activedescendant, Escape=취소, 열린 동안 Enter는 폼 제출 안 함 |
| 카테고리 버튼 | 아이콘+라벨 88×88 | default / hover / expanded / disabled | 닫힌 패널은 부재 문장. 과업 경로 아님 |
| 워드마크 | 텍스트 `coupang` | hover | 홈으로. 공식 마크 원본 없음 |
| 히어로 | 생성 사진 + 카피 오버레이 + 레일 | 레일 aria-current | 사진 alt는 피사체 설명. 장식 썸은 aria-hidden |
| 상품 카드 | 플레이트 · 브랜드 · 이름 2줄 · 가격(최대 웨이트) · 메타 | hover 면 전환 | 전체 클릭 CTA 없음(목록이 과업 종점) |
| 빈 결과 | 문장 + 조건 지우기 1개 | — | P-FN-05 |

입력 높이 = 인접 제출 버튼. 보더 두께는 상태 간 2px 고정, 포커스는 outline.

Heading: 레이아웃 문법

홈 = **풀블리드 히어로 + 우측 레일 오버레이**, 폴드 아래 **2열 발견 타일**. 콘텐츠 역산: 히어로 사진 1(생성), 레일 항목 6(캡처 라벨), 발견 타일 2+2(캡처 문구). 와이드 전략은 히어로 전폭, 크롬·발견은 1020px 웰.

상품 목록 = **4열 카드 그리드**(900 미만 2열, 640 미만 1열). 캐러셀 문법 사용 안 함(GS6).

320 / 390 / 1440에서 문서 가로 스크롤 없음(`overflow-x: clip`). 히어로 `figure` 마진 리셋 — UA `figure { margin: 1em 40px }`가 폭을 밀어 실측 파손한 전례가 있다.

Heading: 과업 상태 (SELF-WALK)

브리프 동사: **검색창에 질의를 입력해 상품 목록으로 이동한다.**

| 동사 | 키보드 경로 | 프로그램 증거 |
|---|---|---|
| 질의 입력 | Tab으로 `#q` 도달, 문자 입력 | 입력 값 |
| 상품 목록으로 이동 | Enter(제출) 또는 검색 버튼 Space/Enter | `home-view[hidden]`, `results-view` 표시, `h1` = `{질의} 상품 목록`, `document.title` 갱신, h1 포커스(시각 링 억제) |
| 빈 질의 거부 | 빈 채 Enter | `data-state="error"`, `aria-invalid`, `#search-error[role=alert]`, 포커스 유지 |
| 0건 | 목록에 없는 질의 | `data-state="empty"`, 조건 지우기 버튼 |
| 범위 | 리스트박스 화살표·Enter | `aria-selected` / `aria-expanded` |

개발자 상태 스위처 없음.

Heading: 정직 경계

- 공식 로고 원본 없음 → 텍스트 워드마크.
- 카테고리 트리 없음 → 패널에 부재 문장.
- 로그인·장바구니·마이쿠팡 화면 없음 → 눌러도 이동하지 않고 짧은 안내.
- 상품 사진은 대표 1장만 생성. 카드 미디어는 토큰 플레이트.
- 가격은 캡처에 보인 것만. 푸터에 보기용 한 줄.

Heading: 가정과 한계

- 스냅샷 첫 뷰포트의 히어로는 시원청량 페스티벌(야외 공연 + 음료 실물). 같은 캐러셀의 R.LUX 컷은 보조 캡처에만 있어 대표 이미지로 쓰지 않았다.
- evidence 이미지 표본 다수가 로딩 전 흰 프레임이라 팔레트 평균 휘도가 높다. 대표 이미지는 보이는 히어로 피사체를 따른다.
- 네트워크 요청 없음. 폰트는 로컬 한글 고딕 스택.
- 이 시스템은 벤치 칸의 `render.html`만 구속한다. 다른 화면을 추가하지 않는다.
