Heading: 쿠팡 홈 검색 표면 Design System

스냅샷 `2026-08-22T19-48-17-298Z` · 표면 desktop-1440 (1440×900) · 과업: 검색창에 질의를 입력해 상품 목록으로 이동한다.

이 문서는  유도 사슬(철학 → 결정 표 → 토큰 → 컴포넌트 명세 → 레이아웃 문법)의 런 산출이다. 프로젝트 루트 는 실험 칸 밖 쓰기가 금지되어 여기에 적는다.

Heading: 철학

**검색이 홈의 일이다.** 쿠팡 홈은 캠페인 사진이 넓지만, 이 런의 성공은 검색창에서 질의를 넣고 상품 목록에 도착하는 한 동작이다.

- **P1 검색 우선.** 한 화면의 제출 동사는 「검색」 하나다. 로그인·장바구니·상세는 과업 밖이므로 새 화면으로 열지 않는다. 얻는 것: 키보드로 끝나는 과업. 버리는 것: 쇼핑몰 전체 맵.
- **P2 카탈로그 밀도.** 커머스는 카드 경계와 가격 위계로 읽힌다. 얻는 것: 목록에서 상품이 물건으로 보인다. 버리는 것: 매거진 여백, 둥근 위젯 키트.
- **P3 스냅샷만 데이터.** 이름·가격·배지는 캡처 홈에 보인 값만 쓴다. 평점·후기 수·재고는 스냅샷에 없어 비운다. 얻는 것: 정직한 목록. 버리는 것: 채워 넣은 별점.

Heading: 컴포넌트 명세

프리셋 우선 (GS8).

Heading: 검색 필드 (no-preset: 쿠팡 홈 검색창 — 카탈로그에 커머스 검색 콤보 없음)

해부: 범위 리스트박스 | 입력 | 제출(돋보기). 높이 `--control-h`. 보더 1px accent, 상태 간 보더 두께 불변. 포커스는 `outline`. 레이블은 입력 옆 스크린리더용으로 유지(C12). 빈 제출은 blur가 아니라 submit에서 검사, 포커스 복귀 + `aria-invalid` + `role="alert"` (C16).

상태: default / hover / focus-visible / error / disabled. loading 없음(로컬 필터).

Heading: 범위 리스트박스 — P-FN-01 파생, 토큰  /

옵션: 전체, 여성패션, 남성패션, 식품. 트리거+listbox, `aria-activedescendant`, Escape=취소, Enter/Space/Tab=커밋.

Heading: 상품 카드 — P-CM-01 파생, 토큰  /  /

해부: 미디어(1:1, minmax(0,1fr)) → 카테고리 eyebrow → 이름 2줄 클램프 → 가격(있으면 최대 웨이트) → 배지 한 줄. 내부 CTA 없음(C25). 평점 행 없음().

Heading: 필터 칩 — P-FN-04 파생

홈 여성패션 키워드. 활성은 면 반전. 히트 ≥44px. 「전체」가 기본.

Heading: 빈 결과 — P-FN-05

「이 검색어의 상품이 없습니다」 + 검색어 지우기 한 개.

Heading: 결과 수 — P-FN-06

「전체 · 「질의」 상품 N건 · 수록된 순서」.

Heading: 라우트 포커스 — P-FN-02

목록 진입 시 `#page-title`에 프로그램 포커스, 시각 링 억제, `document.title` 갱신, `scrollTo(0,0)`.

Heading: 레이아웃 문법

**홈: 크롬 + 히어로 디픽(캠페인 컷 / 레일) + 발견 2칸 + 카테고리 모듈(좌 플레인트 + 우 2×2 카드).**

콘텐츠 역산: 히어로 레일 6칸(캡처), 발견 2칸, 여성패션 카드 4칸. 벤토 5칸 문법은 쓰지 않는다(GS6). 초광폭 전략: 좌측 맥스 크롬, 본문 중앙 최대 1440.

**목록: 결과 정의 라인 + 4열 카드 그리드.** 고정 브레이크 1/2/4열, `auto-fit` 금지.

Heading: 과업 동사 (SELF-WALK)

| 동사 | 키보드 | 프로그램 증거 |
|---|---|---|
| 검색창에 질의를 입력한다 | Tab으로 `#q` → 입력 | `#q` value, `data-state` on form |
| 상품 목록으로 이동한다 | Enter 또는 검색 버튼 Space/Enter | `body[data-view=results]`, `#page-title` 텍스트, `role=status` 「N건」, 카드 리스트 |

빈 질의 제출은 에러 상태(포커스+alert+aria-invalid). 0건은 P-FN-05.

Heading: Experience

- 범위: 쿠팡 홈(desktop-1440)과 그 홈에서 출발하는 검색 결과 목록.
- 주 과업: 검색창에 질의를 입력해 상품 목록으로 이동한다.
- 지원 로케일: ko-KR.
- 만들지 않는 것: 로그인, 장바구니, 상품 상세, 결제, 브리프에 없는 추가 랜딩.

Heading: Foundations

위에 적은 색·간격·모양·모션. 대비율: 본문 ink/paper ≥4.5:1, 큰 제목·아이콘·포커스 ≥3:1. 악센트 면에는 `--color-on-accent`.

Heading: Typography & Assets

- 패밀리: `"Pretendard Variable", Pretendard, "Apple SD Gothic Neo", "Noto Sans KR", "Malgun Gothic", sans-serif`. 네트워크 폰트 없음.
- 대표 이미지: `image.jpg` (Grok Imagine, 페스티벌 피크닉, 로고 없음). 홈 히어로 LCP.
- 상품 미디어: 인라인 SVG/CSS. 캡처 원본 사진·공식 로고 파일 사용 안 함.
- 아이콘: 한 스트로크 SVG.

Heading: Layout & Platforms

- 우선 뷰포트: 1440×900 (evidence). 검증 폭 320 / 390 / 1440. 200% 리플로우에서 문서 가로 스크롤 없음.
- `overflow-x: clip`. 그리드 트랙 `minmax(0, 1fr)`.
- 터치 타깃 짧은 변 ≥44px.
- 히어로 `min-height: 100vh` 금지.

Heading: Content & Locales

- 언어: 한국어. `html lang=ko`. `word-break: keep-all`.
- 가격: 천 단위 + `원`.
- 보이스: 짧은 안내, 반말 금지, 구현 단어 금지.
- 정직 문장(푸터): 이름·가격의 출처와 평점 부재.

Heading: Governance

- 출처 등급: chrome·카피는 `repository-fact`(evidence). 생성 히어로는 `agent-proposed-greenfield-decision`(구도만 증거, 피사체는 새로). 미해결 평점은 `unresolved` → 토큰/카피/UI에 값 없음.
- 권한: 이 런 디렉터리만 기록. 루트  채택 없음.
- 변경: 검색 과업이 깨지면 시각보다 동선을 고친다.
