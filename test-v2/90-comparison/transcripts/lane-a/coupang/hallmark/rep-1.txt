Heading: Type

Single grotesque family is the captured chrome, not a pairing failure. Headings are weight 800 against body 400 (300+ contrast). No italic on any heading, wordmark, or rail label. Prices use `font-variant-numeric: tabular-nums`. Display heads wrap with `overflow-wrap: anywhere; min-width: 0`. Body measure on running copy stays inside 45–75ch; product names are short labels, not prose.

Scale used on the page: xs 11px · sm 13px · base 16px · md 20px · lg 24px · xl 28px. Captured `h2` 24px / `h3` 20px / caption 11px sit on that scale.

Heading: Chrome

- **Promo (N12 banner).** Two cells. Dismiss zeroes `--banner-h`. Scroll-down retracts the banner; scroll-up restores it.
- **Search bar (task).** Visible label is visually hidden; the field is the affordance. Scope select + query + submit. Height matches the submit control (`--input-h` 44px). Border width stays 1px in every state; focus uses outline, not extra border. Empty submit: `aria-invalid`, help text “검색어를 입력한 뒤 검색을 눌러 주세요.” Non-empty submit: same-document product list.
- **Category.** Blue slab opens a three-column mega panel (click, Escape, scrim). Not a second page.
- **Cart.** Native `<dialog>`. Empty state points back to search. Badge `0`.
- **Wordmark.** Text `coupang` in `--color-brand`. No official logo file, no smile graphic.

Heading: Layout

Asymmetric fold: still full-bleed, copy left, rec rail right. Not a centred 100vh hero. Grid tracks that carry images use `minmax(0, 1fr)`. Root `overflow-x: clip` on `html` and `body`. UA reset includes `figure, blockquote, ul, ol { margin: 0 }`. No `100vw`. Clickable labels are `white-space: nowrap`. Section heads stack vertically (no tag-left / heading-right).

Breakpoints: 60rem (rail shrinks, 2-up grid), 40rem (promo one cell, category icon-only, rec rail stacks, 1-up grid). Hit targets stay ≥ 44px on coarse pointers.
