Heading: 표면

앵커 휴는 파랑 264°. 종이는 거의 흰 냉색, 순백 `#fff`와 순흑 `#000`은 쓰지 않는다.

- paper `oklch(99.2% 0.004 264)` — 실측 모달색 `#fefefe`에 가깝게, 휴만 살짝
- ink `oklch(18% 0.022 264)`
- muted `oklch(48% 0.022 264)` — 본문 보조. 실측 p 색 `#7b7b7b`
- accent `oklch(58% 0.16 264)` — 검색 테두리, 장바구니 숫자, 포커스
- accent-ink `oklch(99% 0.01 264)` — 액센트 면 위의 글
- category `oklch(62% 0.17 264)` / category-ink — 왼쪽 카테고리 슬래브
- wordmark `oklch(55% 0.13 58)` — 갈색 글자 마크
- promo-a 차가운 시안 띠, promo-b 탁한 회청 띠
- error / success는 검색 상태에만

액센트 발자국은 검색 테두리·카테고리 슬래브·배지로 제한한다. 히어로를 액센트로 채우지 않는다.

Heading: 글자

네트워크 폰트를 불러오지 않는다. 실측 패밀리 Apple SD Gothic Neo를 표시/본문에 같이 쓰고, 가격만 모노 아웃라이어.

- display / body: `"Apple SD Gothic Neo", "Noto Sans KR", "Malgun Gothic", sans-serif`
- outlier (가격, 한 자리): `ui-monospace, "SF Mono", Menlo, monospace`
- 제목은 로만, 이탤릭 헤더 없음
- 크기: 본문 16px, 제목은 굵기로 구분. 히어로 캠페인 제목은 `--text-display-s` (길이가 짧음)
- 숫자: `tabular-nums`
- 실측 타입: h2 24/700, h3 20/400, p 11/400. 11px는 유틸 바에만 쓰고 본문 바닥은 16px

Heading: 간격 · 레이아웃

4pt 스케일 `--space-3xs` … `--space-3xl`. 페이지 축은 왼쪽(카테고리 슬래브)에서 가운데(검색)로 기운다. 히어로는 전폭 사진, 오른쪽 기획 레일은 사진 위에 얹는다. 그리드 트랙은 `minmax(0, 1fr)`. `html`/`body`는 `overflow-x: clip`. `100vw` 없음.

z: base 1 · raised 10 · dropdown 100 · sticky 200 · sticky-nav 300 · modal 400.

Heading: 움직임

Photographic는 기본 정지. 이 페이지의 움직임은 두 가지뿐이다.

1. N12 배너가 아래로 스크롤되면 위로 접힌다 (`transform`)
2. 검색 제출 중 버튼 스피너, 최소 320ms

호버 확대 없음. `transition-all` 없음. 포커스 링은 즉시. `prefers-reduced-motion: reduce`면 공간 이동을 150ms 불투명으로 줄인다.

Heading: 상태 (검색)

입력과 검색 버튼은 한 높이 `--control-h` 2.75rem. 테두리 두께는 모든 상태에서 1px.

| 상태 | 처리 |
| --- | --- |
| default | 액센트 1px 테두리, 종이 배경 |
| hover | 종이-2 배경, 테두리 두께 유지 |
| focus-visible | 2px 포커스 아웃라인, 오프셋 1px, 즉시 |
| active | 버튼 1px 내려앉음 |
| disabled | 투명 0.55 + not-allowed + disabled |
| loading | 스피너, 제출 잠금, 칸은 수정 가능 |
| error | 테두리 error, 도움말: 무엇을 입력해야 하는지 |
| success | 테두리 success, 목록이 결과 |

빈 제출: “검색어를 입력해 주세요. 빈 칸으로는 상품을 찾지 못합니다.”
결과 없음: 다른 단어를 권한다. 꾸며낸 전환율·회원 수 없음.
가격이 스냅샷에 있던 네 점만 숫자를 적고, 나머지는 `—`.
