Heading: Space and motion

4pt scale `--space-3xs` … `--space-3xl`. Easings: `--ease-out`, `--ease-in`, `--ease-in-out`. Durations: 120 / 220 / 420ms. Animate `transform` and `opacity` only. `prefers-reduced-motion: reduce` collapses spatial motion to ≤150ms. Focus rings are instant, 2px `--color-focus`, never animated.

Heading: Search — the job

The CTA is the form (C2). Scope select + query + submit share one 44px-tall control. Border width stays 1px in every state.

| State | Treatment |
| --- | --- |
| default | paper fill, accent ring on the form |
| hover | paper-2 fill on the field |
| focus-visible | 2px focus outline, offset 1px |
| active | same as focus |
| disabled | opacity 0.55, not-allowed, native disabled |
| loading | data-state on the form |
| error | error border colour + hint (“검색어가 비어 있습니다…”) + aria-invalid |
| success | lands on the product list; silent besides the list itself |

Empty submit stays on home. A non-empty query hides home and shows a product list in the same file. No network. Wordmark returns home.
