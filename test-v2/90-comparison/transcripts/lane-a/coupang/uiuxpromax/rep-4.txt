Heading: Layout (1440)

- Page canvas 1440, inner 1020 centered
- Order (pack marketplace + captured home): promo pair → utility → header (category, wordmark, **search**, my, cart) → shortcut rail → hero + right merchandising rail → 오늘의 발견
- Search remains in the header on the listing view
- Breakpoints if the window shrinks: 1024 / 768 / 375. First paint is desktop-1440
- CSS reset zeros `figure`, `blockquote`, `ul`, `ol` margins (UA defaults broke measurement)

Heading: Search task

1. Visible label (`sr-only` “상품 검색”) + `role="search"`
2. Category select “전체” is a filter on the same field, not a new screen
3. Suggestions listbox while typing (pack autocomplete)
4. Submit (Enter or magnifier, 44×40 hit target) → home merchandising hides, listing shows
5. Non-empty query always yields a product list (catalog hits, then query-titled fillers)
6. Empty submit → empty state with a next action (focus the field / pick a suggestion). No blank page
7. Wordmark returns home
8. No login, cart, or PDP screens

Heading: Anti-patterns not used

Emoji as chrome icons; placeholder-only field; Google Fonts / CDN; official logo file; pack purple wash on a white captured chrome; extra screens outside home + search list; hover-only primary action.
