| Component | Spec |

| Featured | “오늘의 발견” two cards + side tiles |
| Results | Same header; product **list** (not a second branded site); skeleton 180ms then rows; empty query stays on home with live message |

States: default / hover / focus-visible / loading (skeleton) / empty query. Disabled not used on the search submit.

Heading: UX rules applied

- Search autocomplete (do not require full type + enter only)
- `aria-label` on icon-only controls (search, mic, cart count)
- Keyboard: form submit, skip link, focus ring 2–4px
- Loading >300ms pack rule → 180ms skeleton; 0ms if reduced-motion
- No-results path: blank query does not navigate; live region asks for a query
- `cursor: pointer` on clickable nodes
- Tabular figures on prices
- `ul`/`ol`/`figure`/`blockquote` margin reset (UA defaults broke measurement)

Heading: Out of scope

No extra screens (login, cart, category tree as pages). Utility links are in-page anchors on home. Product list is the task destination after search, not a separately briefed surface.

Heading: Assets

- Icons: inline SVG (pack: Phosphor/Heroicons, no emoji as icons)
- Hero still: `image.jpg` via Grok Imagine, 16:9, no letters in the bitmap
- No `url(http…)` in CSS, no font CDN, no third-party scripts
