Heading: Coupang Home — design system

Snapshot `2026-08-22T19-48-17-298Z`. Surface `desktop-1440` (1440×900). Task: type a query in the home search field and land on a product list.

This document is the system the first render implements. It was produced by the  pack workflow (Step 2 `--design-system`, then domain searches for `ux` / `color` / `style` / `typography` / `icons` / `landing`, then `--stack html-tailwind`), then grounded on the captured chrome so the page stays a marketplace home rather than a generic purple template.

Heading: Typography

- **Render stack:** evidence family, system fallbacks. No `@import`, no CDN.
- **Pack pairing (when network is allowed):** Rubik (heading) + Nunito Sans (body), `display=swap`. Not shipped in `render.html`.
- Scale used: 11 / 12 / 13 / 14 / 16 / 20 / 24 / 32 / 48 (hero title only).
- Body line-height 1.5. Product titles `-webkit-line-clamp: 2`. Prices `font-variant-numeric: tabular-nums`.
- Hero title is display size; it is not a second h1. Page h1 exists on the results view; home uses the wordmark + hero h2.

Heading: Layout

Desktop 1440 (the captured surface):

1. Two-up promo strip (로켓배송 안내 / 물티슈).
2. Utility bar (즐겨찾기 · 입점 · 로그인 · 가입 · 고객센터 · 판매자).
3. Header: category block, text wordmark, search, 마이쿠팡, 장바구니.
4. Shortcut row.
5. Campaign hero (generated photograph) + right rail.
6. 오늘의 발견.

Width: header/today/results content `1020px` centered; hero is full bleed. Breakpoints 768 / 1024 / 1440 (pack layout rule). Mobile stacks the rail under the photograph, collapses utility, and keeps search ≥44px.

Reset includes `figure, blockquote, ul, ol { margin: 0 }` so UA list/figure margins cannot shift the measured header or hero.

Z-index is the token scale above. Dropdowns (`suggest`, category panel) sit at `--z-dropdown`; they do not fight the rail.

Heading: Components and states

Icons are inline SVG in the Phosphor regular stroke language (pack default). No emoji glyphs as structure.

| Component | Default | Hover | Active / open | Disabled | Notes |
|---|---|---|---|---|---|
| Category button | `--color-primary`, 112×112 | `--color-blue-700` | `aria-expanded=true`, same hover fill | — | Disclosure; not a new route |
| Search field | 2px primary border, 44px | — | Focus-visible ring | Submit disabled while listing loads | Visible `<label class="sr-only">` |
| Search submit | Icon button 40×40 | Tint `#eef3ff` | Press scale via :active on hero CTA only | Spinner + `disabled` | Loading >300ms rule |
| Suggestion list | Hidden | Row `#f6f8ff` | — | — | Pack: do not require full type+enter |
| Cart | Outline icon + badge `0` | Primary color | — | — | Chrome only; no cart screen |
| Hero CTA | White pill on photo | Scale 1.02 / 180ms | Scale 0.98 | — | Runs the same search task |
| Rail item | White row, 62px min | `#fafafa` | `.active` 2px primary outline | — | Current campaign outlined |
| Product card | White, 1:1 swatch | — | — | — | Listing only; no product-detail route |
| Filter chip | Border gray | — | `aria-pressed=true`, primary border | — | 전체 / 로켓배송 |
| Empty state | Centered copy + chips | — | — | — | Pack: never a blank “0 results” |

Motion: 150–300ms, ease-out on enter, `transform`/`opacity` only. `@media (prefers-reduced-motion: reduce)` collapses duration.

Heading: Search task

This is the only functional journey.

1. Focus the labelled search field (or pick a suggestion / rail / promo / 오늘의 발견 tile).
2. Submit. Hash becomes `#/search?q=…` (pack deep-link guideline).
3. Home unmounts; listing view mounts. Submit is disabled and a status region (`aria-live="polite"`) announces progress for ~320ms.
4. Matching products render in a 4-column grid (2-column under 768px). Rocket filter is a chip, not a second page.
5. Zero hits: message that names the query + suggestion chips that re-run search.
6. Wordmark returns `#/` (home). Back is the browser hash.

No login, cart, PDP, or seller dashboard screens.

Heading: Accessibility (pack §1–§3, html-tailwind stack)

- Skip link to `#main`.
- Search has a visible-to-AT label (`for="q"`).
- Icon-only controls have `aria-label`.
- Focus-visible 2px ring in `--color-ring`; focus outline is never removed without a replacement.
- Touch targets ≥44px on search, category, account, hero CTA, rail rows, chips.
- Color is not the only state signal (outline, weight, text).
- Results status is a live region.
- Contrast: body `#000` on `#fff`; muted `#7b7b7b` is 11px caption only; primary blue on white for borders/icons, white on primary for the category block.
- `lang="ko"`. Keyboard submit on the form. Category panel closes on outside click; it is not a focus-trapped modal because it is not a route.
