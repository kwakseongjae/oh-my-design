Heading: NAVER home — design system

run for the home search task. Offline first render. Snapshot `2026-08-22T19-51-00-372Z`. Chrome numbers come from . Copy on the home is only what that capture shows.

Going with: audience = people who open the portal to look something up · use = type a query and land on results · tone = utilitarian.

Heading: Position

The page is a search portal, not a marketing landing. The fold’s job is the query field. Rails under it (shortcuts, newsstand, login) are discovery surfaces. That is why the macrostructure is **Ecosystem Index**, not a hero statement.

Heading: Type

Evidence family is `-apple-system` at 14.7 px / weight 500–700 / tracking `-0.4px`. The first render cannot fetch a webfont, so the stack is the platform gothic that that family already is:

`--font-display` / `--font-body` = `"Apple SD Gothic Neo", "Noto Sans KR", "Malgun Gothic", ui-sans-serif, sans-serif`

One family on purpose (austere portal chrome). Headings stay roman. Body floor is 16 px; compact chrome uses `--text-sm` (14 px), nearest to the measured 14.7 px. Tracking `-0.025em`.

Heading: Space, radius, motion

4 pt scale `--space-3xs` … `--space-3xl`. Control height 44 px (`--control-h`). Search field 52 px to sit on the same row as the green ring. Pill radius on the field; `--radius-sm` on modules. Easings `--ease-out` / `--ease-in` / `--ease-in-out`. Durations 120 / 220 / 420 ms. `prefers-reduced-motion: reduce` collapses spatial motion to 150 ms.

Heading: Layout

- Sticky N12: cream banner, then hamburger + pay + search + (desktop) alert/cart.
- Desktop ≥ 60 rem: shortcut row; board `1.65fr / 0.9fr` (promo+newsstand | login+shopping chrome).
- Promo: copy left, `image.jpg` right. Mobile stacks copy then image. Image tracks use `minmax(0, 1fr)`.
- Newsstand: tab row from the capture; press grid 2 / 3 / 6 columns. Tabs that have no list in the snapshot open an honest empty line instead of invented articles.
- Results replace the home `<main>` in the same file. No extra product screens.

`html` and `body` use `overflow-x: clip`. Reset zeroes `figure`, `blockquote`, `ul`, `ol` margins (UA defaults broke measurement elsewhere).

Heading: Components and eight states

Search form, search submit, AI chip, icon buttons, login, press cells, shortcuts, and banner download each have default · hover · `:focus-visible` · `:active` · disabled · loading · error · success. Input border width does not change between states; focus uses `outline`. Empty submit writes “검색어가 비어 있습니다. 단어를 입력한 뒤 검색을 눌러 주세요.” Success is silent: the results main appears.

Wordmark is the letter **N** and the word **NAVER**, not a logo file.
