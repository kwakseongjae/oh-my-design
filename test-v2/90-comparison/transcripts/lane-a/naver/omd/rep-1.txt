Heading: 네이버 홈 표면 시스템

스냅샷 `2026-08-22T19-51-00-372Z` · 화면 홈 · 과업: 검색어를 입력해 검색 결과로 이동한다.

프로젝트 루트  쓰지 않는다. 이 문서가 이번 런의 시스템 설명이다.

Heading: Philosophy

검색이 유일한 과업인 포털 보드. 한 칸의 입력으로 결과 화면에 닿게 하고, 나머지 모듈은 스냅샷에 보인 정보판이다.

1. **검색이 먼저다.** 얻는 것: 브리프 동사(입력 → 이동)가 키보드만으로 닫힌다. 희생: 메일·카페·로그인 같은 스냅샷 크롬은 새 화면을 열지 않는다.
2. **스냅샷이 데이터 천장이다.** 얻는 것: 기사·가격·건수를 지어내지 않는다. 희생: 엔터/스포츠 칸과 쇼핑 9페이지는 빈 칸으로 남긴다.
3. **헤어라인 보드.** 얻는 것: 포털 홈의 밀도. 희생: 히어로 스택, 그라데이션, 센터드 랜딩.

장르: 라운드 외곽선 보드(hairline-rule boards). 악센트는 검색 링과 로그인 채움 신호.

와이드 전략: 컬럼 추가 — 좌 콘텐츠 스택 + 우 유틸/광고 22rem, 최대 72rem 중앙.

Heading: Components

- **검색 필** — no-preset: 포털 검색 필은 카탈로그에 없음. C11–C16. 라벨 `검색어`(sr), 플레이스홀더 스냅샷 문구, 제출 `검색 결과로 이동` (`data-cta="submit"`). 상태: default / hover(칩) / focus-visible(아웃라인, 보더 두께 불변) / error(링+alert+aria-invalid) / loading(면 칩+제출 disabled) / disabled(로딩 중).
- **커스텀 리스트박스** — P-FN-01. `전체언론사` + 현재 페이지 언론사. Escape는 값 유지 취소.
- **빈 결과** — P-FN-05. 정직한 문장 + 검색어 지우고 홈으로.
- **결과 수** — P-FN-06. 「수록된 순서 · N건」.
- **결과 행** — P-FN-03 가로형 미디어 카드. 매트리스 항목만 `image.jpg`.
- **라우트 포커스** — P-FN-02. `#page-title` 포커스, 시각 링 억제, `document.title` 갱신, 스크롤 리셋.
- **뉴스스탠드 탭** — 스냅샷 라벨. 언론사편집만 데이터, 나머지 칸은 정직한 빈 상태.
- **로그인** — 스냅샷 카피. `data-cta="primary"`. 화면 추가 없음.
- **웨일 다이얼로그** — 스냅샷 카피. 마스코트 원본 대신 문자 `W`. 닫기 가능.

아이콘은 한 스트로크 SVG. 공식 로고 경로·이미지 없음. 워드마크는 `N` / `NAVER` / `pay` / `SUMMIT`.

Heading: Layout grammar

**홈:** 2컬럼 포털 보드. 좌: 프로모(카피|피겨 디프틱) → 뉴스스탠드 그리드 → 쇼핑 크롬. 우: 로그인 → 분양 플레이트 → 라이프워크 띠. 콘텐츠 역산: 언론사 셀 24×2(두 프레임), 바로가기 11, 프로모 이미지 1.

**검색 결과:** 같은 헤더 아래 단일 컬럼 리스트. 홈 보드를 숨기고(`hidden`+`inert`) 결과만 연다.

반응: 320 / 390 / 1440, 200% 리플로우. `overflow-x: clip`. 터치 타깃 ≥44px.

Heading: States (journey verbs)

브리프 동사: **검색어를 입력해 검색 결과로 이동한다.**

| 상태 | 도달 | 기계 증거 |
|---|---|---|
| default | 첫 페인트, 홈 | `form[data-state=default]`, `main[data-state=home]` |
| error | 빈 제출 | `aria-invalid`, `#search-help[role=alert]`, 포커스 필드 |
| loading | 질의 제출 직후 | `form[data-state=loading]`, 제출 `disabled` |
| success | 질의 일치 | `main[data-state=results]`, 건수 라인, 결과 행 |
| empty | 질의 불일치 | `.empty[data-state=empty]`, 해제 버튼 |
| disabled | 로딩 중 제출, 첫/끝 페이지 화살표 | `disabled` + `cursor: not-allowed` + 색 뮤트 |

키보드: Tab → 검색어 → Enter. 또는 Tab → `검색 결과로 이동`.
