Heading: Philosophy

One job on the first screen: put a query in the search field and go to results. A Korean portal is a dense instrument, not a campaign landing.

| ID | Principle | Gain | Sacrifice |
|---|---|---|---|
| P1 | Search is the only first-screen job | The field is the largest control, always in the first fold, keyboard-submittable | No 100vh story, no second primary CTA in chrome |
| P2 | Portal density, not gallery | Shortcuts, login, newsstand share the 1440×900 fold the way the snapshot does | Display type is used only in the campaign line (~2× body), never as a page-title poster |
| P3 | Reconstruct without trademark files | Green ring, letter N, word “NAVER”, shortcut row, login slab | Official logo assets are not used; N is a typed letter |

Heading: Component specs (before code)

Presets used: **P-FN-01** (언론사 listbox), **P-FN-02** (results heading focus, outline suppressed), **P-FN-04** (뉴스스탠드 탭), **P-FN-05** (empty query), **P-FN-06** (result count line). **P-FN-03** for the campaign copy/figure row. **no-preset: search-pill** — catalog has no portal search field; anatomy below. **no-preset: shortcut-rail** — snapshot K2 is a labeled icon row, not P-CM-01.

Heading: Search pill (no-preset)

- Anatomy: typed N (submit) · text field · AI local action. Height `--control-height`. Radius `--radius-pill`. Border 2px `--color-accent` in all states (width does not change, G39).
- States: default / hover (chip fill) / focus-visible (offset ring, instant) / error (`aria-invalid` + `role="alert"`) / disabled (opacity + `cursor: not-allowed` + `disabled`).
- Label `검색어` is visually present (clipped into the form, not placeholder-only — C12). Placeholder copies the snapshot: `검색어를 입력해 주세요.`
- Submit accessible name is the brief verb: `검색 결과로 이동`. `data-cta="submit"`.
- Empty submit: focus returns to `#q`, alert “검색어를 입력해 주세요.” (C16 three channels).

Heading: Layout grammar

Page: **portal split** (left instrument, right account). Not magazine, not bento, not master-detail.

Content back-calc: shortcuts ≥10 (snapshot has 10+more), newsstand 24 names (6×4), campaign 1 copy + 1 figure, results ≥4 rows after a query. Ultra-wide strategy: **center max 1280**.

Fold at 1440×900: whale strip, search (K1), shortcuts (K2), login (K3), campaign + newsstand start (K4). Below fold allowed: more news rows, shopping rail, footer.

390×844: single column, search full width **inside** the padding (the source mobile frame clips the field; we do not). Campaign figure hidden. Login after news. Shortcuts wrap, no horizontal document scroll.

320px and 200% reflow: `overflow-x: clip`, `minmax(0,1fr)`, display headings `overflow-wrap: anywhere; min-width: 0`.

Heading: Journey verbs (SELF-WALK)

| Verb | Keyboard path | Programmatic evidence |
|---|---|---|
| 검색어를 입력해 | Tab to `#q`, type | `value` non-empty; `aria-invalid=false` |
| 검색 결과로 이동한다 | Enter on `#q` or Space/Enter on submit | `data-view="results"` on `body`; `#page-title` focused; `document.title` contains the query; `role="status"` names the query |
| empty reject | Enter with empty field | `aria-invalid=true`; `#q-error[role=alert]` visible; focus stays on `#q` |

No developer state switcher (P0-1).
