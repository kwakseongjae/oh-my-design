Heading: Components and states

Search field (anatomy from pack Input spec, lg size):
visible label (sr-only `검색어`) + placeholder + leading wordmark submit + trailing 입력기 / AI.
States: default, hover (tools), focus-within (ring), error (destructive border + `role="alert"`), disabled/loading (submit disabled while `aria-busy`).

Suggestions: listbox, debounce 150ms, ArrowUp/Down + Enter, Escape closes. Pack UX: do not require a full type-and-enter with no predictions.

Login: primary button (pack Button default/lg). Links are tertiary.

Newsstand: outline card + 6-col (3-col mobile) publisher grid, text names only.

Promo figure: local `image.jpg`, width/height + `aspect-ratio: 16/9` (CLS). `object-fit: cover`.

Icons: Phosphor-style outline set (pack default library), inline SVG sprite, explicit `width`/`height`. No emoji as structure. No official logos.

Heading: Search interaction (the assigned task)

1. Focus the pill. Label is not placeholder-only.
2. Type → suggestions (pack Search / Autocomplete).
3. Empty submit → stay on home, alert “검색어를 입력해 주세요.”, focus returns to the field.
4. Non-empty submit (Enter, `N`, or AI chip) → `#search?q=…` (hash so file:// back-button works; pack Navigation / Back Button).
5. ≥300ms loading line, then results. Submit is the only primary CTA on the home hero.
6. Results keep the same field. `NAVER` wordmark returns to `#home`. Related chips re-enter search. Result rows are not extra product screens and do not fetch the network.

Heading: Layout and breakpoints

Mobile-first. Pack `html-tailwind`: `px-4` → desktop padding, `hidden md:flex` analogue for newsstand extra tools, `min-h-[44px]`, `focus-visible` ring, `motion-reduce`.

| Width | Behavior |
|-------|----------|
| 390 | Search full-width under icon clusters; shortcuts scroll; promo stacks; press grid 3-col |
| 768 | Promo row; product row 4-col |
| 1024–1440 | Absolutely centered search; 1.72 / 0.86 main+side grid; press grid 6-col |

Viewport meta does not disable zoom. `touch-action: manipulation`. `min-h-dvh`.

Z-index scale: base 0 / dropdown 40 / header 50 / banner 60.

Heading: Motion and feedback

Pressable scale 0.97, 180ms. Hover 150–300ms color. Loading spinner; `prefers-reduced-motion` flattens animation and press scale. Pack: no decorative-only motion, no width/height animation.

Heading: Accessibility (priority 1–2)

- Contrast: primary `#03c75a` on white is for large fill (login) and the 28px wordmark, not small body text. Body is `#2e2e2e` on `#fff` ≫ 4.5:1. Result titles `#0f7c3d` on white for AA large/bold.
- Skip link → search.
- Heading order: promo `h2`, shopping/news via labelled sections, results `h3` under a results `h2` for related.
- Icon-only controls have `aria-label`.
- Keyboard tab order matches visual order. Combobox pattern on the field.
- `aria-live` on errors and results. `aria-busy` while searching.
- Image alt describes the mattress photograph, not a brand name.

Heading: Offline / first-render constraints

- No `http(s)` asset requests. No Google Fonts, Tailwind CDN, or live naver.com images.
- CSS reset zeros `figure, blockquote, ul, ol` (UA default margins broke measurement in prior runs).
- Representative image is `image.jpg` next to this HTML.
- Publisher cells and the side “SUMMIT CLAVION” block are type, not marks.

Heading: Anti-patterns avoided

Pack: cluttered-without-hierarchy, slow loading, placeholder-only label, no search suggestions, missing focus ring, emoji-as-icon, hover-only primary action, layout-shifting press, extra screens not in the brief.
