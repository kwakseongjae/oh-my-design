Heading: Product read (Step 1)

| Slot | Decision |
|------|----------|
| Product | Korean consumer web portal. Primary job on this screen: type a query and move to search results. |
| Pattern (pack) | Marketplace / Directory — search bar is the CTA; reduce friction to search; category icons; featured listings. |
| Style (pack, `--variance 3 --density 8 --motion 3`) | Centered, dense, subtle motion. Script also emitted “Exaggerated Minimalism”; that oversized-type / massive-whitespace recipe is **not** applied, because the measured home is a dense two-column portal, not a fashion landing. Closest pack style actually used: **Minimal & Direct + Data-Dense** spacing (8–12px gaps, 12–15px type). |
| Platform | Single-file HTML. No Tailwind CDN, no GSAP, no Phosphor npm. Inline CSS + inline SVG (Phosphor-equivalent outline set from `--domain icons`: list, magnifying-glass, bell, shopping-cart). |
| Audience | ko-KR, C-end, commute/home. Light color scheme only (evidence `colorScheme: light`). |

Heading: Type

Evidence type scale is unusually flat (h1/p/button all ~14.7px / weight 700·500, letter-spacing `-0.4px`). The home still needs hierarchy for the featured story, so:

| Role | Size | Weight | Notes |
|------|------|--------|--------|
| Body / controls | 15px | 500 | letter-spacing -0.4px |
| Search input | 16px | 500 | pack: readable-font-size on mobile |
| Featured title | 26px / 22px mobile | 800 | one loud line, not 12rem clamp |
| Section titles | 15–18px | 700–800 | |
| Shortcut / press names | 12–13px | 500–600 | dense grid |

Heading order: visually hidden `h1` “NAVER” → featured `h2` → 뉴스스탠드 / 쇼핑 / 로그인 `h2`. No level skip.

Heading: Layout

- Desktop 1440: header (tools · search · tools) → shortcut row → two columns (content ~1fr, rail 420px).

Heading: Components

Heading: Search (the task)

- Visible `<label class="sr-only" for="q">` — pack UX: never placeholder-only.
- Pill field, green 2px stroke, leading text wordmark `N` (not the official mark).
- Submit on Enter and via the magnifying-glass control. Empty submit → `role="alert"` next to the field.
- Static suggestion list (pack: autocomplete). No network.
- After submit: 180ms disabled/loading (pack: loading-buttons, submit-feedback) then the results view in the **same file**. No extra product screens (no login, mail, or shopping pages).
- Results are generated from the query string; links stay on-page (`#result-n`). Opening `render.html` with no query is the home first paint.

Heading: Other home chrome (from the snapshot, not invented screens)

- Cream Whale install bar, dismissible, does not cover the search field (the live overlay would have blocked the task).
- Shortcut row: 메일…치지직 + 더보기. SVG only.
- Featured story: kicker 누잠매트리스, copy from the desktop viewport, figure = `image.jpg`.
- 뉴스스탠드: tabs + ticker + 6×4 press **names as text** (no publisher marks).
- Login rail: green `NAVER 로그인` wordmark button.
- Ad rail: text-only “광고” block. No third-party marks.
- Shopping strip: CSS swatches, no extra bitmaps.

Heading: Interaction / a11y (pack checklist)

- Contrast: `#2e2e2e` on `#fefefe` and white on `#03c75a` meet 4.5:1.
- `:focus-visible` 3px ring (html-tailwind: `focus-visible`, not click focus).
- Touch targets ≥ 44px; 8px gaps.
- `prefers-reduced-motion: reduce` kills transitions.
- Skip link to `#main`.
- `aria-live` status on search. `aria-expanded` on the suggestion box.
- No emoji as icons.
- `cursor: pointer` on buttons.

Heading: Offline rule

Allowed: this HTML, `image.jpg`, system fonts already on the machine.
Forbidden in the first render: `@import` fonts, CDN CSS/JS, remote `<img>`, tracking pixels, official logo files.
