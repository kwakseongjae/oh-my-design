Heading: Interaction (the briefed task)

1. 직군 / 경력 listboxes filter the grid.  
2. Chips (한국, 기술스택, 글로벌, …) further restrict.  
3. Clicking a card opens a native `<dialog>` (same listing, not a second screen). Hash `#job-{id}`.  
4. Empty grid: message + 필터 초기화 (pack: do not leave a blank dead end).  
5. Query string keeps role/exp. Escape / 닫기 / 공고 열기 dismiss the dialog.

Heading: Motion / a11y (pack §1–§3)

- 200ms transform/opacity only; `prefers-reduced-motion: reduce` disables it.  
- Focus-visible 2px ring. Icon-only controls have `aria-label`. Touch ≥ 44px on mobile.  
- `figure` / `blockquote` / `ul` / `ol` margins reset (UA defaults).  
- Contrast: ink `#171719` on white; meta `#666666` on white ≥ 4.5:1.  
- One primary action in the dialog (`공고 열기`).

No `@import`, no CDN, no webfonts, no remote images. The only bitmap is local `image.jpg`.
