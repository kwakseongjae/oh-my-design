Heading: Domain supplements (Step 3)

- **product** — Job Board/Recruitment; Directory / Listing Site (filter-heavy grid).
- **style** — Flat Design Mobile (Touch-First): zero elevation, pill chips, press scale 0.97, 4pt spacing. Minimalism & Swiss as secondary (white field, sans, grid).
- **color** — Professional blue + neutral white. Measured chrome from evidence overrides generic sky (`#F0F9FF` / `#0369A1`).
- **typography** — Noto Sans KR (pack). Evidence family is Pretendard Variable. Offline stack, no Google Fonts CSS.
- **ux** — alt text, 4.5:1 contrast, heading order, aria-label on icon buttons, keyboard, skip link, `prefers-reduced-motion`.
- **icons** — Phosphor-style outline: magnifying-glass, bookmark, x, funnel/sort, list, caret.
- **stack html-tailwind** — consistent cards, `focus-visible` rings, 44px targets, duration 150–300ms. Tailwind CDN is a network request, so tokens are inlined as CSS variables.

Heading: Motion

Pack motion dial 3 + html-tailwind duration 150–300ms.

- Press: scale 0.97–0.99, 180ms ease-out
- Menus: display toggle (no height animation)
- Drawer: 180ms translateX
- `prefers-reduced-motion: reduce` kills transitions

Heading: Accessibility checklist (pack §1–3)

- Contrast: body ink 4.5:1+; secondary `#666666` / `#767676` on white
- Skip link, sequential `h1` → card titles as text, dialog `h2`
- Icon-only controls have `aria-label`
- Keyboard: filter listboxes, card buttons, native `<dialog>`, Escape
- Touch ≥44px
- `aria-live` on result count
- Empty state has a reset action
- No emoji icons
