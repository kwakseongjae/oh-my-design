Heading: 포지션

이 화면은 랜딩이 아니라 분류된 인벤토리다. 구직자가 직군·경력을 좁힌 뒤 공고 한 장을 연다. 뉴스프린트 분류광고의 리듬 — 따뜻한 지면에 머리선, 같은 크기의 칸, 큰 디스플레이 헤드라인 없음 — 으로 그 일을 한다.

스냅샷 `2026-08-22T19-52-31-934Z`의 공고 제목·회사·근무지·경력만 쓴다. 없는 필드는 비운다. 추천순·인기순 순위, 지원 가능 여부는 이 스냅샷에 없으므로 만들지 않는다.

Heading: 토큰

모든 색과 서체는 `render.html` `:root` 이름만 참조한다.

Heading: 간격 · 규칙 · 깊이

4pt 척도 `--space-3xs` … `--space-3xl`. 페이지 거터 `--page-gutter`. 컨트롤 높이 `--control-h` (44px) — 버튼·셀렉트·칩·아이콘 버튼이 같다. 카드 반지름 0, 그림자 없음. 구조는 1px 머리선.

Heading: 모션

Newsprint 배율 0×. `transform` 리프트 없음. `transition-all` 없음. 포커스 링은 즉시. `prefers-reduced-motion: reduce`에서 `scroll-behavior: auto`.

1. **N9 가장자리 정렬** — 왼쪽 워드마크 `wanted` (공식 로고 원본 없음), 오른쪽 `회원가입`. 가운데 링크 열 없음.
2. **S2 매달린 머리** — `채용 정보`와 스냅샷 날짜. 챕터 번호·eyebrow 없음.
3. **필터 띠** — Catalogue의 디바이더. 직군·경력 `<select>`. 최신순만 활성. 추천순·인기순은 스냅샷에 순위가 없어 disabled.

5. **Ft2 한 줄 바닥** — `wanted · 채용 정보 · 2026년 8월 22일`.

같은 문서의 `<dialog>`가 공고를 연다. 새 화면을 만들지 않는다.

Heading: 상태 (8)

`.btn` · `.chip` · `.icon-btn` · `.job__open` · `select`에 default / hover / `:focus-visible` / `:active` / disabled / loading / error / success. 호버는 `(hover: hover)`가 가능한 포인터에서만 의미가 있고, 터치에서는 탭이 연다.

지원하기는 스냅샷 세션이 비로그인(`authenticated: false`)이므로 눌러도 접수되지 않는다. 버튼이 error 상태로 바뀌고, 회원가입 후 지원하라는 한 줄을 남긴다.

외부 요청 없음. 폰트는 로컬 스택, 사진은 `image.jpg` 상대 경로. CSS 리셋이 `figure` · `blockquote` · `ul` · `ol` 마진을 지운다.
