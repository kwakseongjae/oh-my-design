Heading: wanted 채용 목록 Design System

스냅샷 `2026-08-22T19-52-31-934Z`의 채용 목록(`wdlist`) 한 화면.
과업 동사: **필터를 적용한다**, **채용 카드 하나를 연다**.
이 문서는 철학 → 결정 표 → 토큰 → 컴포넌트 → 레이아웃 문법 순이다. `render.html`은 여기 적힌 값만 소비한다.

Heading: Philosophy

한 줄 입장: **스캔 가능한 채용 격자에서, 조건은 즉시 줄고, 카드 하나는 그 자리에서 열린다.**

1. **조건이 결과를 밀어낸다.** 필터는 장식이 아니라 목록을 바꾸는 유일한 집단 조작이다. 그 대가로 히어로·프로모 밴드·별도 랜딩을 두지 않는다.
2. **카드가 단위다.** 회사 사진이 이름보다 먼저 읽힌다. 그 대가로 행-밀도 테이블과 사이드 레일을 버린다.
3. **없는 숫자는 비운다.** 스냅샷에 없는 연봉·지원자 수·공식 로고·전체 공고 총량은 자리를 비우고 이름을 밝힌다. 그 대가로 “있어 보이는” KPI를 만들지 않는다.

상태 매트릭스(인터랙티브 7상태):

- 리스트박스 트리거: default / hover / focus-visible / active / expanded / disabled(해당 없음) / error(해당 없음)
- 칩: default / hover / focus-visible / active / pressed / disabled / (loading 없음)
- 카드 히트: default / hover / focus-visible / active / disabled 없음
- 북마크: default / hover / focus-visible / active / pressed
- 다이얼로그 닫기: default / hover / focus-visible / active
- 회원가입(primary): default / hover / focus-visible / active — 누르면 가입 화면이 없음을 status로 알림(성공이 아님)
- 필터 초기화: 기본 상태에서는 숨김(P-FN-04). 활성 필터가 있을 때만 ghost

비인터랙티브: 보상 배지, 푸터 고지, 미디어 톤 — focus 계약 없음.

Heading: Layout grammar

페이지 문법: **카탈로그 격자**. 콘텐츠 역산: 12장 ≥ 4열×2행. 와이드에서 40% 공백을 남기지 않기 위해 열을 늘린다.

구조:

1. 스킵 링크 → `#main`
2. 헤더(워드마크 + 채용 current + primary `회원가입/로그인`)
3. `main` 하나, `h1` 하나(“채용 정보”)
4. 직군/경력 리스트박스 + 정렬 라디오
5. 필터 칩 행
6. 결과 정의 줄 `role="status"`
7. 카드 격자 / 빈 상태
8. 푸터 샘플 고지
9. 모바일 하단 탭(채용만 current. 나머지 목적지는 이 스냅샷에 없음)

Heading: Data honesty

진실 소스:  + viewport 캡처에서 **읽히는** 필드만.

- 제목 12개: imagery `alt`
- 회사·지역·경력: viewport에서 보이는 카드 메타. 안 보이면 생략
- 직군: 제목 명사에서만 분류(교육/마케팅/개발/재무/매니지먼트/영업/고객지원)
- 기술스택: 제목에 있는 “유니티”만
- 한국: 지역에 “서울”이 있는 카드
- 생성 이미지 1장: 1번 카드 미디어
- 없는 것(화면에 이름을 밝힘): 공식 로고, 전체 공고 수, 연봉, 지원자 수, 응답률, 투자액, 퇴사율, 기업 규모

모든 레코드는 보이는 ID `WD-01`…`WD-12`와 푸터의 “샘플” 한 줄.

Heading: SELF-WALK

| 과업 동사 | 키보드 경로 | 프로그램 증거 |
|---|---|---|
| 필터를 적용한다 | Tab → 직군 필터 트리거 → Enter/Space로 열기 → Arrow → Enter로 커밋. 또는 Tab → “한국” 칩 → Space | 트리거 `aria-expanded`, 옵션 `aria-selected`, 칩 `aria-pressed="true"`, `#result-status` 문구 변경, `#job-grid[data-state="filtered"]`, 카드 `hidden` |
| 채용 카드 하나를 연다 | 필터 후 Tab → 카드의 “채용 카드 열기” → Enter | `dialog[open]`, `data-state="open"`, `aria-modal="true"`, 레코드 ID 노출, 열었던 카드 `aria-current="true"`, 포커스는 닫기 버튼 |

빈 결과: 직군 “고객지원” + 경력 “신입” 등 교집합 0. P-FN-05 문장 + 필터 해제.

Heading: Journey states (graded)

- `default` — 필터 없음, 12장
- `filtered` — 조건 적용, status가 조건을 말함
- `empty` — 0건
- `open` — 카드 다이얼로그
- `disabled` — 데이터 없는 칩, 필터 없을 때 초기화 숨김
- loading/error 네트워크 상태 — 로컬 샘플이라 엔드포인트가 없음. 만들지 않음(발명 금지)
