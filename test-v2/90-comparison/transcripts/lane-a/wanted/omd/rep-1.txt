Heading: 채용 목록 표면 시스템

벤치 산출물. 프로젝트  채택하지 않는다 (`surface-local-only`). 토큰·컴포넌트는 이 문서가 잠그고 `render.html`만 소비한다.

근거 등급: 스냅샷·evidence.json은 `repository-fact`. 직군/경력 분류는 직무명에서 유도한 `agent-proposed-greenfield-decision`. 스냅샷에 안 보인 회사명·위치·연봉·공고 본문은 `unresolved` — 필드 단위로 생략.

Heading: Philosophy

한 문장: **많이 훑고, 조건을 걸고, 카드 하나를 연다.**

- P1 스캔이 과업이다. 히어로 카피·일러스트를 버리고 3:2 미디어 그리드를 남긴다.
- P2 색은 카드 사진이 쓴다. 크롬은 종이/잉크이고 악센트는 신호(현재 탭, 가입 글자, 포커스)만.
- P3 한글 고딕 한 가족. 디스플레이도 같은 얼굴의 무게로 세운다. 라틴 세리프 폴백 없음.

Heading: Layout grammar

**카탈로그 격자.** 1440 = 4열, 860–1100 = 3열, 390 = 2열, 320 = 1열. 트랙 `minmax(0, 1fr)` (G50). 콘텐츠 12장 — 격자 최소를 채운다 (GS6).

폴드: 워드마크 · 채용 현재 · 회원가입/로그인(primary) · 직군/경력 · 칩 · 첫 카드 행.

한 화면만. 이력서·소셜 등은 과업 밖 — 누르면 상태줄에 부재를 알리고 화면을 추가하지 않는다.

Heading: Journey (SELF-WALK)

브리프 동사: **필터를 적용한다**, **채용 카드 하나를 연다**.

| 동사 | 키보드 | 기계 증거 |
|---|---|---|
| 필터 | Tab → 직군 트리거 → Enter → 화살표 → Enter. 또는 칩에서 Space | `aria-expanded`, `aria-activedescendant`, `aria-selected` / 칩 `aria-pressed`, `#job-grid[data-state=filtered\|empty]`, `#result-status` 문구 |
| 채용 카드 열기 | Tab → `.card-open` → Enter | `dialog[data-state=open]`, 카드 `data-state=open`, 대화상자 안 레코드 id, `document.title` 갱신, 닫으면 트리거로 포커스 복귀 |

Primary CTA 1개: `회원가입/로그인` `data-cta="primary"`. 카드 열기는 `data-cta="local"`. main 1, h1 1.

Heading: Honesty

- 공식 로고 원본 없음. 워드마크는 텍스트 `wanted`.
- 생성 이미지 1장(`image.jpg`)만 네트워크 없이 로드. 나머지 미디어는 실측 팔레트 플레이트.
- 연봉·지원자 수·전체 공고 수·평점 없음 — 푸터와 대화상자가 카테고리를 이름으로 고지.
- `합격보상금 100만원`은 스냅샷 모든 카드 오버레이를 재현한 UI 배지(정적, C27).
