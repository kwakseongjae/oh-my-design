Heading: Tokens

모든 색과 서체는 `render.html` `:root`의 이름만 참조한다.

| Token | Value | Role |
|---|---|---|
| `--color-paper` | `oklch(99.4% 0.006 90)` | 페이지 면. 스냅샷 모달은 `#ffffff`. |
| `--color-ink` | `oklch(18% 0.012 90)` | 본문·워드마크. 순수 `#000`은 쓰지 않음. |
| `--color-accent` | same as ink | 채운 CTA. 장르가 허용하는 먹 필. |

| `--color-focus` | `oklch(52% 0.14 250)` | 밝은 면 위 포커스. |
| `--color-focus-on-ink` | `oklch(92% 0.03 90)` | 먹 버튼 위 포커스. |
| `--color-canvas-*` | blue / cyan / pink / green | 아래쪽 작업 샘플. UI 액센트가 아님. |
| `--font-display` | Avenir Next, Trebuchet MS | 헤드. 오프라인 제약으로 웹폰트 없음. |

스페이싱은 4pt 척도 `--space-3xs` … `--space-3xl`. 이징은 `--ease-out` / `--ease-in` / `--ease-in-out`. 모션은 `--dur-micro` 120ms, `--dur-short` 220ms, `--dur-long` 420ms. `prefers-reduced-motion: reduce`에서 공간 이동은 150ms 이하 페이드.
