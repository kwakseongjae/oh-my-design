팩  순서대로 실행했다.

1. 요구 분석 — SaaS 디자인 협업 캔버스, C-end + 팀, ko-KR 홈, 스택은 단일 HTML(오프라인).

3. 도메인 보강

   - `product` SaaS design tool → Productivity / Remote Work → Soft UI Evolution + Minimalism, Hero + CTA.

   - `ux` form signup accessibility → 라벨, 제출 피드백, alt, role=alert, 4.5:1.
   - `typography` → Korean Modern (Noto Sans KR) 후보. 네트워크 금지라 로컬 시스템 스택으로 투영.
   - `icons` → Phosphor outline (`x`, `list`).
   - `--stack html-tailwind` → 시맨틱 컬러 토큰, 아이콘 버튼 `aria-label`.
4. 스냅샷 크롬이 토큰을 이긴다. desktop-1440 / mobile-390 실측: 배경 `#ffffff`, 헤더 높이 78.4px, CTA 검정 필, 쿠키 버튼 radius 8px, h1 56/36px weight 400, tracking `-1.25px`. 팩의 다크 퍼플 팔레트는 쓰지 않았다.

Heading: Layout

- 브레이크포인트: 390 / 768 / 1024 / 1440.
- 헤더 sticky, 본문은 `min-height: calc(100dvh - 78px)`.
- 데스크톱 히어로 3열: 헤드라인 · `image.jpg` · `시작하기`.
- 모바일: 헤드라인 → 이미지. 무료 시작은 헤더 필 CTA.
- 히어로 이미지 `width/height` + `aspect-ratio`로 CLS 방지.
- `figure, blockquote, ul, ol { margin: 0 }` — UA 기본 마진 제거.
- `dialog { margin: auto }` — 리셋이 네이티브 가운데 정렬을 지우지 않게 복구.

Heading: 가입 흐름 (같은 화면)

1. `지금 무료로 시작하기` 또는 `시작하기` → `<dialog id="signup">`.
2. 라벨 붙은 이메일 1필드 (landing: 필드 ≤ 3).
3. 검증 실패: `aria-invalid` + `role="alert"` 근접 메시지.
4. 성공: 버튼 `aria-busy` → 400ms 후 status “가입 흐름에 진입했습니다.”
5. Esc / 닫기 / backdrop. 닫으면 트리거로 포커스 복귀.

쿠키는 스냅샷에 있어 재현하되 `aria-modal="false"` — 헤더 무료 시작 CTA를 막지 않는다.

Heading: Motion / a11y

- 150–300ms, transform/opacity만. `prefers-reduced-motion`에서 duration 0.
- 터치 44×44, `cursor: pointer`, `touch-action: manipulation`.
- Skip link, 헤딩 순서 h1→h2, 아이콘 버튼 `aria-label`.
- 본문 대비율 흑/백 ≥ 4.5:1. 색만으로 오류를 알리지 않음.
- 줌 비활성 없음 (`width=device-width, initial-scale=1`).

Heading: Anti-patterns 회피

팩 체크리스트 + 스냅샷 제약: 이모지 아이콘, placeholder-only 라벨, 호버-only 핵심 동작, 공식 로고 원본, 외부 네트워크, 브리프 밖 페이지, 쿠키를 모달로 올려 CTA 차단.
