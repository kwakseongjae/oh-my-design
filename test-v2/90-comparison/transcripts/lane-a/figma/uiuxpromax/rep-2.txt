Heading: Step 3 — domain searches (resolved)

- **product** `saas design tool collaboration` → Productivity Tool + SaaS (General). Styles: Flat + Minimalism. Landing: Interactive Product Demo / Hero + Features + CTA.
- **landing** `hero-centric` → **Hero-Centric Design**. Order: full-bleed hero (headline + visual) → value strip → proof → CTA. Primary CTA in hero + sticky nav. Hero is 60–80% of the fold. One primary CTA, 7:1 contrast.
- **style** `exaggerated minimalism` → **Exaggerated Minimalism** + **Minimalism & Swiss Style**. Black `#000` / white `#FFF`, oversized type, negative space, geometric sans, no decorative shadow.
- **color** `black white high contrast` → **Museum/Gallery**: bg `#FAFAFA` / fg `#09090B` / primary `#18181B`. Mapped onto captured chrome (bg `#FFFFFF`, fg `#000000`) rather than the teal App Store palette.
- **typography** pack heading/body: Outfit / Work Sans, then Roboto. Captured face is `figmaSans` at weight 400. Render uses a **local system stack** (no Google Fonts CSS) so the file stays offline.
- **ux** form labels, submit feedback, alt text, contrast, heading order, aria names, keyboard, skip link, loading buttons, z-index scale.
- **icons** Phosphor outline: `list`, `x`. Inlined as SVG (no npm, no emoji).
- **stack html-tailwind** no bounce spam; hide/show at breakpoints instead of forking content.

Heading: Layout

- Mobile-first. Breakpoint 1024px for the 1440 hero row.
- Header sticky; wordmark is the string `Figma` (no official mark).
- Hero: headline left, generated `image.jpg` center, `시작하기` right on desktop. Mobile keeps the same nodes; hero CTA hides with CSS (`html-tailwind` hide/show, not a second page).
- Signup is a dialog on this home, not a second screen.
- `figure, blockquote, ul, ol { margin: 0; padding: 0; }` in the reset — UA list/figure margins broke measurement in this bench.

Heading: Interaction / a11y (pack §1–3)

- One conversion job: header and hero start buttons open the same signup dialog.
- Visible email label, error in `role="alert"`, submit → disable + spinner → success text.
- Skip link, heading order h1 then h2, icon-only controls have `aria-label`.
- Focus rings 3px black. Keyboard: Tab order, Escape closes dialog / menu / cookie.
- Contrast: black on white and white on black exceed 4.5:1.
- Touch ≥ 44px. `cursor: pointer` on clickable nodes. `touch-action: manipulation`.
- `prefers-reduced-motion: reduce` disables transition/animation.
- Viewport meta does not disable zoom.
