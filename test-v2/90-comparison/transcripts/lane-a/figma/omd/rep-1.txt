Heading: Figma 홈 — surface-local system

스냅샷 `2026-08-22T19-48-41-602Z` (ko-KR, `https://www.figma.com/ko-kr/`). 화면은 홈 하나. 과업은 무료 시작 CTA로 가입 흐름에 진입하는 것이다. 공식 로고 원본은 쓰지 않는다.

Disposition: **surface-local-only**. 프로젝트 루트  열거나 채택하지 않는다. 아래 값은 이 홈 렌더의 계약이다.

데이터 인벤토리: 제공 레코드/API는 없다. 쓰는 카피는 스냅샷에 보이는 것(제목, 내비, CTA, 모바일 메뉴 항목)과 페이지 `<title>`뿐이다. 사용자 수·요금·후기는 없다.

Heading: Philosophy

**캔버스가 제품이다.** 크롬은 얇게 두고, 접히는 화면의 대부분을 작업 파일처럼 보이는 히어로에 쓴다. 무료 시작은 한 번만 크게 보인다.

희생:

- P1 장식 악센트·그라데이션 헤드라인 → 흰 지면 + 검정 잉크 대비.
- P2 디스플레이 700+ 관례 → 스냅샷 typeScale 그대로 400. 크기로 위계를 만든다.
- P3 추가 화면 → 가입은 같은 홈의 `dialog`다.

Heading: Components

Heading: Button — no-preset (마케팅 CTA, P-CM 비대상)

- 해부: 라벨만. 아이콘 없음.
- 상태: default / hover(면 전환) / focus-visible(outline) / active(scale 0.98) / disabled(opacity + cursor + native).
- 기하: min-height 44px, border-width 상태 간 불변(아웃라인은 inset box-shadow 1px).
- 프라이머리: ink 면 + on-ink 글. 아웃라인: paper 면 + ink 링.

Heading: Text field — no-preset (가입 이메일)

- appearance: none. 높이 44px = 제출 버튼.
- hover는 링 색만. focus는 outline 슬롯.
- 힌트·에러 슬롯 `min-height: 1lh`. 에러는 `role="alert"` + `aria-describedby` + 필드 포커스.

Heading: Dialog — native `<dialog>` (팩: 다이얼로그는 별 표면)

- 가입: h2 + 이메일 + 계속.
- 메뉴: 스냅샷 390 오버레이 카피. 목적지 없는 항목은 닫기만 한다.
- 닫기: 버튼, Escape, `dialog.close`.
- `::backdrop` 토큰.

Heading: Header / wordmark

- 워드마크 텍스트. 데스크톱 인라인 내비는 `#main`. 390은 햄버거 → 메뉴 다이얼로그.
- 로그인 = 같은 다이얼로그, 제목만 변경.

Heading: Layout grammar

홈 = **카피/피규어 디프틱** (visual-quality §4). 와이드 전략: 좌 헤드라인, 중 캔버스가 폭을 채움, 우 로컬 CTA.

콘텐츠 역산: 대표 이미지 1 + 헤드라인 1 + CTA. 벤토/캐러셀/매거진 문법은 열지 않는다.

390: 헤더(워드마크 · 지금 무료로 시작하기 · 메뉴) → h1 → figure. 히어로 시작하기는 숨긴다(프라이머리 중복 방지).

320–1440: `overflow-x: clip`. 100vw 없음. figure/blockquote/ul/ol 마진 리셋.

Heading: Journey self-walk
