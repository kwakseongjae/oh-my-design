Heading: Philosophy

흰 지면을 비우고, 캔버스 작업물이 접면의 그림이 되게 한다. 무료 시작 동사 하나를 남기기 위해 장식 악센트·추정 수치·공식 마크를 버린다.

| 원칙 | 얻는 것 | 버리는 것 |
|---|---|---|
| P1 캔버스가 그림이다 | 접면에서 작업 표면이 바로 읽힌다 | 아이콘 타일, 그라데이션 헤드라인, 센터 스택 히어로 |
| P2 무료 시작은 하나다 | 가입 진입 경로가 유일하다 | 헤더와 히어로에 같은 primary를 두 번 심는 것 |
| P3 없는 것은 비운다 | 스냅샷에 없는 로고·가격·추천사·이용자 수를 만들지 않는다 | 그럴듯한 대체 마크, 추정 카피, 하위 라우트 |

Heading: Layout grammar

페이지 하나, 문법 **카피/피겨 디프틱**. 콘텐츠 역산: 브리프가 준 대표 이미지 1장(`image.jpg`)이 우측을 채운다. 스냅샷 이미지 9장은 역할이 코드북 몫이라 그리드로 재배열하지 않는다.

- 1440: 좌 헤드라인(max ~8em) · 우 피겨 · 그 옆 local `시작하기`
- 390: 워드마크 + primary + 메뉴 → 헤드라인 → 피겨. local CTA 숨김(캡처와 동일)
- 320 / 200% 리플로우: 단열, `overflow-x: clip`, 디스플레이 `min-width:0; overflow-wrap:anywhere`

Heading: Journey

브리프 동사: **무료 시작 CTA를 눌러 가입 흐름에 진입한다.**

| 동사 | 키보드 | 프로그램 증거 |
|---|---|---|
| 지금 무료로 시작하기 | Tab → primary → Enter | `dialog#signup[open]`, `data-state="signup"`, 제목 포커스 |
| 이메일 제출 | Tab → 이메일 → 계속 | 성공: `role="status"`가 이메일 포함. 실패: `aria-invalid` + `role="alert"` + 필드 포커스 |
| 쿠키 허용/거부 | Tab → 해당 버튼 | 배너 `hidden`, `data-state="dismissed"` |

로그인·영업팀 문의는 스냅샷 크롬에만 있고 화면은 없다. 클릭 시 정직 부재 문장을 `role="status"`로 읽힌다. 하위 내비 라벨은 홈에 머문다.
