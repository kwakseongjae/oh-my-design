Heading: Components

상태 매트릭스는 코드에 구현. 개발자 스위처 없음.

**Wordmark** (non-interactive 이유: 홈에서는 현재 위치, 가입에서는 홈 복귀 링크)
- 텍스트만. 공식 로고 원본 없음.

**Nav** (desktop)
- 라벨은 캡처 그대로: 제품 / 솔루션 / 커뮤니티 / 리소스 / 가격.
- 하위 항목은 캡처에 닫혀 있어 만들지 않음.
- hover: opacity. focus-visible: 2px 링.

**Button**
- default / hover (면 변화) / :focus-visible / :active(scale 0.98) / :disabled(opacity + cursor + native disabled).
- 높이: 데스크톱 40px, 터치 뷰포트 44px. 히어로·제출 56px.
- primary fill, outline hairline, ghost.

**Primary CTA**
- 이름: 브리프 동사 그대로 `지금 무료로 시작하기`.
- 클릭·Enter → `data-state="signup"`, 제목·`document.title` 갱신, `#page-title` 포커스, 링 억제 (P-FN-02 / G19).

**Hero local CTA**
- 라벨 `시작하기`. 같은 여정. `data-cta="local"`. 390에서는 캡처에 없어 숨김.

**Signup field**
- 네이티브 `input type="email"` + 토큰 보더. appearance none.
- 높이 = 히어로 버튼 56px (G39).
- 에러: `aria-invalid` + `aria-describedby` + `role="alert"` + 필드 포커스.
- 성공: `role="status"`에 진입 사실. 다음 단계는 스냅샷에 없다고 말함.

**Cookie dialog**
- 캡처 카피·버튼 라벨 유지. 과업이 아님. 닫으면 `data-cookie="closed"`.

**Mobile menu**
- 캡처된 열린 메뉴 라벨만. 검정 면 + 큰 흰 글자. 과업 화면을 추가하지 않음.

Heading: Layout grammar

홈: **3존 디프틱** .
- 1280×800 폴드: 헤드라인, 캔버스, primary가 헤더에 보임.
- 1440: 카피 22rem / 캔버스 1fr / 로컬 CTA auto.
- 390: 1열. 로컬 CTA 숨김. 헤더 primary가 과업.
- 320: 워드마크 축소, `overflow-x: clip`.
- 초광폭: 좌측 카피 고정, 캔버스가 남는 폭을 먹음.

가입: 같은 헤더, 단일 컬럼 28rem. 캔버스·로컬 CTA 숨김. h1 1개 유지.

Heading: Journey (SELF-WALK)

| 동사 | 키보드 경로 | 프로그램 증거 |
|---|---|---|
| 무료 시작 CTA를 누른다 | Tab → `data-cta="primary"` → Enter | `body[data-view=signup]`, `main[data-state=signup]`, h1 텍스트 교체 |
| 가입 흐름에 진입한다 | 이메일 입력 → Tab → `data-cta="submit"` → Enter | 성공 시 `form[data-state=success]`, `role="status"` 문구. 실패 시 `aria-invalid` + `role="alert"` + 포커스 복귀 |
