Heading: 배달의민족 홈 — surface-local system

스냅샷 `2026-08-22T19-47-32-522Z`의 홈 한 화면. 과업은 **앱 설치 경로(스토어 배지 또는 QR) 하나를 연다.** 공식 로고 원본은 쓰지 않는다. 이 문서는 그 화면이 소비하는 로컬 계약이다.

Disposition: `surface-local-only`. 프로젝트 루트  만들지 않는다.

Preset: **P-ED-03 룩북 스크롤 내러티브** (커버 광폭 → 민트 플레이트 컷 반복). 히어로 카피/피규어는 증거 사진 위에 겹친 변형이며, 해부(표지 → 컷 → 캡션)는 유지한다.


Heading: Philosophy

한 화면에 설치 경로 하나만 연다. 홈은 식욕을 주는 사진과 민트 플레이트 이야기이되, 첫 과업은 스토어 배지 또는 QR이다.

원칙 (얻는 것 / 버리는 것):

- **P1 설치가 유일한 1차 행동.** 히어로에 primary CTA 하나. 상품권 구매 같은 다른 화면의 버튼은 이 과업에 없으므로 두지 않는다.
- **P2 사진이 식욕, 민트가 말.** 표지는 실사, 이하는 민트 면 + 선화. 카드 키트·아이콘 타일로 장르를 바꾸지 않는다.
- **P3 없는 값은 비운다.** 스토어 URL, 가게 수, 별점, 우아한형제들/라이더/외국인 화면은 스냅샷에 없다. 자리만 정직하게 비운다.

Heading: 워드마크
텍스트 「배달의민족」. 로고 파일 없음. 표지 위 밝은 글, 민트 구간은 ink (`is-mint`).

Heading: 설치 CTA — no-preset: store-badge
프리셋에 스토어 배지가 없다. 해부: 라벨 / (QR은) 미니 코드 아이콘. 상태: default / hover(면 변화) / focus-visible(즉시 링) / active(scale 0.97) / open(`aria-expanded` + 링) / disabled는 다이얼로그 안 스토어 주소 없음 버튼. 접근 이름: 「앱 설치 경로 열기」(브리프 동사). `data-cta="primary"` 하나. Google Play·QR은 `data-cta="local"`.

Heading: 설치 다이얼로그
native `<dialog>`. 열림 = 과업 성공 상태. `role="status"`로 「앱 설치 경로를 열었습니다.」 외부 스토어 URL은 disabled + not-allowed + 낮은 대비 채움.

Heading: 내비
한 개의 `nav`. 세 링크는 푸터의 정직 부재 문장으로만 이동. 모바일은 disclosure (`aria-expanded`).

Heading: Layout grammar

P-ED-03. 패널: 표지 → 오늘도 달립니다 → 음식배달 → 배달팁 무료 → 식료품 → 초신속 배달 → 선물하기. 카피는 증거 화면에서 읽은 문장만. 320 / 390 / 1440에서 가로 문서 스크롤 없음 (`overflow-x: clip`).

Heading: Honesty

- 공식 로고 없음, 텍스트 워드마크.
- 스토어 URL 없음 → 다이얼로그 안에서 연다. 코드는 스냅샷 출처 `https://www.baemin.com/` 을 담는다.
- 우아한형제들 / 라이더 모집 / For foreigners 화면 없음.
- 가격·별점·가게 수 없음.
- 생성 이미지 `image.jpg`는 표지 음식 사진. 네트워크 폰트/CDN 없음.
