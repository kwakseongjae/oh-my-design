Heading: Three-layer tokens

Primitive → semantic → component. Components never take raw hex.

Heading: Primitive

```css
--color-mint-500: #0cefd3;
--color-ink-900: #000000;
--color-paper-50: #f6f6f6;
--color-paper-0: #ffffff;
--space-*: 4px grid (4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 / 64);
--font-sans: -apple-system, BlinkMacSystemFont, "Segoe UI",
             "Apple SD Gothic Neo", "Noto Sans KR", sans-serif;
--duration-fast: 160ms;
--duration-base: 220ms;
```

Fredoka/Nunito from the pack are mapped onto this system stack so the first render has zero font network requests (`font-loading` / FOIT). Weight 800 carries the playful extra-bold mood.

Heading: Semantic

```css
--color-background: var(--color-paper-50);
--color-foreground: var(--color-ink-900);
--color-primary: var(--color-mint-500);
--color-on-primary: var(--color-ink-900);
--color-on-photo: var(--color-mint-500);
--color-wordmark: var(--color-paper-0);
--color-ring: var(--color-mint-500);
```

Light surface only. Evidence is `colorScheme: light`. Dark tokens are not invented.

Heading: Interaction — install path

Opening **one** of: App Store badge, Google Play badge, QR, or mobile **Get the App**.

- Native `<dialog showModal()>`. Esc dismisses. Focus moves to Close, returns to the opener.
- `aria-live="polite"` announces which path opened.
- No `https://` store URLs — first render and the dialog stay offline.
- Touch targets ≥ 44px, gap ≥ 8px.
- `touch-action: manipulation`.
- `prefers-reduced-motion` zeros transitions.

z-index: base 0 · header 20 · overlay 100 · skip 1000.

Heading: Anti-patterns avoided

- Catalog orange as if it were this product
- Google Fonts / CDN / remote images
- Official 배달의민족 mark (text wordmark instead)
- Extra screens (클럽, 선물하기, listings)
- Emoji as icons
- Focus outline removed
- Hover-only install
- Invented copy outside the snapshot chrome
