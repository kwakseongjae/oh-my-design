Heading: Toss Home Design System

This document is the  portable contract for this run. It is a
surface-local system derived from the frozen snapshot, not Toss’s published
design-system site. Unresolved values are omitted rather than filled.

Heading: Experience

**Scope.** One consumer surface: the Toss home (`https://toss.im/`, snapshot
`2026-08-22T19-51-46-001Z`). The first render is that home. The only additional
view is the destination of the top-nav item **서비스**.

**Primary task.** From the top nav, select 서비스 and move to that destination.

**Stance.** The home is an entrance to one nav destination. Reproduce the
measured first plate; open 서비스; leave every unmeasured service name blank.

**Principles (each names a sacrifice).**

- P1 Honesty over catalog completeness. If a service name, count, or store
  URL is not in the snapshot, the screen names the missing category instead of
  inventing a list.
- P2 One journey over a long homepage. Later marketing plates (shopping stills,
  app screens) are sacrificed so the graded verb stays reachable on the
  observed 서비스 control.
- P3 Measured chrome over reinterpretation. Color, type metrics, header height,
  and CTA radius come from `evidence.json` chrome and the verify-basis
  viewports. Unmeasured spacing uses the pack 4pt scale and is labelled as
  proposed.

**Source classes used.** `prompt-fact` (brief: home, 서비스 from top nav,
snapshot handle). `repository-fact` (evidence chrome, imagery alts, viewport
copy, palettes, manifest). `agent-proposed-greenfield-decision` (unmeasured
inset, hero radius, motion durations, compact breakpoint). `unresolved`
(Toss Product Sans files, open 서비스 mega-menu items, app-store URL,
`primaryButton.background` `#07194c` which contradicts the visible pill).

Heading: Spacing (4pt roles)

`--space-1` 4px · `--space-2` 8px · `--space-3` 12px · `--space-4` 16px ·
`--space-5` 20px · `--space-6` 24px · `--space-section-sm` 2.5rem ·
`--space-section` 4rem · `--space-section-lg` 6rem ·
`--gutter: clamp(1rem, 2.2vw, 1.5rem)`. Header height `--header-h: 64px`
desktop / `56px` mobile (`chrome.header.heightPx`).

Heading: Motion

`--duration-fast: 120ms` · `--duration-base: 200ms` ·
`--ease-enter: cubic-bezier(0.22, 1, 0.36, 1)` ·
`--ease-exit: cubic-bezier(0.4, 0, 1, 1)`. Animate transform/opacity only.

**Observed family.** `typeScale.family` = `Toss Product Sans OTF`. That face is
not bundled in this run (unresolved load). The stack names it first, then
Hangul-covering gothic fallbacks required by the pack Korean contract. No
network `@font-face`.

```
"Toss Product Sans OTF", "Pretendard Variable", Pretendard,
"Apple SD Gothic Neo", "Noto Sans KR", "Malgun Gothic", sans-serif
```

| control / nav | 16px | 16px | 500 | 25.6px | ink |

Hangul: `word-break: keep-all`. Display headings also `overflow-wrap: anywhere;
min-width: 0`. No italic display.

**Imagery.** One generated still (`image.jpg`, 1280×800) stands in for
desktop-1440 imagery sample `c1` (`intro-main.mp4` frame). Evidence `alt` is
empty; the render alt describes the capture without naming a person. Decorative
SVG in chrome is `aria-hidden`. No logo file was provided; the mark is an
inline drop + accessible name “토스”.

**License / authority.** Snapshot captures are evidence, not redistributed in
the render. The generated image is produced in this run for the first plate.
Font files are not shipped.

Heading: Components & States

Presets used: **P-ED-03** (lookbook cover plate, token slots from ),
**P-FN-01** (KOR listbox), **P-FN-02** (route focus). Global nav is
**no-preset: observed chrome** — the snapshot bar is the product chrome, not a

Interactive components declare the seven-state map. Non-interactive plates do
not get a fictional focus contract.

Heading: Global header (no-preset: observed chrome)

Anatomy: mark+wordmark · primary links · KOR listbox · 앱 다운로드. Mobile:
wordmark · disclosure. Height 64/56px, fill `--color-header`.

| State | Applicability |
|---|---|
| default | yes |
| hover | yes (fill on CTA and listbox; background on links) |

| active | yes (pressed scale on buttons) |
| disabled | not-applicable — header controls that have no destination stay enabled and announce absence |

| error | not-applicable |

Anatomy: label only on 앱 다운로드. Min hit 44×44. Radius `--radius-pill: 12px`.

| State | Fill CTA |

Heading: Layout & Platforms

**Grammar.** Cover plate, center-max, inset by `--gutter`. 서비스 destination
is a paper well on the same route (`#service`), not a second HTML file.

**Viewports.** 1440 / 390 / 320 / 200% reflow. `overflow-x: clip`. Nav labels
do not wrap (nowrap). Touch controls ≥44px on 390/320.

**Compact chrome.** Below 860px the inline links collapse into a disclosure
(agent-proposed; 390 capture shows a hamburger and no above-fold CTA).

**Platforms named.** Desktop-1440 and mobile-390 as captured. No app shell.

Heading: Content & Locales

**Voice.** Snapshot Korean, casual-clear. Implementation words stay off-screen.

**Locale.** `ko-KR` as captured. `html lang="ko"`. The KOR control does not
invent a second locale.

**Copy on screen (verbatim from viewport or named alt).**

- Wordmark: toss (accessible name 토스)
- Nav: 서비스, 비즈니스, 회사소개, 뉴스룸, 채용
- Tools: KOR, 앱 다운로드
- Home h1: 금융부터 일상까지 마침내 토스 하나로
- Service lede: 내 자산 모아보기 (`mobile-390-imagery-10` alt)

**Honesty (visible).** App-store path, other nav destinations, open 서비스
menu items, and any count/price are named as absent where a reader would
expect them. Footer holds one sample line.

Heading: Governance

**Authority priority.** Brief → snapshot evidence → pack contract → proposed
tokens. A proposed token never overrides a measured one.

**Unknown-absence.** Omit at the smallest field. Do not promote
`primaryButton.background` `#07194c`, Toss Product Sans files, or uncaptured
mega-menu products.

**Consequential unresolved.** Font files; store URL; 서비스 menu members other
than the nav label itself; later-page imagery as extra screens.

**Application priority.** Tokens in `:root` only. Pages consume. No second
stylesheet.
