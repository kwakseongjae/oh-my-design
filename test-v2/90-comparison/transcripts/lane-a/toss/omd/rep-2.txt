Heading: Toss Home Design System

Run-scoped contract for the specified home surface. Written in the pack derivation order (philosophy → decisions → tokens → component specs → layout grammar). This is not a compiler-bound  package: the pack compiler would publish outside the allowed run directory, so this document carries the same decisions the page consumes.

Authority for product facts: locked brief +  snapshot `2026-08-22T19-51-46-001Z`. Pack methods (visual-quality-contract, derivation-chain, presets, component-craft, slop-gates) decide *how* those facts become tokens. They do not supply missing brand facts.

Disposition: **establish** a surface-local system for this run. There is no adopted project  in scope, and the brief asked for a design-system document.


Heading: Philosophy

**Stance.** This home is a cover and a door: one media plate, one headline, and a top nav whose job is to let someone pick 서비스 and leave. Anything the snapshot does not show is omitted.

**P1 — One cover, one task.** We keep the first viewport as a single rounded media plate with the overlay line from the capture. We sacrifice a marketing mosaic, extra product showcases, and any second primary CTA.

**P2 — Evidence over kit.** Color, type metrics, header height, control radius, and labels come from measured chrome or the visible capture. We sacrifice a complete official typeface (Toss Product Sans OTF is named but not loadable offline) and any unused navy fill that the capture does not show on the download pill.

**P3 — Navigate, don’t invent a catalog.** Selecting 서비스 must actually move the view. We sacrifice a mega-menu of products that never appears in this snapshot.

Heading: Layout grammar

**Page: home cover plate ().**

- Wide strategy: central max. Gutter + one plate. No extra column (one image cannot fill a diptych without invention).
- Content back-calc: 1 still fills the plate. Carousel/bento/magazine forbidden (GS6).
- Fold: header 64 + plate using remaining 1440×900 viewport. Hero bottom padding ≥ 1.3× top inset.
- Overlay type sits on the plate, not in a stack under a cropped strip.
- Destination views (서비스 and the other four labels) are **the same document**, not additional HTML files. They keep the same header. Body is a heading + honesty node + the same still at reduced height so the 1440 viewport is not 40% empty (GS5) without adding a new screen type.

**Breakpoints.** 1440 grammar from desktop-1440; 390 grammar from mobile-390 (stacked headline, disclosure nav). 320 and 200% reflow: no horizontal overflow (`overflow-x: clip`), display type `overflow-wrap: anywhere; min-width: 0`.
