Heading: Stack notes (`html-tailwind`)

- Fixed nav: `z-50`; overlays `z-40`; skip `z-100`. No `z-index: 9999`.
- Visibility: CSS `@media` equivalent of `hidden md:flex` / `md:hidden`.
- Images: `width`/`height` + `object-fit: cover`. Hero is above-the-fold → not `loading=lazy`.
- Single file, inline CSS. No CDN Tailwind, no shadcn runtime. Patterns taken from `ui-styling` (Navigation Menu, skip link, focus-visible, sr-only live region).

Heading: Avoid

- Playful design
- Unclear fees
- AI purple/pink gradients
- Emoji as icons
- Hover-only primary actions
- Invented service names, ratings, or metrics
- Google Fonts network import
- Painting JSON `#07194c` as the download fill when the viewport shows a light pill
