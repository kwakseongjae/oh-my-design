Heading: Components (pack specs × this screen)

Heading: Header
- Height: 56 mobile / 64 desktop (evidence).
- Three regions: logo · primary nav · utilities (`KOR`, `앱 다운로드`).
- Background empty in JSON; painted `var(--color-white)` so sticky nav does not show the hero through it (pack sticky-nav: do not obscure content).
- Mobile: logo + Phosphor `List` (`aria-label` 메뉴 열기). Drawer `z-40`, nav `z-50` (html-tailwind stack).
- Active item: weight 700 (pack UX Active State). Do not rely on color alone — `aria-current="page"`.

Heading: Navigation (task surface)
- Desktop: text links `서비스` `비즈니스` `회사소개` `뉴스룸` `채용` (from viewport capture).
- `서비스` is the selectable item. Click → `history.pushState` to `#서비스` (pack: do not silently reset the stack), set `aria-current`, move focus to the destination heading.
- Other labels stay visible for chrome fidelity. They do not open extra screens (brief: home only).
- Keyboard: Tab order = visual order; Escape closes drawer; skip link to `#main`.
- Touch: min 44×44px (stack `min-h-[44px] min-w-[44px]`).

Heading: Button `앱 다운로드`
- Pack variant mapping: secondary chip (`gray-100` analog = `--color-muted`), not pack `default` (primary navy/gold).
- Size visual: pack `lg` height 48px is the nearest named size that still meets 44px; font 16 / weight 500 from evidence.
- States (pack ): hover 150ms ease-in-out; `focus-visible` ring 2px + 2px offset; active scale 0.95–1.00 band via 0.98; disabled unused.

Heading: Hero
- One generated photograph (`image.jpg`), aspect 1.778 (16:9), `object-fit: cover`.
- Subject placement: omitted (unresolved in JSON).
- Headline overlay: evidence type scale, white, bottom of frame. Capture line `금융부터 일상까지 마침내 토스 하나로`. Desktop: three spans in a row; mobile: stacked (viewport).
- Markup uses `h1` for pack heading-hierarchy (single page title). Evidence tag on this type size is `h2`.
- No autoplay video (offline). Motion magnitude 0.0025 → treat as still; honor `prefers-reduced-motion`.

Heading: Icons
- Phosphor outline, one stroke family, no emoji.
- Icon-only controls have `aria-label`.
