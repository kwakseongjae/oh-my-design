Heading: Layout

Mobile-first. Breakpoints 768 / 1024. Desktop 1024+ uses filter sidebar (220px) + 4-column listing grid. Below 1024: 2-column grid, location + filter in the main column, hamburger for service chips.

Sticky header with reserved height. No nested scroll regions. Listing photos `aspect-ratio: 1 / 1` with width/height on the generated image to hold CLS.

Heading: Components

**Button** — solid (`foreground` fill, used for 현 위치로 설정), outline (1px `#000`, 8px radius, 서울시 강동구 천호동), ghost pill (필터). Hover 200ms, press scale 0.98, min 44×44, `cursor: pointer`.

**Search** — pill field, category prefix + query + magnifying-glass (Phosphor outline, inline SVG). Visible label via `sr-only`. Submit stays on this screen.

**Listing card** — interactive card: square figure, title (2-line clamp), price, location · time. First card uses `image.jpg`. Other cards use inline SVG stand-ins (offline). Whole card is the hit target.

**Filter** — desktop sidebar (위치, 상태 checkbox, 카테고리 radios). Mobile: location row + 필터 chip. Not a separate screen.

**Detail** — same listing fields only (photo, title, price, meta) plus 검색 결과 back. `history.pushState` / `hashchange` so browser back is predictable. No invented seller chrome.

**Menu** — mobile drawer (`role="dialog"`, Esc / scrim / close). Service list only.

Heading: Icons

Phosphor-style outline, 2px stroke, one family. Used: magnifying-glass, list, x, funnel, caret, compass-like location, list-rows for 중고거래. No emoji icons.

Heading: Motion

200ms ease-out on hover/press. Transform/opacity only. `prefers-reduced-motion` collapses duration. No decorative loops.

Heading: Imagery

`image.jpg` is the representative listing photo for card 1 and its detail. Square, local file, no remote CDN. Other listings do not fetch capture URLs.

Heading: Accessibility

- Skip link → `#main`
- Heading order: page `h1` then card `h2` (detail `h1` when that view is shown)
- Icon-only controls have `aria-label`
- Focus ring 3px `--color-ring`
- Contrast: ink on white; wordmark orange `#EA580C` on white is large/bold
- Zoom not disabled
- `aria-live` not used; view swap is a route change with focus moved to `main`

Heading: Anti-patterns avoided

- Flat page with no depth: cards keep radius + photo block
- Text-heavy landing sections on a results screen
- Google Fonts / Phosphor npm / Chart.js CDN (offline constraint)
- Mixing filled and outline icons in the same layer
- Hover-only primary action (cards are click/tap)
- Official logo asset
