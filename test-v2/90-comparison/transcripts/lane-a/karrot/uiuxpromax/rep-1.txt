Heading: Layout

Marketplace pattern: search in the header, related queries, then a filter-heavy listing grid.

| Breakpoint | Layout |
|------------|--------|
| default / 390 | 2-column cards, location + filter chips in the body, hamburger drawer |
| 768 | 3-column cards, still no sidebar |
| 1024+ | 260px filter sidebar + 4-column grid (matches desktop `docBox` x=332 start) |
| 1440 | same structure, 40px page gutters |

Sticky header with content sitting below it (pack UX: do not let a fixed nav cover the first section). No nested horizontal swipe on the card grid; related queries may scroll sideways.

Grid gaps use one `gap` token, not per-item margins (html-tailwind stack: Grid gaps).

Heading: Components and states

| Component | Default | Hover | Active | Focus | Disabled |
|-----------|---------|-------|--------|-------|----------|
| Card (interactive) | 1:1 media, title, tabular price, meta | translateY(-2px) | scale(0.98) | 2px primary ring | n/a |
| Fill button | ink bg, white text, pill | — | scale(0.98) | ring | opacity 0.5 |
| Outline button | 1px `#000`, radius 8 / pill, 14/700 | — | scale(0.98) | ring | opacity 0.5 |
| Chip / nav | muted pill | brightness 0.97 | — | ring | — |
| Search | 44px pill, 16px input | — | — | ring on field | — |
| Checkbox / radio | 18px, `accent-color` primary | — | — | ring | — |
| Drawer | closed | — | — | focus to close | — |

State priority: disabled > loading > active > focus > hover > default.

Touch: 44×44px minimum on icon buttons, chips, cards, back, menu. 8px+ gap. `cursor: pointer` on every clickable control. `touch-action: manipulation`.

Icons: inline SVG, outline, 1.75 stroke — Phosphor-equivalent (magnifying-glass, list, map-pin/crosshair, funnel, caret, dots, close, back). No emoji icons.

Heading: Navigation (the task)

First paint is **search results** (`#results` or empty hash).

A listing card is an `<a href="#item/{id}">`. Opening it is the required task: hashchange shows the same listing’s photo, title, price, and meta. Back is `<a href="#results">` (pack: Back Button severity High — do not `location.replace`). Focus moves to the detail heading and returns to the originating card.

No additional product screens.

Heading: Motion

Pack stagger list is Subtle-tier (300ms, 30ms/item, `y: 8`). **Not applied on first paint:** `animation-fill-mode: both` from opacity 0 made the listing grid unscored/transparent in a measured snapshot. Cards render opaque. Hover/active still use 180ms transform-only motion. `prefers-reduced-motion: reduce` collapses duration to 0.01ms. No decorative infinite loops.

Heading: Accessibility (pack §1–§3 + pre-delivery)

- Skip link to `#main`
- `h1` once per view; sidebar uses `h2`; cards use `h3`
- `:focus-visible` 2px ring, 2px offset, primary color
- `aria-current="page"` on 중고거래
- `aria-live="polite"` on view change
- Form labels (`sr-only` on the search field)
- Meaningful `alt` = listing title
- Color is not the only state (current chip also gets an inset stroke)
- Images declare `width`/`height` and `aspect-ratio: 1/1` (CLS)
- First four thumbs `loading="eager"`; the rest `lazy`
- Drawer: Escape, scrim 50% black, `aria-expanded`

Heading: Image

`image.jpg` is the representative generated listing photograph (used black laptop, seller-style overhead, 1:1). It is the first card and the detail media for that card. Other thumbs are local data URIs so the file opens with no network.

Heading: Anti-patterns avoided

- Google Fonts / CDN / any `http(s)` request
- Official logo file (text wordmark only)
- Emoji as UI icons
- Hover-only affordance
- Raw hex in component rules
- Arbitrary `z-index: 9999` (scale 20/40/50/100)
- Extra screens not named in the brief
- Invented listing copy beyond the snapshot grid
