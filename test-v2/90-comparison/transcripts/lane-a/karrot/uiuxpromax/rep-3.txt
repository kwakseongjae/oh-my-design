Heading: Decisions

**Pattern.** Search is the primary control. Related queries sit under the bar. Filters are a left rail on desktop and a compact button row on mobile. Listings are a square-thumb grid. This is the pack Marketplace/Directory + Filter-Heavy Grid pattern applied to the captured search page — not a marketing landing, so pack sections “Trust/Safety” and “Become a seller” were not added.

**Style override.** `--design-system` returned Aurora UI (mesh gradient, luminous hero). Product-domain Classifieds recommends Flat + Vibrant, and Aurora’s own “best for” list is SaaS/hero, not a used-goods grid. Applied: flat surfaces, one accent, no drop shadows on cards, press via `transform`/`filter` only.

**Color.** Pack classifieds palette is listing-blue on `#EFF6FF`. Captured chrome is white page, ink text `#1a1c20`, orange wordmark, black outline location control (radius 8). Applied tokens follow the captured chrome. Pack accent green `#16A34A` is reserved as `--color-accent` and unused on this screen (prices stay ink, matching the snapshot). Wordmark is the text string `당근` — no official mark.

**Type.** Pack pairing that requires a network import (Fredoka/Nunito, Cormorant/Crimson, Poppins) is blocked by the offline first-render rule. Body/UI use the system stack from the MD3/Roboto System row, which also matches captured `family: -apple-system`. Scale from captured type: desktop h1 28/700/36.4, mobile h1 24/700/32, card title/price 16/700, controls 14/700, meta 13.

**Density / motion.** Dial density 7 → 4/8px rhythm, compact card grid (2-col @390, 4-col @1440). Dial motion 3 → 180ms ease, no load stagger (opacity-0 entrance would blank a first screenshot). `prefers-reduced-motion: reduce` disables transitions.

**Image.** `image.jpg` is the representative listing photograph for card `c1` and its detail. Other cards use inline SVG stand-ins so the file opens with zero network.

Heading: Layout

- Mobile-first. Breakpoint 1024px for sidebar + 4-column grid.
- Sticky header in flow (no overlay of the title).
- Grid thumbs `aspect-ratio: 1 / 1` with width/height on the generated image (CLS).
- z-index: header 40, skip-link 100.
- Horizontal scroll is limited to the related-query row on small widths.

Heading: Navigation (task)

1. First paint = search results (`#view-results`).
2. A listing card is an `<a href="#listing-cN">`. Click/`Enter` `pushState`s and shows `#view-detail` with that card’s title, price, meta, and photo.
3. Back control calls `history.back()` when the current state is detail (pack: do not `location.replace`).
4. `popstate` restores results or the hashed listing.

Heading: Anti-patterns avoided (pack)

- No emoji icons.
- No Aurora mesh background on a classifieds grid.
- No webfont `@import`.
- No official logo asset.
- No extra screens (chat, write, login, map).
- No load-time opacity stagger.
