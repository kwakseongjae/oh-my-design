Heading: Philosophy

한 문장: 동네 중고 검색 결과는 사진을 훑고 가격을 비교한 뒤 카드 한 장을 열어 확인하는 도구이지, 브랜드 히어로나 신뢰 배지를 늘어놓는 지면이 아니다.

원칙 (각 원칙은 희생을 포함한다).

- **P1 사진이 스캔의 단위다.** 정방형 미디어가 카드 면적의 대부분을 차지한다. 카드 크롬·배지·내부 CTA를 희생한다.
- **P2 한 번의 활성화로 상세.** 카드 전체가 히트 영역이다. 그리드 안에 채팅/찜 버튼을 넣지 않는다.
- **P3 스냅샷에 없는 것은 비운다.** 캡처에 보인 제목·가격·동네·시간만 싣는다. 판매자 신뢰 점수, 별점, 재고 문장을 만들지 않는다.

Heading: Tokens

`:root`에만 선언한다. 컴포넌트는 `var(--*)`만 읽는다.

- 색: `--color-paper`, `--color-ink`, `--color-ink-inverse`, `--color-accent`, `--color-meta`, `--color-muted`, `--color-rule`, `--color-chip`, `--color-search`, `--color-fill`, `--color-focus`
- 모서리: `--radius-control` 8px, `--radius-media` 12px, `--radius-pill`
- 공간: 4/8/12/16/24/40/64 + `--gutter: clamp(16px, 3vw, 32px)`
- 타입: `--font` Apple SD Gothic Neo / Noto Sans KR / Malgun Gothic / -apple-system. `--fs-display` 28→24. 가격 tabular-nums
- 모션: `--duration-fast` 120ms, `--duration-base` 200ms, `--ease-enter`, `--ease-exit`
- 타깃: `--target` 44px

워드마크 악센트 `#ff6f0f`의 흰 배경 대비율은 2.79이다. 본문이 아니라 디스플레이 워드마크에만 쓴다 ().

Heading: Component specs

코드 전에 고른 프리셋. 해부는 유지하고 토큰만 이 표로 채운다.

Heading: 검색 결과 카드 — P-CM-01 파생 (P-MK-01 행이 아님)

캡처가 정방형 사진 그리드라 P-MK-01(~88px 썸네일 행)을 쓰지 않는다. 기록: 해부는 P-CM-01, 메타 한 줄은 마켓플레이스(동네 · 시간).

- 순서: 미디어 1:1 → 제목 2줄 클램프 → 가격(카드 안 최대 웨이트) → 메타
- 전체 클릭, 내부 CTA 없음 (C25)
- hover: 미디어 brightness. focus-visible: 잉크 링
- `data-cta="local"`. 상태 `data-state`는 카드가 아니라 main의 results/detail

Heading: 위치 리스트박스 — P-FN-01

네이티브 select 없음 (G28). 트리거 버튼 + `role="listbox"` + `aria-activedescendant`.
옵션은 스냅샷에 있는 `서울시 강동구 천호동`만. 다른 동네를 만들지 않음.

Heading: 필터 — P-FN-04 / 커스텀 라디오·체크

카테고리 라디오·거래가능 체크는 `appearance: none` + 토큰 마크.
`초기화`는 조건이 있을 때만 노출 (P-FN-04). 라벨 문자열은 캡처 그대로.

Heading: 빈 결과 — P-FN-05

카테고리/연관어가 0건이면 “이 조건의 매물이 없습니다” + 필터 해제 1개. 일러스트 없음.

Heading: 결과 수 — P-FN-06

“서울시 강동구 천호동 · 이 화면에 실린 매물 8건”. 8은 폴드에 전사한 레코드 수이며 전체 서비스 총량이 아니다.

Heading: 라우트 포커스 — P-FN-02

상세 진입 시 `document.title` 갱신, 스크롤 0, `#page-title` 프로그램 포커스, 시각 링 억제.

Heading: 사용하지 않은 프리셋

- P-MK-02 거래 상태 배지 — 스냅샷 그리드에 판매중/예약중/완료 라벨 없음. `no-preset`이 아니라 **미사용**.
- P-MK-03 신뢰 지표 — 점수 없음. 발명 금지.
- P-MK-04 채팅 미리보기 — 상세 스냅샷 없음. 상세에 “본문·판매자·채팅이 없습니다”.
- P-MK-05 히어로+데이터 블록 — 이 화면은 검색 결과이지 홈 히어로가 아님.
- 검색 필: `no-preset: search-pill` — 캡처 크롬을 재현. 토큰 슬롯만 /.

Heading: Layout grammar

페이지: **사이드바 필터 + 카탈로그 그리드**. 상세는 같은 HTML의 `data-state="detail"` (새 제품 화면을 추가하지 않음). 와이드 상세는 P-FN-03 파생 — 사진 좌, 가격·메타·부재 문장 우.

콘텐츠 역산: 그리드 8칸. 캡처 폴드에 제목·가격이 보인 매물만. 이미지 샘플 9–12는 메타가 폴드 밖이라 제목/가격을 만들지 않고 생략.

- 1440: 필터 260px + 4열, 미디어 갭 16px
- 960–1199: 3열
- 390: 필터는 오버레이, 2열, 위치 버튼 가로 배치
- 320: 2열 `minmax(0,1fr)`, `overflow-x: clip`
- 200% 리플로우: 클램프 거터, 제목 `overflow-wrap: anywhere`

Chrome: 텍스트 워드마크 “당근”. 공식 로고 원본 없음.

Primary CTA: 채워진 `현 위치로 설정` 하나 (`data-cta="primary"`). 카드는 local. 검색 제출은 `data-cta="submit"`. 기기 위치는 스냅샷에 없으므로 버튼을 눌러도 천호동을 유지하고 그 부재를 알린다.

브리프 동사: **열다**, **상세로 이동한다**.

| 상태 | 키보드 | 프로그램 증거 |
