Heading: 배달의민족 홈 — surface-local system

Disposition: **surface-local-only**. This is a benchmark first-render, not a project  adoption. Tokens live in `render.html` `:root` and are cited here with . Official logo files are not part of the system.

Preset: **P-ED-03** lookbook scroll narrative (cover photograph → mint plates). Not P-CM-07 (no SKU grid in the snapshot).

Heading: Philosophy

**Mint is the field; black is the mark; the fold’s only job is to open an install path.**

1. **P1 — Field, not accent.** Mint occupies whole chapters so the photograph can be food, not a branded banner. Sacrifice: a small-dot accent budget, purple-SaaS gradients, and a card kit used on every surface.
2. **P2 — One install path owns the fold.** Store badge or QR is the journey. Sacrifice: extra product CTAs, counters, and testimonials above the fold.
3. **P3 — Hangul gothic weight is the display face.** No Latin serif, no logo file. Sacrifice: a decorative display family and tight Latin tracking on Korean.

Heading: Components (before code)

Heading: Wordmark — no-preset (official mark forbidden)
Text “배달의민족”, display weight, header color. Not an image.

Heading: Store badge — no-preset (install path, not P-CM-01)
Anatomy: 48× min 44px control, 8px radius, badge paper/ink, nowrap label. States: default / hover (fill) / focus-visible (outline) / active (scale) / disabled (opacity + cursor + native). Apple/Google marks are not used; labels are “App Store” / “Google Play”. `data-cta="local"`. Opens the install dialog.

Heading: QR control — no-preset
48×48 finder-pattern icon. `data-cta="primary"` on desktop. Accessible name includes the brief verb: “QR로 앱 설치 경로 열기”.

Heading: Get the App — evidence primary on mobile
Pill, mint fill, on-mint ink, 20px/700. `data-cta="primary"` on small viewports only (the desktop QR is hidden). Same dialog.

Heading: Install dialog
Native `<dialog>`. States: `data-state="closed|open"`. Title “앱 설치 경로”. Contains the QR figure and the two store labels. Close control. `role="status"` announces “앱 설치 경로를 열었습니다.” Escape / backdrop close via native dialog.

Heading: Nav — snapshot chrome, not a generic app shell
Three labels from the snapshot. Destinations were not in evidence; in-page fragments only. Mobile: disclosure (`aria-expanded`, `aria-controls`), 44px toggle. Off-canvas panel, not a hamburger+sidebar app.

Heading: Chapter title + doodle
Display 800 on mint. Doodles are inline SVG, `aria-hidden`. No emoji feature icons (G30).

Heading: Layout grammar (this page only)

Cover (hero) → 음식배달 → 배민클럽 → 선물하기. Four beats (GS6). Content back-calc: one generated photograph + three evidence-labeled plates. Do not invent B마트/쇼핑/페이 copy from filenames.

Hero fold at 1440: wordmark, headline, lede, install path, all in view. Copy max ~20ch per line on the display heading.
