# 90-comparison

## 평가자 패널 결정 규칙 (2026-09-03 사용자 지시)

**새 실행을 열기 전에 사용자에게 지금 가용한 평가자 채널을 묻는다.** 문서에 적힌 명부를 그대로 가정하지 않는다.
구독·한도·모델 은퇴로 가용 채널이 계속 바뀌었다(sol 은퇴, grok 402, Claude 주간 한도, 세션 한도 중단).
답은 그 실행의 `run-config.json`에 기록하고 계열 독립성 한계도 그 시점 명부로 다시 적는다.
**이미 봉인된 실행의 명부는 소급 변경하지 않는다** — 새 실행의 조건으로만 쓴다.
