**The subagent found a stylesheet-walking bug that affects any probe.** Under CSS Nesting, Chrome
gives every `CSSStyleRule` a `cssRules` list, empty but truthy, so a walker that tests
`if (rule.cssRules)` to decide whether to recurse skips the rule's own declarations — its first
pass returned 0 custom properties. `probe-component-states.mjs` never recursed at all, so it
missed `@layer`/`@media` rules; it now recurses and tests `.length` (same day).

EnterpriseZine and Biz/Zine, which the subagent cited, answer with a bot check and could not be
confirmed; they are not cited.

**Self-referencing placeholders.** `--text-*`, `--radius-*`, `--tracking-*`, `--leading-*`,
`--font-mono/display/yugothic`, `--shadow-card*` and `--shadow-cta-card*` are declared in
`@layer theme` as `var(<own name>)` and given values in an unlayered `:root` rule. Values here are
the resolved ones from `getComputedStyle(document.documentElement)`.
