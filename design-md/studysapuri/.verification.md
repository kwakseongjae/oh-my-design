## Scope and collector boundary

- Local Playwright-driven Chrome (Tier 1), 1440×1000, `ja-JP`, `getComputedStyle` on the
  document element and on individual controls; state readings through
  `web/scripts/probe-component-states.mjs`, which opens a fresh page per state and reads focus
  under a real Tab key before any pointer movement.
- Logged out. No account was created and no sign-in was attempted.
- Desktop only, light mode only. Captured and authored 2026-09-23.

### Two collectors, and what verification changed

A delegated subagent (Sonnet) ran the deep probe under the round-3 allocation
(`docs/COLLECTOR_MODEL_TRIAL_2026-09-22.md` §6). Its token census, Panda CSS identification,
font reading and history sources are used after independent checks. **Its headline claim was
wrong**: it reported all six controls as unchanged on hover and press. Re-measured, every
styled control fades — the sign-up button to opacity 0.9, audience cards 0.8, grade pills 0.7,
the login link 0.5 — over `transition: … opacity 0.3s`.

The cause was the tool, not the model: `probe-component-states.mjs` read opacity but did not
print it, and its summary line compared background colour only. Fixed the same day (the summary
now compares bg, fg, border, shadow, outline, transform and opacity), and recorded in
`docs/MEASUREMENT_METHOD_2026-09-22.md` §2.7. Every component value below is from the
re-measurement.

Of the subagent's six controls, one — a course button rendering `#efefef` with `#000000` text
at 13.33px — is the browser's unstyled `<button>` and is not recorded. The white header links
change none of the seven values on hover; underline was not read, so they are not declared.

## Namespace ownership and the nonsense-path control

`https://studysapuri.jp/zz-this-does-not-exist` returns a real **HTTP 404** titled
「スタディサプリ」 with a 112-character body. Not a catch-all.

**Panda CSS, excluded.** `--made-with-panda` resolves to `"🐼"` on the root — Panda's build
marker — and live elements carry Panda's atomic class names (`d_flex ai_center bg-c_transparent`).
Excluded as Panda's: `--breakpoints-{sm,md,lg,xl,2xl}`, `--sizes-breakpoint-*` (the same five
again), and 36 utility variables (`--blur`, `--brightness`, `--translate-x/y`, `--rotate`,
`--scale-x/y`, `--skew-x/y`, `--gradient-from/via/to-position`, `--scroll-snap-strictness`,
`--animate-duration` …).

Third-party on the page, not read for tokens: Google Tag Manager, Optimizely, Adobe/Demdex,
KARTE, Zeals, Promolayer, Microsoft Clarity, Facebook Pixel, Contentful, and an ad-exchange
stack.
