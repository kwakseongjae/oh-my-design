## Namespace ownership and the nonsense-path control

`https://smartbank.co.jp/zz-this-does-not-exist` returns a real **HTTP 404**, titled
「お探しのページは見つかりませんでした。 | 株式会社スマートバンク」, with its own 784-character
body. Not a catch-all.

Of the 371 custom properties, **370 carry SmartBank's own naming** across nine namespaces:
`--color-*` 214 · `--dimension-*` 55 · `--line-height-*` 36 · `--font-*` 23 · `--gradient-*` 18
· `--duration-*` 17 · `--cubic-bezier-*` 4 · `--letter-spacing-*` 2 · `--opacity-*` 1. The one
exception is a single `--swiper-*` property from the carousel library, which is not recorded.

No framework prefix (`--tw-`, `--wp-`, `--el-`, `--bs-`, `--mantine-`) appears. Names like
`--color-prepaid-card-junior-card-on-container` and `--color-emoji-sun-base-variant` could not
come from a generic theme.

`https://b43.jp/` **redirects to `https://onebank.jp/`** — the product was renamed ワンバンク.

## Why no component is declared

Every control on both surfaces is a CSS-module wrapper — `_rounded-button_gtcz6_1`,
`_circle-button_t4zv0_1` — computing **`background-color: rgba(0, 0, 0, 0)` and
`border-width: 0px`**. The fill and label live on children. Measured at rest, hover, pressed and
focus with `:hover` matching live on two of them, **no property changed on any control**, and
focus rendered `outline: rgb(0, 95, 204) auto 1px`, which is Chrome's default ring
(`docs/MEASUREMENT_METHOD_2026-09-22.md` §2.5).

`onebank.jp` behaves the same way: two `_rounded-button_` CTAs at 312px radius, transparent,
unchanged.

So this is a **token-only reference**, the same shape as huawei and douyin. A system that
publishes `--color-state-*-hover`, `--color-state-*-focused` and `--opacity-state-disabled`
almost certainly has components that use them; **this capture did not see one**, and nothing is
declared that was not observed.

## `primary_color` is a reading, not a citation

The system declares **no brand token**. Mint `#1dd0b0` is recorded as the identity because it is
what `--color-state-default-selected` (`#1dd0b014`) is built from, what the positive impression
resolves to, what the Pair Card gradient starts on, and what the product surface paints. That
reasoning is stated in §2 of the reference rather than left implicit.

## Evidence limitations

- **No component observed.** See above.
- **The app was not opened.** The platform-split font families (`-ios-*`, `-android-*`), the
  line-height density axis, the motion curves and the state tokens are all read from the sheet
  and **none was observed in use**.
- **No shadow token and none observed.**
- One `--swiper-*` property belongs to the carousel library and is excluded.
- `--font-family-android-japanese` reads `"SF Pro Text"`, which is Apple's face on Android's
  row. Recorded as measured; no correction is inferred.
- Desktop 1440×1000, light scheme, logged out.
