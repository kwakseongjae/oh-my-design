# Ctrip — Verification Notes (2026-09-22)

Pipeline: CN expansion wave 1, brand #2 · Brand: Ctrip (携程 / Trip.com Group)

## Scope and collector boundary

- Playwright-driven Chrome, 1440×900, `zh-CN` locale with `accept-language: zh-CN`, light
  scheme. `getComputedStyle` on the document element and on individual controls. Clicks were
  swallowed in the capture phase so `:active` could be read without navigating.
- Two surfaces: `ctrip.com` (404 custom properties) and `hotels.ctrip.com` (417). Both are
  Ctrip-owned, satisfying the CN regional Tier-1 ≥ 2 rule.
- No authenticated view, no booking funnel past the search panel, no mobile viewport.

### The token architecture

             smtcColorBgFavorite · smtcColorBgStarRating · smtcColorBgNoticeFilled · …

### Fonts

`tokens.typography.family` is **absent**. `ctrip.com` computes **Pingfang SC** — Apple's
Simplified-Chinese system face — and `hotels.ctrip.com` computes plain `system-ui`. Neither is
a licensed brand typeface, and a platform CJK system face is not promoted to one.

## Conflict matrix

| Field | Declared token | Rendered | Resolution |
|---|---|---|---|
| Brand blue | `coreColorBlue1` `#006ff6` | `hotels.ctrip.com` search submit `#006ff6` | **Confirmed — token and render agree exactly** |
| Home interactive blue | none | `ctrip.com` renders `#0086f6` | **Off-system.** `#0086f6` is not among the 404 properties that page loads. Recorded only as the measured component hover, not as a palette role |
| Sign-in pill fill | none | `#f2f8fe` | Off-system; same treatment |
| Search hover | none | `#2953d6` | Off-system; recorded on the component, flagged in §4 |

**Ctrip publishes a coherent token system and its own home page is only partly on it.** That
is the finding, and both halves are stated rather than averaged: the palette records the
declared system, and the off-system values appear only where a measured component used them.

## Browser defaults excluded

One anchor on `ctrip.com` computed color `#0000ee` at rest and `#ff0000` on press. Those are
**Chrome's default link and active-link colours on an unstyled `<a>`**, not Ctrip's. They are
not recorded. This is the same class of error as reading a default focus ring as a brand token.

## Tier 2 cross-checks

getdesign.md and refero.design return no Ctrip record — the ordinary CN outcome, and the
reason `REGIONAL_PROOF_COUNTRIES` requires two brand-owned regional sources instead. Both
cited sources are Ctrip-owned domains.

## Evidence limitations

- **Three components.** Result cards, calendar picker, price filters and the map panel were
  not reached. `comp*` tokens name several of them
  (`compSearchBoxCalendarHighlight`, `compHotelRoomListFilterBgcHover`), so the system
  documents components this capture did not measure. They are not declared.
- No disabled state was observed, though `smtcColorBgDisabledTinted` `#f5f5f5` exists.
- No shadow, elevation, transition or duration token appears in any of the three tiers.
- Desktop only; no authenticated or booking-funnel surface.
