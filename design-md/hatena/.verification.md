Pipeline: JP expansion wave 5, #2 · Brand: Hatena (株式会社はてな), portal www.hatena.ne.jp

## Scope and collector boundary

- Local Playwright-driven Chrome (Tier 1), 1440×1000, `ja-JP`, `getComputedStyle` on the document
  element and on individual controls; state readings through
  `web/scripts/probe-component-states.mjs`.
- Logged out; no Hatena ID was created.
- Desktop only, light mode only. Captured and authored 2026-09-26.
- Surface choice: `b.hatena.ne.jp` (Hatena Bookmark) exposes **no** custom properties; the portal
  carries the token set and is the measured surface.

### Two collectors

A delegated subagent (Sonnet) ran the deep probe. **Its headline claim was wrong**: it reported that
the six `--color-service-*` tokens are declared but unused, because the service links render the
browser's default link blue. Re-measured: every link it read that way is **not visible** (zero-size,
inside closed menus), and a rule walk finds **17 component rules** that use the service tokens —
`.BookmarkEntries … .more { background-color: var(--color-service-bookmark) }`, the same for Blog,
Question, Anond and Parks, `.ServiceIntro … a { color / border-color: var(--color-service-*) }`,
`.Header.signup { background-color: var(--color-service-portal) }`, `.Header.signin`, the selected
tab marker and the profile ID. On the logged-out page only the portal colour renders (5 visible
elements). Recorded that way.

The subagent's search-field states (pressed and focus `#cccccc`) and entry-title reading are used;
the sign-up button was re-measured (hover: no change in the seven values; focus: Chrome's `auto`
ring). The subagent's claim that the 2021 logo is Creative Commons licensed matched only script text
in a press page and is not used.

## Namespace ownership and the nonsense-path control

70 properties, all Hatena's: `--color-*` 26, `--icon-*` 29 (`url(/p/images/*.svg)`), `--size-font-*`
11, `--ui-radius-*` 4. No framework, consent or analytics variables; no third-party stylesheets.

`https://www.hatena.ne.jp/zz-this-does-not-exist` redirects and ends in **HTTP 500** — not a page.
No design-system or brand-guideline page exists; `design.hatenastaff.com` is the design team's blog
(culture, hiring, process).
