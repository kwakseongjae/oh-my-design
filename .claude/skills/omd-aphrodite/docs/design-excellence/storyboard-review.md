# 스토리보드 리뷰 게이트 (빌드 전) — v2 2026-09-04 (크기·무노동·사용자 표 추가)

> 빌드 뒤 리뷰는 늦다. 60점 라운드의 지적("포인트 컬러·미감이 아쉽다, 스크립트·구도 설정 때 피드백이 있어야")을 받아
> **스토리보드/컨셉 단계에서** 아래를 통과해야 빌드에 들어간다. 업종 무관 — 특정 색이 아니라 **역할·빈도·숫자**로 말한다.

> 수치 근거: r1 리뷰 실측 + 스크롤 안무 규칙(R-A~R-F) + 10개 사이트 액센트 실측(accent-probe, 2026-09-04: 첫 뷰포트 액센트 요소 중앙값 0·9/10 ≤3, 면적 ≤2.82%, CTA 가 최다 위치 10/10, 명도 반전 0~4).

## E. 자기 표절 시험
"이 스토리보드가 비슷한 브리프(다른 업종)에도 그대로 나올 것 같은 부분"을 최소 1곳 지목하고, 이 브리프만을 위해 무엇을 왜 바꿨는지 한 줄. 지목이 0 이면 FAIL(frontend-design 규칙).

## 첫 줄 다이얼 (LC-59)
스토리보드 첫 줄에 `밀도 n/10 · 모션 n/10` 을 선언한다. 밀도 ≤5 면 밀도 바닥(LI-24~26)보다 **상한**(LI-36 초점비·LI-37 폴드 ≤5·LI-38 채널 ≤2)이 우선한다.
