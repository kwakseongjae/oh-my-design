# magnetic-cursor — 끌려오는 타깃

| | |
|---|---|
| 계열 | 커서 |
| CSS-only | 아니오 — JS 30줄 |
| 인라인 크기 | CSS 8줄 + JS 30줄 / 약 1.4KB |
| 다크/라이트 | 둘 다 — 형태 효과라 색과 무관 |
| 라이선스 | 이 구현은 oh-my-design 자작, MIT |
| 난이도 | 중 |

## 핵심 두 가지
1. **반경 안에서만, 거리에 반비례해서.** 화면 어디서나 끌리면 버튼이 떠다니는 것처럼 보인다.
2. **라벨이 본체보다 더 끌린다** (`--fx-mag-lead: .45`). 이 미세한 어긋남이 "자기장에 의해 늘어난다"는
   인상을 만든다. 본체와 라벨이 같이 움직이면 그냥 버튼이 이동하는 것으로 읽힌다.

## 금기 — 여기는 사용성 문제가 진짜로 발생한다
- **44~50px 미만 타깃에 걸지 않는다.** 작은 타깃이 커서를 피해 움직이면 클릭 실패율이 올라간다.
  (모바일 최소 타깃 44px 규칙과 같은 이유.)
- pull 0.5 초과 금지. 버튼이 커서를 "쫓아오면" 조작 대상이 아니라 장난감이 된다. 0.15~0.35 권장.
- **한 화면에 자성 타깃 2~3개까지.** 내비게이션 링크 전체에 걸면 헤더 전체가 꿈틀거린다.
- 폼 필드, 리스트 행, 표 셀에는 절대 쓰지 않는다.
- 복귀 트랜지션을 짧게(<300ms) 주면 튕기듯 돌아와 불안정해 보인다. 500ms 내외.
- 터치 기기와 `prefers-reduced-motion` 에서 마운트 자체를 건너뛴다 (이 구현이 그렇게 한다).

## 파라미터
`data-fx-mag-radius`, `data-fx-mag-pull`, `--fx-mag-lead`, `--fx-mag-track`, `--fx-mag-settle`

## 계보

(https://www.npmjs.com/package/@phucbm/magnetic-button — 존재 확인, LICENSE 원문은 확인 못 함).
