flip-expand-card 호버 · 전환

호버가 예고하고, 클릭이 펼친다. 위치·크기 차이를 역변환으로 되돌린 뒤 0 으로 재생(FLIP)하므로 레이아웃 애니메이션인데도 transform 만 움직인다. GSAP Flip(24.4KB) 없이 WAAPI 46줄.

01 표류클릭하면 펼쳐진다
02 잔광ESC 로 닫는다
03 궤도키보드 Enter 도 된다
04 격자배경이 어두워진다
05 파문역스케일로 내용이 안 찌그러진다
06 정지리듀스드 모션이면 즉시 전환

색면은 이미지 슬롯 플레이스홀더다 — .fx-flip__ph 를 <img> 로 교체한다.
