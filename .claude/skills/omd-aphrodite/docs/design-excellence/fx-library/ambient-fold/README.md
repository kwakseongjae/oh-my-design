# ambient-fold — 폴드를 살리는 데 WebGL 은 필요 없었다

| | |
|---|---|
| 계열 | 유휴(idle) · 빛 · 텍스트 |
| CSS-only | ✅ 예 — JS 0줄 |
| 인라인 크기 | CSS 48줄 / 약 1.6KB |
| 다크/라이트 | 둘 다 — `--fx-amb-a/b`(광원 색)와 `--fx-amb-sh`(시머 색) 교체 필수 |
| 라이선스 | 이 구현은 oh-my-design 자작, MIT |
| 난이도 | 하 |

## 근거 — 실측 (2026-09-04)
경쟁 랜딩(higgsfield.ai)을 Chrome 으로 열어 scrollY=0, 입력 0 상태에서 계측한 결과:

| 항목 | 값 |
|---|---|
| `canvas` 개수 | **0** |
| `window.gsap` / `THREE` / `Lenis` | 전부 `undefined` |
| 실행 중 CSS 애니메이션 | **24개** (폴드 안에만 **17개**) |
| `infinite` + duration > 5s | **6개** ← "과하지 않게 살아 있다"의 상한선 |
| 폴드 내 `video` | 5개 — 전부 `autoplay:false`, `readyState:0`(**idle 에는 정지**) |
| `prefers-reduced-motion` 룰 | 4개 |

관측된 키프레임 이름: `typewriterReveal` · `typingCursorBlink` · `workingTextShimmer` · `festival-flashlight-beam` · `festival-sun-haze` · `festival-sun-glow` · `pulse` · `supercomputer-dot` · `preload-gradient-loop` 등.

**결론: 폴드 생동감의 정답은 셰이더가 아니라 ~1.6KB 키프레임이다.** 이 효과는 그 3계열만 추출한 것이다.

## 3계열
1. **광원 드리프트** — 물체가 아니라 **빛**이 20~60초 주기로 아주 느리게 흐른다. 시선을 뺏지 않으면서 "죽지 않았다"만 알린다. 가장 싸고 가장 안전한 유휴 동사.
2. **타이핑 헤드라인** — `steps()` + `ch` 폭 + 커서 blink. 제품의 본질이 '생성'이면 **카피 전달 방식으로 그 본질을 재연**한다. 문장이 완성된 뒤 시머가 7초마다 한 번 지나간다.
3. **상태 점멸** — `pulse` 링 + 라이브 수치("지금 3,052개"). 모션 + 숫자로 "사람들이 지금 쓰고 있다"를 만든다.

## 금기
- **폴드당 무한 애니메이션 6개 초과 금지**(실측 상한). 넘으면 살아 있는 게 아니라 산만한 것이다.
- 광원 주기 20초 미만 금지. 빠른 빛은 경고등으로 읽힌다.
- 타이핑을 `ch` 단위 없이 만들지 않는다. 비례폭 글꼴에서 `steps()` 는 `ch` 와 짝이어야 글자 경계에 맞는다. **줄바꿈되는 긴 문장에는 쓰지 않는다**(`white-space: nowrap` 이 필수라서 모바일에서 넘친다 — 짧은 구절만).
- 시머를 본문 문단에 걸지 않는다. 읽는 동안 색이 변하면 난독증에 가깝다. **한 줄 부제까지.**
- 라이트 모드에서 광원 알파를 그대로 두지 않는다. 밝은 배경 위의 밝은 빛은 얼룩이다.
- 라이브 숫자를 **지어내지 않는다.** 거짓 카운터는 걸리는 순간 신뢰가 0이 된다.

## 성능 조건
- 광원은 `filter: blur(28px)` + `transform` — 레이어 1개. `will-change` 도 여기 하나만.
- blur 반경 40px 초과 시 저사양 GPU 에서 눈에 띄게 떨어진다. 28px 권장.
- `background-clip: text` 시머는 페인트를 유발한다. 대상은 **짧은 한 줄**로 제한한다.
- `aurora-mesh` 와 동시 사용 금지 — 배경 레이어 2겹 규칙에 걸린다. 둘 중 하나.

## 모바일 / 리듀스드 모션
- `prefers-reduced-motion` → 빛은 **멈추되 남고**(구도), 타이핑은 **완성 상태로 스냅**(`width:auto`), 커서는 제거, 시머는 평범한 색으로, 점멸은 정지. 어떤 정보도 사라지지 않는다.
- 모바일에서 타이핑 문구는 화면 폭을 넘지 않는 길이만. `--fx-amb-ch` 를 반응형으로 줄인다.
