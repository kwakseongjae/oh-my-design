# FOLIO — Verification Notes (2026-09-23)

Pipeline: JP expansion wave 4, brand #2 · Brand: FOLIO (株式会社FOLIO)

## Scope and collector boundary

- Local Playwright-driven Chrome (Tier 1), 1440×1000, `ja-JP`, `getComputedStyle` on the
  document element and on individual controls; state readings through
  `web/scripts/probe-component-states.mjs` (fresh page per state, focus under a real Tab key
  before any pointer movement), using the version fixed on 2026-09-23 that compares bg, fg,
  border, shadow, outline, transform and opacity.
- Logged out. No account was created and no sign-in was attempted.
- Desktop only, light mode only. Captured and authored 2026-09-23.

### Two collectors

A delegated subagent (Sonnet) ran the deep probe. Checked independently before use: the 75
custom properties and their single prefix (re-read), the loaded fonts (re-read), all five
declared controls (re-measured with the fixed tool — every value matched the subagent's table),
and the 2018 rebrand account (the note.com post re-read for its key sentences and publication
date). The subagent's founding facts (date, address, employee count) came from search
aggregators and were not fetched; they are not used.

The subagent also recorded that a plain `cssText` regex over stylesheets found none of the 75
properties — the page's CSS Modules build defeats it — and only `getComputedStyle(:root)` lists
them. Recorded as method.

## Namespace ownership and the nonsense-path control

`https://folio-sec.com/zz-this-does-not-exist` returns a real **HTTP 404** on a different
template — a 63-character body set in `Noto Sans JP` / `Open Sans` / `YakuHanJP`, not the branded
face. Not a catch-all. `/design`, `/brand` and `/company` also 404; no design-system or
brand-guideline page exists on the host.

**All 75 properties are `--FOLIOWEB-LP-*`.** No framework, embed or third-party variables. The
page's third-party scripts (three GTM containers, GA, Bing UET, Yahoo tags, Facebook Pixel,
Clarity, DoubleClick, A8.net and other attribution tags) inject no visible styled DOM. TypeSquare
(`typesquare.com`) is Morisawa's font loader, part of font delivery.
