# JAL — Verification Notes (2026-09-22)

Pipeline: JP expansion wave 2, brand #3 · Brand: Japan Airlines / 日本航空

## Scope and collector boundary — **read this first**

**This is the first reference in the catalog measured through the Aside Browser MCP rather
than a local headless Chromium**, and the reason is recorded below because it changes what the
next person has to do to reproduce it.

- **Collector:** Aside Browser (`mcp__aside__repl`), a real desktop Chrome the owner runs,
  driven with Playwright JavaScript. 1440×1100, `ja-JP`, `getComputedStyle` on the document
  element and on individual controls.
- **Tab discipline:** a fresh tab via `openTab()` for each pass, closed at the end. The
  session's existing tabs were never listed or attached, and nothing outside `jal.co.jp` was
  opened.
- **Privacy:** computed styles and geometry only — no page text, form values, account
  identifiers or media were read. `looksAuthenticated` was checked before every measuring pass
  and returned **false** each time; had it returned true the tab would have been closed
  unmeasured. No sign-in was attempted and no account was created.
- Desktop only; the mobile surface and the JMB application were not measured.

## Why the collector changed: local headless is refused

`www.jal.co.jp` will not open under local headless Chromium. **Seven combinations were tried**
and all failed:

| Attempt | Result |
|---|---|
| Playwright, HTTP/2 on, `/ja-jp/` | `net::ERR_HTTP2_PROTOCOL_ERROR` |
| Playwright, `--disable-http2`, `/ja-jp/` | 70s navigation timeout |
| Playwright, `--disable-http2`, `/` | 70s navigation timeout |
| Playwright, HTTP/2 on, `/jp/ja/` | `net::ERR_HTTP2_PROTOCOL_ERROR` |
| 3 navigation retries with backoff | same error each time |
| `waitForSelector` on `.ds-button__trigger` | never reached — navigation failed first |
| `web/scripts/probe-component-states.mjs` | 대상 요소를 찾지 못했다 |

The 404 route (below) serves normally under the same local harness, so the block is on the
booking route specifically and keys on the headless fingerprint rather than on the address —
the Aside Browser, on the same machine and network, opened it **first try**.

Pushing a local harness past that would stop being "receive a public page the way a person
does" and start being evasion, which is why the collector changed instead of the technique.

### Known-answer check before trusting the new collector

One earlier local run did succeed, before the block became consistent, and its readings were
kept as a control. The Aside reading was compared against it:

| | local (single success) | Aside | |
|---|---|---|---|
| body text length | 2810 | 2810 | ✓ |
| own custom properties | 445 − 29 `--tw-*` = **416** | 479 − 63 `--tw-*` = **416** | ✓ |
| `lang` / title | ja / 日本航空 (JAL) | identical | ✓ |
| brand red | `#cc0000` | `#cc0000` | ✓ |
| focus ring | `solid 2px` | `solid 2px` | ✓ |

The total property count differs (445 vs 479) and the `--tw-*` count differs with it (29 vs
63) — the Tailwind layer emits more properties in the newer load — but **the 416 JAL-owned
properties match exactly.** Same method as the ego lite validation on 2026-09-21: a new
collector is checked against a known answer before it is trusted.

## The shadcn layer, and why it matters here more than usual

31 properties resolve to `oklch` values — `--background`, `--foreground`, `--card`,
`--popover`, `--muted`, `--border`, `--primary-foreground`, `--secondary-foreground`,
`--accent-foreground`, `--sidebar-*`, `--chart-*` — which is shadcn/ui's default theme, plus
63 `--tw-*` from Tailwind. Neither is recorded.

**The most-rendered text colour on the page, `oklch(0.145 0 0)` on 150 elements, is shadcn's
default foreground and not JAL's.** JAL's own heading colour is `--textColor-heading` `#000000`,
which renders on 41. A census taken without separating the two would have promoted a framework
default as this brand's ink — the same error class as nulab's WordPress properties and
Chatwork's Marketo form, and the reason the census above is annotated rather than summarised.
`rgb(31, 41, 55)` (Tailwind gray-800, 4 elements) is excluded for the same reason.

## 87 colours published twice — measured, not assumed

The 105 camelCase semantic tokens are also published as `--color-<kebab-case>`. This was
tested rather than eyeballed: for each camelCase key the kebab twin was constructed
mechanically and the two values compared after normalising 3-digit hex.

```
105 camelCase semantic tokens
 69  exact twin, byte-identical
 18  twin present, same colour in a different notation
 18  no twin
```

The 18 notation pairs are `rgba()` against 8-digit hex, and each resolves to the same colour:

```
--iconColor-white-hover              rgba(255, 255, 255, 0.6)
--color-icon-color-white-hover       #fff9                      0x99 = 153 = 0.6 × 255
--iconColor-subtle-hover             rgba(102, 102, 102, 0.8)
--color-icon-color-subtle-hover      #666c                      0xcc = 204 = 0.8 × 255
--surfaceColor-informative-hover     rgba(42, 52, 75, 0.8)
--color-surface-color-informative-hover  #2a344bcc
--surfaceColor-base-hover-compact        rgba(0, 0, 0, 0.1019607843)
--color-surface-color-base-hover-compact #0000001a              0x1a = 26 = 0.102 × 255
```

The same doubling appears in spacing (`--space-16` beside `--spacing-space-16`) and in type
(a semantic `--text-*` scale beside a numeric `--fontSize-*` one).

**No conflict is recorded in `verification_v2.conflicts`,** and that is deliberate: a conflict
in this schema is two sources disagreeing about one claim. Every pair that exists here agrees.
It is one system written down twice — mid-rename — and the reference says so in §14 and takes
the camelCase names, which are the complete set.

## Evidence limitations

- **Reproducing this requires the Aside Browser or another non-headless Chrome.** A local
  headless harness cannot open `jal.co.jp/ja-jp/`; see the table above.
- **Two controls declared, two measured and rejected.** Pressed was not measured on either
  declared control, so no pressed value is recorded.
- **No shadow token, no motion token, neither observed.**
- **Only `Noto Sans JP` of the seven language families rendered.** The other six are declared
  and unobserved. `--fontFamily-poppins` likewise. `AdobeClean-Regular` and `-Bold` loaded from
  an embedded Adobe component and are not JAL tokens.
- The membership-tier colours are recorded as published; **none was observed rendering** on the
  logged-out booking surface, which is expected — they paint a signed-in member's status.
- Desktop 1440×1100, light scheme, logged out.
