# Financial Times — Verification Notes (2026-09-23)

Pipeline: UK wave 1 · Brand: Financial Times (ft.com)

## Scope and collector boundary — read this first

- **Collector: Aside Browser** (`mcp__aside__repl`, Tier 2), the owner's desktop Chrome driven
  with Playwright JavaScript. Local headless Chromium (Tier 1) meets a Cloudflare challenge on
  `/`, `/world` and `/companies` (a delegated subagent reproduced it twice and, correctly, did not
  try to solve it).
- **Tab discipline:** fresh tabs via `openTab()` only, closed at the end. Existing tabs were never
  listed or attached; nothing outside `ft.com` was opened in Aside.
- **Privacy:** logged out — an account-link check (`[data-trackable="my-account"]`,
  `a[href*="logout"]`) returned false before measuring. Computed styles and geometry were read.
  Visible control labels and public link text on the home page were read only to locate the
  controls; no account data, form values or media were read. No sign-in, no subscription flow.
- **Hover and pressed were not measured.** Neither `locator.hover()` nor a stepped
  `mouse.move()` to the element centre (also after `bringToFront()`) produced `:hover` —
  `matches(':hover')` returned false each time. The JAL capture on 2026-09-22 did get
  `:hover` = true through Aside, so this is a property of today's session, not of the channel.
  Hover is left unrecorded rather than recorded as unchanged.
- **Excluded:** `AdobeClean-Regular` / `AdobeClean-Bold` appear in `document.fonts` as loaded but
  are not referenced by any FT style; they come from the collecting browser (an installed
  extension or app), not from ft.com.
- Desktop only, light mode only. Captured and authored 2026-09-23.

## Country

FT is owned by Nikkei (Tokyo) but is its own operating company headquartered in London. The
catalog classifies acquired operating companies by their own headquarters (skyscanner, owned by
Trip.com, and farfetch, owned by Coupang, are both UK). Recorded as **UK**.

## Origami, and the nonsense-path control

- `https://www.ft.com/zz-this-does-not-exist` renders a distinct page titled
  「Not found | Financial Times」 (3,271 characters). Not a catch-all.
- `origami.ft.com` now redirects to an Okta / Google sign-in; the subagent found `/components` and
  `/registry` returning the same 64-character 404 as its nonsense path, and the Origami monorepo on
  GitHub private. The last public snapshot of the colour documentation,
  https://web.archive.org/web/20251229031638/https://origami.ft.com/foundations/colours/ , was
  re-read for three sentences: teal "is the most striking colour and main CTA colour on ft.com";
  paper "is a lighter, more legible shade of FT Pink and can be seen as a kind of replacement of
  white"; "FT pink and FT grey are not used for digital UI". Every palette value quoted in the
  reference matches the live tokens.
