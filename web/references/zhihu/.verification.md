## Scope and collector boundary

- Playwright-driven Chrome, 1440×900, `zh-CN`, `getComputedStyle` on the document element and
  on individual controls, clicks suppressed so `:active` could be read without navigating.
- Two Zhihu-owned surfaces: `zhihu.com` (389 custom properties) and `zhuanlan.zhihu.com`
  (389), satisfying the CN regional Tier-1 ≥ 2 rule — **after a gate fix, see below**.
- Logged-out only. Answer pages, the editor, membership flows and search were not measured.

## A gate had to be corrected before this reference could pass

`zhihu.com` is listed in the catalog-integrity `PLATFORM_HOSTS` set, alongside note.com,
medium.com, velog.io and others. That rule exists for a good reason: it stops *somebody else's
post* on a publishing platform being cited as a brand's own evidence, so a platform URL only
counts when it names an account.

**When the reference is the platform, the rule inverts.** Zhihu's own homepage is Zhihu's
product surface, not a third party's account page, and the bare host was failing
`isBrandOperatedAccount` — so Zhihu could not satisfy Zhihu's own proof gate.

The fix is narrow: `isBrandOperatedAccount` now takes the reference's own homepage host, and a
source on that host (or a subdomain of it) counts as brand-owned. Every *other* reference
still has to name an account to cite zhihu.com. Two references already in the catalog have the
same shape — `note` (note.com) and `velog` (velog.io), the latter verified exactly on the
proof-gate cutoff — so this was live, not hypothetical.

### Modern colour spaces, recorded verbatim

Zhihu's hover states resolve as `oklch()` and `color(srgb …)` — the only reference in this
catalog that does. **The values are recorded verbatim rather than converted to hex.** An
`oklch` lightness–chroma–hue triple does not round-trip to sRGB without loss, and writing a
hex would assert a precision this measurement does not have. The component-token grounding
check only inspects hex, so these pass through untouched, which is the correct outcome.

### Fonts

`tokens.typography.family` is **absent**. No font-family token appears among the 389
properties and both surfaces compute the platform system stack; a system face is not promoted
to a brand typeface.

## Dark theme published, not claimed

`_dark` variants exist for most `Map*` roles. One (`MapText04A_dark` `#c2c6cf`) is recorded as
evidence the dark theme is published. **No dark-theme palette is claimed** — this pass measured
the light surface only.
