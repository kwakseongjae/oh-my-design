Pipeline: UK wave 2, #1 · Brand: Sainsbury's (J Sainsbury plc), sainsburys.co.uk

## Scope and collector boundary

- **Headed** local Chrome (Playwright, `headless:false`, desktop Chrome UA), 1440×1000, `en-GB`.
  Headless requests to `www.sainsburys.co.uk` are refused by the edge (HTTP 403 "Access Denied");
  the headed browser gets HTTP 200. This is still the Tier 1 local collector, run with a window.
- **Consent:** OneTrust's banner was **rejected** (`#onetrust-reject-all-handler`) before any state
  was read. Nothing was accepted.
- Logged out; no slot was booked, no registration started.
- Desktop only, light mode only. Captured and authored 2026-09-26.

### Two collectors, and what verification changed

A delegated subagent (Sonnet) ran the deep probe in a headed browser and reported **no hover change
on any of its three controls**, with focus not read. Re-measured: with the consent banner open, the
pointer and the Tab key both land on the banner — `:hover` never matched and Tab never reached the
controls. After rejecting the banner:

- the call to action's hover is genuinely unchanged (`:hover` matched true, all values equal);
- the navigation link's hover turns the label `rgb(229, 80, 0)`;
- focus (real Tab, `:focus-visible` true) draws `box-shadow: rgba(25, 118, 210, 0.7) 0 0 0 3px` on
  both, deepens the call to action's fill to `rgba(229, 80, 0, 0.8)`, and turns the navigation label
  `#e55000`.

So two of the subagent's three "no change" readings were artefacts of the banner. The probe tool now
rejects common consent banners before measuring and marks a hover that never matched `:hover` as
unmeasured; the probe brief requires both.

The subagent's grocery-app observation (`/gol-ui/groceries` carries a separate `--ds-*` system of
about 1,000 properties plus Tailwind, not Luna) is noted but that surface is not part of this
reference. Its note that MaryAnn is named after Mary Ann Sainsbury is not first-party confirmed and
is not used.
