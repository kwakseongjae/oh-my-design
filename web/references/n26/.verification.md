# N26 — Verification Notes (2026-09-26)

Pipeline: EU wave 1, #1 · Brand: N26 (N26 SE, Berlin)

## Scope and collector boundary

- Local Playwright-driven Chrome (Tier 1), 1440×1000, `de-DE`. n26.com rate-limits bursts of
  requests (a few rapid loads, then HTTP 403 for two to three minutes), so states were read in **one
  browser session** rather than a fresh page per state.
- **Consent:** the Usercentrics banner was rejected (`button[data-testid="uc-deny-all-button"]`)
  before any state was read.
- Logged out; no account opening was started.
- Desktop only, light mode only. Captured and authored 2026-09-26.

### Two collectors

A delegated subagent (Sonnet) ran the deep probe. It measured the Login pill's focus ring but
reported **hover as unmeasured on both buttons** (pointer actionability timed out) and **no consent
banner**. Re-measured: a Usercentrics banner is present and was intercepting the pointer; after
rejecting it, hover resolves with `:hover` true on both — the primary goes `#003b39` → `#045e58`, the
Login pill's sand goes from 25% to 50% — and both show the double ring
`box-shadow: rgb(255,255,255) 0 0 0 2px, rgb(4,94,88) 0 0 0 4px` under `:focus-visible`. The colour
tokens were re-read in a second session and match. The 2018 blog post was re-read. The subagent's
note of an InsideN26 Medium "brand book" post (403) is not used.
