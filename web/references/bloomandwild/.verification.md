# Bloom & Wild — Verification Notes (2026-09-26)

Pipeline: UK expansion track · Brand: Bloom & Wild, bloomandwild.com

## Scope and collector boundary

- Headless Chrome, viewport 1440×1000, locale `en-GB`, `waitUntil: load` plus ~6s settle.
- Cookiebot consent banner present — clicked the "Reject all"-equivalent selector; page re-settled
  1.5s after.
- Enumeration = `getComputedStyle(document.documentElement)` for root custom properties, plus a
  separate recursive stylesheet walk (`rule.cssRules?.length`, checked as a property, not
  truthiness — Chrome gives every rule an empty `cssRules` array under CSS Nesting, so a truthy
  check would silently skip nested rules).
- Component states read via `web/scripts/probe-component-states.mjs`, six controls, each at rest,
  hover, pressed and focus.
- Logged out; no purchase or checkout flow was entered. Desktop only, light mode only (no dark
  mode found). Captured and authored 2026-09-26.

## Namespace ownership and the nonsense-path control

`https://www.bloomandwild.com/design-system` and `https://www.bloomandwild.com/zz-this-does-not-exist`
return the **same generic 404** ("Uhoh! We can't find the page...", byte-similar template) — no
official design-system page exists on this host; the platform-name pattern from the hard-rules
control does not apply here since Bloom & Wild is already the catalog's target brand, but the
control confirms `/design-system` is not a real distinct page.

**`--oasys-*` (889 declarations), excluded from the brand's own token count**: the Bloom & Wild
**Group**'s shared design-token platform (colour ramps for green/blue/lilac/red/blush/buttercream
plus partner-brand colours for PayPal, Facebook, Trustpilot). It is described in prose (§2, §11)
and used where it explains a rendered value — the universal focus-ring blue
(`--oasys-color-blue-50` = `#2771fc`) and the pine-green ramp overlap
(`--oasys-color-green-60` = `--bwBrand__pine-green` = `#447964`) — but the brand's own
`--bwBrand__*` / `--ui__*` / `--bw-*` / `--spacing-*` / `--radius-*` tokens (59 of the 60 root
vars) remain the core token set.

Also excluded: `--pswp-*` (10 vars, PhotoSwipe lightbox), `--swiper-*` (1 var, Swiper.js carousel,
the one non-brand var that rounds `:root` to 60), one unprefixed `--button` and 6 anonymous
unprefixed/empty custom properties found only in the stylesheet walk.

Third-party script hosts identified and excluded from token capture: `consent.cookiebot.com`
(Cybot/Cookiebot), `www.googletagmanager.com` (GTM), `chat.digitalgenius.com` (DigitalGenius chat
widget), `static.cloudflareinsights.com` (Cloudflare RUM beacon).

## Review of the draft (2026-09-26)

This reference was drafted by a delegated subagent (Sonnet) from the probe and reviewed in the main
session — a trial of delegated authoring. Corrections made in review, each re-measured or re-read:

- Focus is `outline: 2px solid #2771fc`, not a box-shadow ring (the draft wrote `ring 0 0 0 2px`
  on five components).
- The card link's focus does not recolour the label — re-measured, it stays `#ffffff` and only the
  outline appears; its pressed state was not measured and is not declared.
- Hover on the Claim offer, Flowers and Log in controls re-measured with `:hover` confirmed matched:
  no change. The draft had omitted the measured hover values; they are declared.
- "The browser's focus ring" in the draft body was wrong — the ring is authored.
- The B Corp certification is stated in the site's own footer ("Proud to be a B Corp"); it is used.
- The sister brands are taken from the site's footer (bloomon Netherlands / Belgium / Denmark,
  Bergamotte France), not from the draft's unsourced "2021 group formation" and "eight markets".
- The draft cited Marketing Week and UKTN by domain only; UKTN's article URL was found and
  re-read, Marketing Week's was not found and is not cited.
