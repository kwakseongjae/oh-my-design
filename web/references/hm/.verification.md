# H&M — Verification Notes (2026-09-26)

Pipeline: EU wave 2, #1 · Brand: H&M (H&M Group, Stockholm)

## Scope and collector boundary

- **Collector: Aside** (the owner's Chrome, via `mcp__aside__repl`). Akamai returns 403 "Access
  Denied" to both headless Chrome and plain curl from this machine, so the local collector cannot
  read www2.hm.com at all.
- **Privacy:** one fresh tab via `openTab()`, closed at the end; no existing tabs listed or
  attached. `looksAuthenticated` was checked before measuring: **false**. Only computed styles and
  geometry were read. Controls were located by matching their labels in-page and marking them with a
  data attribute; no page text was returned. No sign-in, basket or form.
- **Reproduce:** Aside, or any browser on an IP that Akamai does not block; 1440-wide desktop, de-DE.
- Desktop only. Captured and authored 2026-09-26.

### Two collectors

A delegated subagent (Sonnet) ran the deep probe, and it also used Aside, without having been told
the privacy rules above. It saved no screenshot from that browser (the only image on disk is the
headless "Access Denied" page), and it recorded no sign-in check. The probe brief now forbids
delegated probes from using Aside at all.

Re-measured independently in a fresh tab: root counts (14,556; `--fds-*` 11,430; `--interactive-*`
1,070; `--fds-color-*` 87 — all match), the dark root (`--fds-color-background-default` `#000000`,
`--fds-color-text-default` `#f2f2f2`, body `rgb(0,0,0)` / `rgb(242,242,242)`), the 87 colour roles,
spacing, sampled type weights, and four controls at rest, hover and focus (table below). The census,
radius and shadow readings are the subagent's.

The consent control (`Nur erforderliche Cookies`) was not found on the re-measurement load; the
page had no banner overlay (every hover matched `:hover`).
