# Citymapper — Verification Notes (2026-09-23)

Pipeline: UK wave 1, #2 · Brand: Citymapper

## Scope and collector boundary

- Local Playwright-driven Chrome (Tier 1), 1440×1000, `en-GB`, `getComputedStyle` on the document
  element and on individual controls; state readings through
  `web/scripts/probe-component-states.mjs` (fresh page per state, focus under a real Tab key before
  any pointer movement, seven values compared).
- Logged out. No journey was planned, nothing submitted, no sign-in.
- Desktop only, light mode only. Captured and authored 2026-09-23.

### Two collectors

A delegated subagent (Sonnet) ran the deep probe. Re-measured independently: the headline claim —
the start-location field has no visible focus indicator — confirmed (when the field matched
`:focus-visible`, `outline-style` stayed `none` and no other value changed); Get Me Somewhere
(pressed `#333333` with opacity 0.7, focus `2px solid #000` with `#333333` fill) and Switch City
(hover `rgba(255,255,255,0.2)`, focus `3px solid rgba(255,255,255,0.5)`) matched. The Go and
app-store readings are the subagent's, taken with the same tool version; on the independent run
those two were not found on some page loads (the home page varies between loads), which the tool
reports as unmeasured rather than unchanged.

**Tool fix from this probe:** `--text` matched only `textContent`, so a field labelled by
`aria-label` could never be found. It now matches `aria-label`, `placeholder` and `value` too.

### Country

Citymapper Ltd was founded and is based in London; since March 2023 it is owned by Via
Transportation (New York). The catalog files acquired operating companies by their own
headquarters (skyscanner → UK under Trip.com; farfetch → UK under Coupang). Recorded as **UK**.

## Namespace ownership and the nonsense-path control

**68 properties, all Citymapper's**: 66 `--color-*`, `--font-base`, `--font-body`. No framework
prefix. The computed-root enumeration and a recursive rule walk (testing `cssRules.length`) list the
same 68.

`https://citymapper.com/zz-this-does-not-exist` answers **HTTP 200**, as do `/design` and `/brand` —
the host is a client-routed catch-all. All three render the same "Not Found" body, so status codes
prove nothing here and none of those paths is treated as a page. `/press` redirects to a Google
Drive folder. No design-system or brand-guideline page exists.

Third-party, not read for tokens: Adobe Fonts (`use.typekit.net`, the Proxima Soft delivery),
Google sign-in and Maps, `cdnjs.cloudflare.com`, `sdk.privacy-center.org` (consent).
