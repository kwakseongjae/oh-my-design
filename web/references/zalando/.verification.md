# Zalando — Verification Notes (2026-09-26)

Pipeline: EU wave 1, #5 · Brand: Zalando (Berlin; Zalando SE)

## Scope and collector boundary

- Local Playwright-driven Chrome (Tier 1), 1440×1000, `de-DE`, realistic desktop user agent (a bare
  headless context gets a 403 block page); state readings through
  `web/scripts/probe-component-states.mjs` (fresh page per state, focus under a real Tab key, hover
  counted only when `:hover` matched).
- **Consent:** Usercentrics (`#usercentrics-root`, rendered in a shadow root). A reject click was not
  confirmed in the subagent's runs; every reported state had `:hover` / `:focus-visible` matched, so
  nothing intercepted the pointer at measurement time.
- Logged out; no newsletter sign-up was submitted.
- Desktop only, light mode only. Captured and authored 2026-09-26.

### Two collectors

A delegated subagent (Sonnet) ran the deep probe. Re-measured independently: the Herren navigation
pill — rest `#ffffff`, hover and pressed `#f1f1f1`, focus `rgb(0,95,204) auto 1px` — matching the
rebrand layer's `--color-background-tertiary`. The primary pill and search field readings are the
subagent's.

The subagent took "lagom" to be the theme named in the 2024 engineering post; on re-read the post
does not use that word, so the reference only names the file. The subagent's claim that Zalando SE is
listed in Frankfurt and its "25 markets" were not found on the pages cited; the reference uses the
press-release boilerplate (29 markets) instead. Its search-snippet claim of "200 components and 70
styles" is not used.

### Country

Zalando SE, founded and headquartered in Berlin; no parent company. Recorded as **DE**.

## Namespace ownership and the nonsense-path control

360 root properties, all first-party: `--typography-*` 104, `--color-*` 37, `--component-*` 35,
`--box-*` 28, `--deprecated-*` 18, and smaller `--font-*`, `--border-*`, `--input-*`, `--flyout-*`,
`--drawer-*`, `--ratio-*`, `--spacing-*`, `--grid-*`, `--modal-*` groups. No Tailwind, MUI, Mantine or
other framework signature. The rebrand layer is
`mosaic02.ztat.net/zds/tokens/tokens-lagom-stage-1-border-radius-3.13.27.css`, an `@scope (:root)`
block read from its source text.

Control: `https://brand.zalando.com/zz-this-does-not-exist` returns a 24-byte body (the path echoed)
where the real brand site returns 67 KB with the ZalandoSans font links — not a catch-all; the
subagent saw a rendered "Page not found". `www.zalando.de/zz-this-does-not-exist` returns 403 to curl
(bot block) and is not used as the control.

Third-party, not read for tokens: Usercentrics. Zalando's own Assistant widget is a separate surface.
